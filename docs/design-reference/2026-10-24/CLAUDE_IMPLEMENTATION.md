# 列国纪地图与界面参考图：Claude 执行交接

用户要求：生成游戏界面与游戏画面参考图，交给 Claude 继续实现；复用此前 Codex 多个版本的地图、地形与文字成果。

## 先读与范围
1. 阅读根 AGENTS.md、docs/CLAUDE_CODEX_HANDOFF.md，检查实时 git status / diff。尊重已有文件归属，不提交其他会话未交接的修改。
2. 打开同目录 lieguoji-map-ui-reference.png。它是 AI 生成的视觉目标，不是原作截图，也不是规则依据。功能和模拟规则以 Fantasy Map Simulator 原作为准。
3. 先盘点现有 original renderer、map.ts、city-labels.ts、map-label-layout.ts、territory-labels.ts、国家面板与移动布局，列出已完成/需调整/缺素材。不得重建第二套地图引擎，不得覆盖 C1 标签稳定性改动。

## 还原目标
- 地形：俯视二维古地图，羊皮纸底、自然海岸与群岛、蓝绿色海水、细河流、山脉与森林细节；使用当前真实地图几何与地形数据。国家填色半透明、低饱和，让地形仍可辨认。
- 边界：国家外边界较强、省界较细、河流可区分。不同文化/宗教/家族/联盟视图继续按现有规则分组，不能固定画成图上的五国。
- 文字：国家名使用动态数据、随版图锚点布局，保留已有倾斜、缩放与避让逻辑；首都星标、城市圆点、城市文字分级清晰；选中城市不能让周围名字跳动。不得把任何国名、城名、兵力数字写死进纹理。
- 行军：军队旗标、兵力、行军路线和交战标记来自真实模拟状态；解决与城市名相互遮挡，不能只加装饰箭头。
- 桌面：地图为主体，紧凑顶部日期与存档/图层/设置；左侧工具栏，右侧可关闭国家详情；底部倍速控制及紧凑历史。暖白面板、墨色字、深绿选中态、轻边框，避免巨大胶囊占满屏幕。
- 手机：地图铺满可用区域，避免上下大片空白；顶部简洁，国家详情默认收起为短底栏，支持展开和关闭；时间控制可触达，保留拖动、双指缩放和现有手势。
- 图中地名、日期和统计数字仅为示例；不要引入原作没有的资源或功能。图中“播放”与“运行中”的状态表达有歧义，实现时按实际播放状态显示暂停/播放。

## 素材与实现方式
整张参考图只用于比对，不能作为可玩的地图背景铺上去冒充实现。纸张/山脉/树林等可使用合法现有原作素材或独立纹理与精灵；边界、河流、名称和军队走现有 Pixi 数据渲染。不要将此大图加入 dist 或运行时 import。

## 执行顺序和验收
A. 先修地图可视面积、地形和政治色透明度，再调文字层级和边界；保留截图对比。
B. 接着调整桌面/手机面板和状态；已有按钮必须有效，不做假数据控制。
C. 使用固定种子与同一存档，在全景/近景、暂停/运行、选中/取消、切换地图视图下比较。覆盖桌面1440×900、手机390×844与360×800；验证名字稳定、缩放可读、军队不遮挡关键城市、底栏不吞掉地图、无横向溢出。
D. 检查渲染变化不改变确定性模拟结果；前后性能用同输入实测，视觉截图不能代替功能验证。
E. 按最新 AGENTS.md 发布：本地全量 npm run check，记录真实结果；更新版本和中文 CHANGELOG，仅提交明确交接的文件，推送 main，不跳 hook。GitHub Actions 仅手动触发。部署后核对正式站 build.json 的版本和提交。

本批仅新增参考图、本文档，并追加公共交接记录；没有修改游戏代码，没有启动 Claude 会话或发布新版本。Claude 读取后即可按以上步骤继续；如与另一会话占用文件冲突，先协调文件归属。

# ADR 0019：细海岸显示光照的共享节点重建

日期：2026-09-27。对应PH06-T3/T4。只处理显示光照，不改变权威地理。

实际preview.10在1120%—1125%近岸视图中出现约22px宽的明暗块。v4细格间距为2world，旧shader从最终裁切三角的三个高度求常量坡度，并把整片赋予相同的光照。片间高度连续，解析导数却不连续；海底可分离高度又会使同一细格的两片亮度相近，于是呈现方块。RGBA编码页的nearest过滤承担精确signed16数据读取，不能通过改成linear来修复。

preview.11采用显示版本 `final-q8-pieces-gl2-shared-light-v2`。每个全局细节点分别计算陆侧与海侧光照：轴向邻点在同侧时使用其真实高度，异侧时止于原规则的量化零线，世界边缘使用实际单边距离。同一源节点、同一海陆侧在各细格中复用同值；规范裁切交点继承该侧端点的光照。在原有真实裁切三角中，以重心权重插值光照，再查询原海陆分离的颜色表。零值点和零边也使用确定的共享值，不遗留固定中性光的独立细线。

原Q8裁切、交点量化、三角分片、海陆优先关系、命中高度、诊断字节、CPU拾取、存档和地貌生成器保持不变。原 `detailTerrainPieceRelief` 仍用于核对权威分片的解析高度导数，不能再把其常量light当作新显示光照的期望值。显示连续光照不等于增加了内陆采样精度，也不等于地貌变得更真实。

每个fragment显式读取四个角点及八个外部轴向邻点，最多12次真实节点读取；不会在每个fan候选中重取，也不新增全图光照数组或纹理页。源页仍是五页、16,797,696字节，加两张LUT仍为七个sampler。由4次变为12次采样有额外运算成本，显存不增不能推导帧率不变，三端性能仍需单独测量。

隔离GPU检查直接编译并执行候选GLSL，以原CPU地理拾取核对316个mask/height/color探针；另在五条共边、对角线和薄岸同侧两边读回像素，检查颜色差。CPU参考、GPU诊断、实际产品视图各自记录，不能互相代替。原高度和颜色容差未放宽，非有限值直接失败。

根已在同一保存修订、同一1280×720视口、同一组原生缩放操作下对比1120%近岸，原整片明暗接缝明显消除，岸线位置保持一致。此观察只关闭该处显示缺陷；完整自然外观、用户视觉、内陆精度、真实设备及性能验收继续独立保留。PH06状态只认plan/tasks.json，不由本ADR自动提升。

# 原生 0.9.0：原生界面 + 网页原引擎

## 路线
- 用户决定（2026-10-31）：界面全部原生（SwiftUI + Metal），游戏规则直接用网页引擎，保证与网页完全一致。
- 引擎：`src/native-bridge/engine.ts`（生成世界、推进、调兵、宣战议和、存读档、紧凑状态），由 `vite.bridge.config.ts` 打包为 `Resources/Engine/engine.js`。
- 宿主：iOS 应用内的 JavaScriptCore 不能用 JIT，网页引擎会慢十倍以上；因此放在一个不可见、不可交互的 WKWebView 里运行（Safari 的 JIT），界面不显示任何网页内容，只用 JSON 交换数据（`App/Engine.swift`）。
- 纯 Swift 移植的模块（经济、国库国运、行军、宣战、AI 军队）保留在 LieguojiCore 及其黄金对照测试里，供以后需要时使用，应用本身改用网页引擎。

## 新增
- 启动动画：朱印盖下、「列國紀」浮现。
- 标题画面：地图在羊皮纸上自行生成（海 → 陆地由海岸向山地升起 → 国家着色 → 标注），缓慢平移；「新世界」「继续」。
- 新世界：原作四种地形模板（多大陆 / 联合大陆 / 群岛 / 高山大岛）、国家数量、可选种子；生成后同样以生成动画揭开。
- 游戏界面重做：毛玻璃悬浮控件（日期与战争数、图层、菜单；底部国家 / 军事 / 外交 / 纪事 与播放速度），面板统一纸色卡片。
- 交战、围城、占领、议和、家族、叛乱等全部来自网页引擎；地图领土与国名标签随占领变化。
- 每 30 天及返回标题时自动保存（存档是网页的操作日志，读档时严格重放）。
- 字体：全部界面使用原作 TW-Kai；用原作导出的完整字体按引擎与界面用到的汉字做子集（2617 字，覆盖全部汉字；假名、谚文等回退系统字体）。字体来源与许可见 docs/FONT_TW-KAI.md（政府资料开放授权条款第 1 版，须注明来源）。
- 图标：朱红渐变底、象牙色印框与原作楷体「列」。应用名「列国纪」。

## 已知限制
- 推进速度取决于手机：桌面 Chrome 上战时约每天 0.2 秒，手机可能更慢。
- 未在真机上验证（只在 CI 编译），首次启动若引擎加载失败会弹出原因。

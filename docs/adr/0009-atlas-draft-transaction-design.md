# ADR 0009 — 大世界草稿、共享地理与持久事务

状态：PROPOSED。PH03 实测期间形成的下一阶段设计；不是 PH04 实现或验收证据。实施依赖 PH03 完成，状态仍以 `plan/tasks.json` 为准。

## 范围与兼容边界

PH04 先交付可以生成、查看、局部修改、撤销、保存并刷新恢复的大世界**编辑草稿**。使用新的 `lieguoji-atlas-draft` 格式、独立数据库和入口；不把实验 `ScaleFixture` 或合成社会实体当生产数据。不修改已冻结的 0.4 引擎、旧 World、旧数据库或旧历史上限。

草稿 codec 版本不等于模拟规则版本。新的完整社会引擎尚未注册前，草稿明确 `kind: draft`，不写假引擎指纹、不提供假的开始推演操作。未来真正编译为模拟运行时，才绑定实际已注册的规则及完整指纹。旧入口与旧存档继续按旧格式运行。

## 稳定身份与权威分层

完整地理身份为 `atlasId + entityKind + localId`。初始单元、顶点、边可以按创建网格确定性分配整数 ID，不能因排序、移动、重命名、行政改隶、屏幕 LOD 或 revision 改变。将来细化/合并需要新 ID 与沿革，不能复用旧身份。

初始标准拓扑为 256×256 共享四边形，32×32 单元一个逻辑块。16k/65k/262k 使用同一格式与事务，不把每个地块变成一个县。最低权威层分别是：

- 共享几何：固定拓扑下唯一拥有的顶点与坐标。
- 高程：逐地理样本的定点值；视觉阴影与分类为派生数据。
- 地块到模拟区的 membership。
- 地块到行政叶的 membership。
- 独立的模拟区实体目录和行政实体目录；法理归属、实际控制另设领域，不塞进行政 ID。

模拟区和行政叶不能互相一对一绑定。必须允许一个模拟区跨多个行政叶，一个行政叶包含不同模拟区的地块；两种映射独立修改、校验和持久化。尚未建立的实体允许显式未分配值，不表示相关经营玩法已经完成。

共享顶点按创建坐标的西北相邻地块固定 owner：`floor(clamp(vertexAxis - 1, 0, cellCount - 1) / 32)`。移动顶点不改变 owner；相邻块引用同一权威顶点与边。逻辑块身份绑定 atlas、块方案、层和块坐标；内容 hash 标识该次不可变内容，不覆盖旧内容。

必须分别记录选区块、实际写入的 owner 块、派生显示/索引失效块。四块交界的笔划可能触及额外 halo；不能漏更新邻块来满足性能预算。PH03 的局部预算仅适用于明确满足实际写入块数约束的固定轨迹，更大范围另计。

## 几何、索引与事务

权威坐标采用明确比例的定点数，高程采用独立明确单位；范围与溢出在外部入口严格校验。初版只移动固定拓扑顶点，在创建网格附近的有界范围内检查全部 incident cells 的方向、退化和局部交叉。非法几何整笔拒绝，不自动挪动更多顶点。

索引由真实依赖的块内容摘要标识。移动顶点使所有相邻单元的旧 AABB、点选、面积和显示边界失效；既移除旧位置又加入新位置。高程不无条件重建二维点选，行政 membership 不重建模拟区身份。未来水文的远距离依赖不能假设为只更新一圈邻居。

事务携带 `commandId、draftId、expectedRevision、expectedRootDigest` 和有界字段补丁。Worker 仅在完整导入并独占权威状态后使用增量验证：固定候选输入 → 计算读写集合 → 复制脏块 → 核验受影响引用/几何 → 计算块/目录/根摘要 → 持久 CAS → 发布成功 delta。外部 raw 不缓存成可信对象；不靠 `Object.freeze(typedArray)` 假装不可变。

撤销是恢复旧字段的新事务，revision 只递增。取消发生于提交前则不换根；提交完成后迟到取消必须报告已提交。transfer 只交出独立副本，不分离权威缓冲区。

## 不可变块与原子根

根记录至少包含格式/版本、draft ID、current manifest、backup manifest、revision、lastCommitId 和整条根记录摘要。摘要覆盖完整元数据、字段类型和数组原字节；不同领域/codec 版本均受保护。

可以提前写入尚不可见的候选块，但最终发布必须在一个 `readwrite` 事务中重新读取实际根、准备状态和容量，检查完整根 CAS 与引用齐备，然后同时切换 current/backup、revision、目录和容量账。只在 `oncomplete` 报成功；事务内不得等待 WebCrypto、Worker 或网络。

读取固定某个根版本和该版本引用，不边读取边追随新 current。已发布块保持不可变，因此读取时其他标签的新提交不能拼出混合世界。任一 current、backup、manifest、块 codec 或领域版本未知都锁写，不以旧备份绕过未来版本保护。坏主档不能覆盖好备份；明确读取备份后保持源槽只读，继续编辑先建独立副本。

容量包括已存去重块、manifest/元数据和准备中块，另报主备逻辑引用量；不称为物理磁盘字节。预写和根切换都在事务内更新容量，实际 quota 失败回滚。首版不自动清理任何已发布块；即使废弃候选也计入上限，不能无限忽略。可清理的范围仅为事务性证明从未发布、无活动准备引用的临时块；若该证明尚未实现，保留并明确拒绝超额保存。

最危险的竞态是 A 在 await 前验证旧根、B 完成提交、A 随后覆盖新主备。最终事务必须重读并检查**完整根**。另一个风险是清理器删掉预写块、另标签发布缺块根；清理与发布需对同一准备记录串行检查，不能只凭一次“目前没根引用”观察或过期租约删除。

提交后消息丢失通过 commandId 查询真实结果，不盲目重试轮换备份。广播仅辅助更新界面，CAS 才是写入依据；冲突的败方保留草稿并明确提示。

## 有界消息

请求和结果分别计量完整编码字节，不只统计字段声明。局部消息不携带整个世界、所有多边形、全部行政树或整张 mesh。稳定整数 ID、TypedArray 补丁、固定会话头和紧凑块回执使同一笔操作不随世界扩大而无条件增大。

以 1024 单元、4096 去重顶点为上界的候选预算：顶点 ID/xy 48 KiB，高程 ID/值 8 KiB，两种 membership 合计16 KiB；还须计入真实根、块回执、操作说明和所有协议开销。目标请求/响应各≤128 KiB，最终以实际编码为准；JSON hex hash 不能沿用32-byte二进制hash的计算。

初始化、全图生成和大批创建走单片≤512 KiB的分段准备，持续进度和可取消；候选分段不等于用户笔划分次生效，最终仍原子提交。缺失基线时才请求对应快照/分片，普通编辑发增量。

## 最小验收矩阵

| 场景 | 必须证明 |
| --- | --- |
| 65k 草稿独立 membership | 改行政不重编号模拟区；保存/恢复 ID 和完整摘要一致 |
| 四块交界高程与共享顶点 | 全部相邻单元无裂缝，旧点选位置无残影，非法几何整笔拒绝，撤销恢复字段 |
| 同一局部操作三档地理 | 真实消息有界，报告读写owner和显示失效块；不整图克隆 |
| 第 N 块写失败、取消、关页 | 原根/主备不变，残留候选不成为可载入存档 |
| 最终事务 quota/abort | 根、revision、备份和容量同时回滚 |
| 两标签相同 expected root | 恰好一个提交；败方保留候选，完整根CAS不可被旧验证绕过 |
| 预写与清理交错 | 不能发布缺块根；被清理候选的发布明确失败 |
| 已提交但响应丢失/迟到取消 | commandId可查实际提交；重试不重复轮换备份 |
| 缺块/坏hash/未来主档或备份 | 拒绝载入或锁写，保留原始数据；不静默重建 |
| 主备/不同副本共享内容块 | 去重容量真实，仍引用的内容不得被回收 |

单元层验证故障边界，浏览器层验证实际 Worker、编辑画面、刷新、双标签和关闭页面。旧0.4回归继续独立。本文只确定实施切片，所有性能、功能和保存恢复结论需对应实际证据。

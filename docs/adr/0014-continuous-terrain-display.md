# ADR 0014：连续地形显示与可选编辑网格

日期：2026-09-27。状态：连续地表实现与具名技术检查通过；PH06-T3 的真实细岸线与用户视觉验收仍未完成。

## 实际问题

用户指出普通近景像一块块像素色卡。旧 renderer 为每个真实地理四边形计算一个 RGB 并整体填色；即使调色函数连续、纹理使用线性采样，每个地块内部仍是常数。16 世界单位的地块在 156% 比例下约为 25 CSS 像素。以前的纹理分块和正确保存测试没有解决此视觉问题。官方参考的实际观察记录在 `docs/REFERENCE_GAME_RESEARCH.md`。

## 本次决定

权威地理仍是原有共享四边形、真实高程和海陆分类。显示层按每个地块的实际面积重心与四个真实角点建立四个三角形；重心保留该地块原始高程。共享角点从同一海陆类别的 incident 地块，按实际重心距离重建高度与光照。因此同类相邻表面连续，海陆两侧保持各自分类，不用蓝绿颜色混合隐藏错误的海岸。

`terrain-surface.ts` 只读取所需地块及有界邻域，返回显示缓冲；不会写入高程、几何、存档、生成配方或模拟数据。相同顶点在不同显示块中使用相同样本和固定累加顺序，避免块间接缝。局部坡度使用真实重心间距，光照约束在 0.87—1.13，不能把亮暗当成新增山川规则。

使用 Pixi Mesh 的插值 UV 读取海、陆各自的高度／光照查色纹理，再渲染到既有有边缘采样带的 RenderTexture。两张查色纹理合计 79,266 像素，计入现有 32 Mi 像素总额；表面 Mesh 的 position、UV、index 缓冲另有真实字节计量和原有几何缓存上限。该计量不冒称浏览器总显存：岸线仍由原 Graphics 绘制，另记实际线段数并以每 quad 至多四边约束。不增加隐藏的全世界贴图、不用镜头相关随机噪声。地形失效覆盖角点 incident 地块及其坡度所需的第二圈邻域。

普通浏览默认不显示地块网格。地图工具栏的“网格”开关在近景显示可编辑边界，选中轮廓始终独立保留。开关不改变拾取、相机、地理或存档，GPU 恢复保留本会话选择。

## 海岸限制与后续

这次连续着色不能自动消除权威海陆格边界的阶梯结构。现有海岸平滑工具可以移动真实共享顶点并保存，但受四分之一格和严格凸拓扑限制。没有新增有版本的细分海岸表示前，显示层不能自行绘制与拾取、面积、海陆规则不符的曲线并声称地理已细化。

静态数值推导进一步确认：规则 45° 阶梯虽能在每轴四分之一格位移内被拉到同一直线，但同一 quad 的三个岸点会共线，被现有严格凸校验拒绝并整轮缩步；更浅的阶梯还受到位移范围本身限制。这是数学分析，不是生成器实测。继续增加轮数或放宽拓扑检查不能作为解决方案。若要求任意方向的近景岸线摆脱逻辑格限制，后续须增加有版本的权威子格海岸：显示、拾取、陆地面积、编辑事务和保存共同读取它。自动接入旧平滑只能有限改善，不能代替这一合同。

因此 PH06-T3 保持打开：须实际检查自然地形近景、真实平滑后的海岸和用户视觉要求。河流、生态、城市与行政边界不以装饰素材替代未来真实系统。此次不改生成器历史指纹，不迁移旧世界，不触发发布。

## 验证范围

surface 单元测试 10 项及旧材质回归 3 项首轮通过。最终 `build:cf` 1164/1164 单元、62 文件、22 发布保护检查、lint、类型检查与 25 个产物审计通过。31 个真实浏览器场景首轮 30/31 通过；手机的一条新增 near 接缝探针因放大后移到屏幕外失败，在保留原世界坐标和色差标准的前提下用真实定位操作重构图，完整接缝用例三端 3/3 复查通过。产品与构建字节没有变化，未重复无关生成器测试来充数。

三端实际 framebuffer 验证单格内部颜色变化、共享边连续和撤销／刷新恢复；两次 GPU 丢失恢复、缓存、拾取、候选保存也有真实浏览器证据。完整失败历史、源码清单、构建指纹及截图见 `docs/evidence/2026-09-27-ph06-continuous-terrain.md`。移动仿真不是物理设备验收，技术通过不替代本条 ADR 中仍开放的海岸与视觉要求。

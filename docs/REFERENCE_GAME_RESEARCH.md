# 《架空地图模拟器》参考研究

研究日期：2026-09-23。对象为 Steam app 3035500《Fantasy Map Simulator》。本页记录官方文字说明和原创交互建议，不把资料阅读称为已运行原作。

## 已核实的一手说明

Steam 商店将地图生成/编辑，与国家内政、外交、发展、战争的自动演化并列为核心功能。它支持创造、观察和干预世界，固定战役不能覆盖这一主循环。[官方商店](https://store.steampowered.com/app/3035500/Fantasy_Map_Simulator/)

开发者 2025-01-16 编辑器教程明确的顺序为：编辑时关闭自主外交与叛乱 → 高度图及笔刷修改 → 基于高度生成生态并手绘修正 → 生成/编辑行省 → 生成国家或逐省放置国家 → 开启自主行为。省由相邻单元组成，是最小占领单位，先编辑省再编辑国；切换工具会切换对应地图视图。[公告页面](https://store.steampowered.com/news/app/3035500/view/786541274080477269?l=english)；网页正文未完整展开，全文通过 [Steam 官方单篇 API 响应](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3035500&count=1&maxlength=0&enddate=1737028143&format=json)读取核实。

- 2024-09-28：支持绘制新省、移动省会、国家占省画笔和仅在陆地放置国家。[官方公告响应](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3035500&count=1&maxlength=0&enddate=1727535432&format=json)
- 2024-10-21：生态绘制影响人口承载、生长、物产、军队移动及主场作战效率，证明地形应进入规则计算。[官方公告响应](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3035500&count=1&maxlength=0&enddate=1729512436&format=json)
- 2024-10-26：灰度图导入支持高度与海洋阈值，深色更低、浅色更高。[官方公告响应](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3035500&count=1&maxlength=0&enddate=1729950486&format=json)
- 2026-01-06：进入编辑可自动暂停，避免编辑过程中世界继续变化。[官方公告响应](https://api.steampowered.com/ISteamNews/GetNewsForApp/v0002/?appid=3035500&count=1&maxlength=0&enddate=1767701368&format=json)
- 2026-08 公告表示未来计划重构地图数据、减少 Voronoi 格子限制。这是开发计划，不是已完成能力；本项目无需复制该实现限制。[官方新闻页](https://steamcommunity.com/app/3035500/allnews/?l=schinese)

官方文字确认省会位置可编辑，但本次未核实原作设置国家首都的精确按钮或步骤。以下国家首都交互是《列国纪》的原创产品建议。

## 本项目落实

| 环节 | 原创交互与规则数据 |
| --- | --- |
| 创世 | 空白海洋、生成大陆、继续草稿；种子和参数可复现，生成后继续编辑。 |
| 海陆与地形 | 可见笔刷范围、陆海工具、连续地形生成、撤销重做；地形影响行动/补给/防守，不能只换颜色。 |
| 国家 | 在已有陆地行政单元上手动分配或自动生成国家；保存国家 ID 与归属，同一国家可有不连通领土。 |
| 城市与首都 | 点选有效陆地放城市，名称可编辑；城市坐标与标签坐标分开；首都引用校验所属国家。 |
| 启动 | 校验草稿后编译到现有 Worker；自主行动记录原因；暂停、倍速和手动干预作用于真实状态。 |
| 保存 | 草稿、运行历史与旧测试战役隔离；保存完整地理、归属、城市、日期和规则版本，刷新可继续。 |

相对已有固定战役，地图数据必须由玩家创造并进入同一模拟核心；主角从“选定烈军下令”扩大为“创造并观察世界”。测试战役仍承担命令和规则回归，不作为自由创世的验收替代。完整外交、经济、皇室和历史系统依后续计划实现，不从参考资料直接宣称已具备。

移动端采用可见工具、底部抽屉、明确确认取消；绘制与导航模式分开，核心流程不依赖原作桌面快捷键。下一轮测试以 ROADMAP.md 和 plan/tasks.json 的 M2-001/002/003 为准，至少覆盖双岛绘制、地形可复现、跨岛同国、城市/标签分离、首都合法、自建世界真实运行及隔离存档恢复。

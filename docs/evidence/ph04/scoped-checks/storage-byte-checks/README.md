# PH04 完整原像比较与按需存在性查询

此轮响应真实 100 笔编辑测量中完整 Worker 计算/校验门失败：原存储事务回调 p95 为 23.4 ms，其中最终校验 p95 为 20.1 ms，事务入队 p95 为 5.8 ms。各分段分位数不能相加。

## 实现边界

- `Uint8Array` 原像完整比较：双方底层须为普通 `ArrayBuffer` 且长度一致；对齐视图逐 `Uint32` 直接循环比对，尾部每字节比对；非对齐视图逐字节直接循环。没有摘要捷径、采样或跳过主备块。非字节元数据仍按原有完整字段和值递归比较，未来/额外字段仍拒绝。
- 固定 key 全部执行 `get`。非 `undefined` 结果直接确认存在；仅歧义 `undefined` 结果在同一活动事务中执行 `getKey`。实存 `undefined` 不得视为可写的空槽。动态补查无法排队或发生取消时由真实 abort 结果结束操作。
- `AtlasStorageSession.currentRootDigest` 返回单个字符串，先执行原有失效检查；不暴露内在对象，也不执行完整 `handle` 的目录克隆/计量。
- 全基线原像读取、whole-root CAS、主备未来版本保护、块/manifest SHA、不可变内容、容量、receipt 与取消业务边界保持；计量字段与计量阶段没有调整。

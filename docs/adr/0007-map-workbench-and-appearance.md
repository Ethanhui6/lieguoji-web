# ADR 0007：以地图为主的工作界面

日期：2026-09-24。对应PH02，具体完成状态见plan/tasks.json。工程保持TypeScript/React/PixiJS，不引入UI框架或在线字体服务。

## 单一地图与检查器

工坊与推演各只挂载一份地图。工具、国家、城市、军队及历史在一个覆盖式检查器中按情境展示，不默认用左右两栏和底部纪事包围地图。检查器开关、half/reading切换不改变Canvas尺寸与组件身份，避免现有ResizeObserver归位行为破坏玩家镜头。实际窗口resize/旋转的相机保位仍交PH05，不将此布局调整冒充相机问题全解决。

工坊提供地图、画笔、国家、城市、世界五个真实目的地；推演提供舆图、军情、国家、纪事、世界。军令属于军情对象详情，历史属于纪事，存档与外观属于世界。未实现的行政、人物、家族、信仰不出现假入口。已保存运行选择器移入世界上下文，继续由Root掌管恢复、身份与读写保护。

手机和较窄竖向平板使用半高/阅读检查器；桌面与横向平板使用侧检查器。内容仍来自同一组件实例，不重复渲染两套可聚焦表单。打开检查器不暂停/启动模拟或更改世界；命令预览仍按原规则主动暂停。普通导航不发领域命令。

## 输入与状态

检查器是非模态区域，显示期间仍能直接操作露出的地图；需要确认的生成、替换或分支继续使用已有原生模态dialog。手机使用明确的展开/收起按钮，不在PH02添加未经验证的拖拽抽屉。Escape关闭检查器并恢复可用触发入口焦点；主要内容由单个正文容器滚动。

浏览器回归发现工坊的浮动成功提示会遮挡城市操作，因此检查器打开时，通知进入自身footer的正常布局，不叠在正文按钮上。该反馈区最多占35%高度；异常长消息可单独滚读且可键盘聚焦，标题/关闭和主体仍保留空间。没有检查器时才显示地图旁浮动提示；不通过点击穿透可见文字解决遮挡。无世界的失败页把反馈作为静态内容，保留原始备份入口。

地图已有pointer capture、平移/缩放、笔刷事务等规则保留；新工坊入口以平移作为初始工具，绘图由显式选择开始。当前工具与选中上下文始终可见。模型不会因工具栏、主题或画质切换而变化。原长列表连续触控问题保留，不能用DOM.click/force/直接改scrollTop宣称通过。

## 样式与偏好

`styles/tokens.css` 集中语义颜色、尺寸、字体、焦点和动效；styles.css拥有应用布局与断点，studio/statecraft/history CSS仅拥有内部内容。删除被替代的旧布局覆盖，避免各组件反向争夺grid或断点。

默认浅色，支持深色和跟随系统。系统字体由设备提供，不捆绑Apple字体/SF Symbols；图标是本项目原创SVG。正文和控件可读，手机正文/输入16px、辅助至少13px、触控至少44px。大面积表单实底，仅少量浮动工具允许材质，并提供减少透明效果与较大文字。减少动效遵循系统媒体查询。

显示偏好在`localStorage[lieguoji-appearance-v1]`，格式为 `{version:1,theme:light|dark|system,reduceTransparency:boolean,largeText:boolean}`；它不进入世界/历史数据，不影响规则指纹。损坏或未知设置只回到默认显示，不在读取时覆盖原值；实际修改时才保存。浏览器拒绝保存设置时继续应用当前选择并明确反馈。

验收使用现有真实创世、军令、国家账册和回放功能；静态样式表、截图和浏览器仿真不等于用户视觉或真机PWA通过。大地图真实数据、地形质量和规模仍属于后续PH03—PH09。

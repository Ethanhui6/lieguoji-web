# 先可玩：同图诸国沙盒 · 2026-10-05

## 本轮可玩的内容

绘图页“进入世界”→从当前地图自动建立 2—8 国、首都、城市和军队→开始/暂停/1、3、7倍时间→查看实际人口、粮储和自主决策→国策/宣战/讲和或军队行军/撤退预览确认→查看事件与原因→独立保存→刷新后继续。

用户本轮明确选择“看海沙盒：自动生成各国，看它们发展与战争，随时干预”。默认勾选战乱开局，可取消以和平开始。和平与均衡国策不保证短时间主动战争；界面提供明确可逆的沙盒干预。讲和是双方同时停战的沙盒操作，尚非谈判 AI。

## 地理和规则合同

- 使用当前源网格 float32 坐标及真实 h20 插值裁剪陆地面，沿共享边合并为最多 200 点单环辖区。拒绝有洞/点接触的合并；不使用凸包、随机涂色或跨海近邻。单个面不会静默丢弃；过多碎片/低于规则最小面积时明确拒绝开局并保留原稿。
- 内海仍为海，分离岛屿可归属于同一国，但不自动建立跨海行军路线。模拟坐标统一等比缩放至最长边 1000，人口经济按实际辖区多边形面积计算。此版本无海军/海上运输。
- 国家、城市、军队是可运行的数据；控制者决定政治色，法理归属保留。仍使用网页已有 sim/core 规则，并非声称原作国家/战争代码已全面移植。每国初始一支军队，暂无征募、细分兵种、完整行政与城市近景。
- 新 Worker 直接调用当前核心，并绑定 Vite 实际计算的 `__SIM_ENGINE__` 指纹；不经过旧兼容入口，不改变旧引擎或历史。Worker 串行处理，订单/外交二次核验 day/nextEventId；失败保留上一状态。
- 推演是绘图的独立副本；编辑器进入推演后 inert 且快捷键暂停，绘图文档不改。确认与退出弹窗也将背景 inert，防止键盘从遮罩后启动时间。页面隐藏暂停；未保存刷新有浏览器离开提醒。

## 保存合同

独立库 `lieguoji-fms-play-v1` 原子保存地形+世界+比例+实际规则指纹；当前/备份、SHA-256、revision CAS与第二次事务快照比较。恢复时选真正有效的 current 或 backup；保存备份也使用该 chosen previous。内外未来版本（含地形、世界 schema/rules、经营层）在两槽校验之前直接锁读写，不能按普通损坏降级覆盖。打开阻塞/超时失败后不会迟到升级；写事务超时 abort。

绘图库 `lieguoji-fms-web-v1`、旧战役和自建世界库不写。本轮未把任何完整存档、分析dump或安装包加入产物。

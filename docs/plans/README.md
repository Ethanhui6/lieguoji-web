# 计划资料

这些文件从共享电脑原样放进仓库，给 [主计划](../MASTER_PLAN.md) 当附表。

单子里的 `extracted-ui/`、`_ui-export/` 等来源路径指的是共享电脑上的位置，仓库里没有。界面要用的素材会另外交到 `public/original-ui/`，来源登记在 `public/original-ui/SOURCES.json`。

`twkai-charset.txt` 是 3,017 字的基础版。实际打包用的是 3,033 字版，多出的是鸣谢面板的 16 个字。那份和打包命令由美术放在 `public/original-ui/`，重新裁字体以那份为准。

对照表里的「csv 第 N 行」是原作 localization.csv 的行号，只作溯源备注。查文字一律按 key。

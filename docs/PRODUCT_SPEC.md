# 产品目标与当前交付范围

《列国纪》是单人、本地优先的二维架空世界模拟网页游戏。用户当前主线为：自由创世 → 海陆与连续地形 → 国家、城市与首都 → 自主推演。电脑、手机和平板共享同一世界数据；无需玩家登录、付费 AI 或云端常驻世界。

现有测试大陆已验证军队命令、路径、补给、战斗、撤退、占领、原因和存档闭环。它保留为测试预设；自由创世和自主推演属于本轮开发目标，尚不能因已有战役可玩而标为完成。

## 创世与编辑

1. 新世界提供空白海洋和生成大陆入口；玩家能够创建自己的海陆形状，而非只能重开固定战役。生成结果使用可复现的种子和参数，继续允许手工修改。
2. 绘制海陆、调整地形并支持撤销重做；笔刷有可见范围和明确模式。连续地形生成产生连贯高度/地形结构，不能将随机散色作为山脉、森林或海岸。
3. 国家既可手动建立、命名和划分领土，也可在现有陆地上自动分布。生成国家不能重新随机化已确认的海陆和地形。
4. 城市点、城市名称标签和国家首都引用分别保存。城市须落在有效陆地行政单元，首都必须指向有效本国城市。同一国家可以拥有多块不连通领土。
5. 草稿支持保存、刷新恢复和明确的未保存提示。切换工具、拖动地图与触控缩放不能意外改变地形；一次连续笔划作为一次可撤销操作。

电脑有可见工具与属性区、地图拖动缩放和确认取消；手机/平板用底部工具与抽屉。核心编辑不依赖 hover、右键、Shift/Alt 等快捷键，单指绘制或拖图由当前工具明确决定，双指用于缩放与导航。

## 从编辑进入推演

启动前校验海陆、行政区邻接、国家归属、城市和首都引用；失败时定位问题并保留草稿。通过后将自建世界编译为现有 sim-core / Worker 可运行数据，不回退成固定测试大陆。

基础自主决策使国家在玩家没有手动下军令时也能依规则行动。地形、邻接、补给和军队状态必须参与计算，行为和结果提供原因。暂停、单步与调速继续真实控制模拟，不播放预制战争动画。这里的基础自主决策不等于外交、经济、皇室和完整历史系统已经实现。

编辑时暂停。初始草稿和运行历史分开，开始推演保留原草稿；再次编辑运行中的世界不得悄悄改写既有历史。既有命令预览、确认取消、行军、补给与战损规则继续作为可选干预与回归基础。

## 存档和内容边界

自建世界草稿、其运行存档和既有测试战役存档隔离，保存世界身份及完整地图数据。保留版本、校验、备份、未来版本锁写与多标签冲突拒绝；不能为了新入口直接覆盖旧局。跨浏览器源通过导入导出迁移。

五国、政权、皇室、法理疆域与实际控制权继续分离；首都失守不无条件灭国。CANON.md 的确认内容不被自由生成改写。原地图、正式轮廓和未知剧情独立待核，五国测试地图不会自动转正；缺原规划及 ACCEPT-MAP 不阻塞玩家自建沙盒。

## 本轮完成定义

- 创造并编辑海陆/地形 → 撤销重做 → 保存草稿 → 刷新后恢复相同地图。
- 手动或自动建国 → 放置城市 → 指定首都 → 调整文字位置 → 保存恢复后地理、国家和城市引用保持一致。
- 自建地图校验 → 启动真实 Worker → 无手动命令时出现有原因的基础自主行为 → 暂停/继续 → 保存/刷新恢复，原测试战役存档未受损。
- 桌面、手机和平板浏览器仿真分别记录；正式 iPhone/Android 真机另行验收。真实 CI 与 HTTPS 部署未通过前继续标记待完成。

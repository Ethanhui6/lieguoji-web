## 算法与接口

背景锚点固定在全局 16 world 网格。每点查看边长 64 world 的方窗，即 33×33 个真实 fine 节点，世界边缘裁剪，**仅 coverage>0** 的节点参与。锚点取 nearest-rank 第 25 百分位整米高度；空海窗口没有背景，不伪造 0m 陆地。16 world 网格间作非负三次 B-spline 插值，结果可以是浮点米值：C2 连续、不超邻域高度范围，也不强制每条格线导数为零。

来源读取可跨局部选区及高度锁，这是只读低频背景支持。为插值加一格背景锚点 halo，窗口源读取最大延伸至锚点32 world外；只有世界边缘重复端点锚。写权限完全由原 kernel 的保守实际 quad 遮罩及所有相邻 fine cell 许可决定，不由背景格决定。对于实际正陆地 fine 节点，它必然落入16个插值支持锚点的采样窗口，故有效权重支持都有真实陆地样本；只对海面诊断查询才可能返回 undefined。若真实写入节点背景缺失则拒绝候选。

先把本局部 envelope 的锚点窗口源数据读一次到短整型临时缓存；随后逐行滑窗、精确整米分层直方图统计。最大完整世界缓存为 2049²×2 字节，背景格 257²×2 字节，直方图 12001×4 字节及 47×4 字节。所有源读、滑动增减、分位查询工作按传入的 64—2048 批次合作取消；不存在每个查询重新全域搜峰。每行直方图归零为固定 12001 bins，未改变旧 kernel 的同步入口接管行为。返回的统计只用于窄证据，不新增持久化字段或 UI 功能。

该背景相当于保留旧地的缓变低地/台地，再替换上方新山脊；不是 `max(old,new)`。因此旧局部高峰能降低，低地能被新脊抬高。大于窗口的宽阔旧高原可能继续作为背景保留，这是明确的局部估计范围，不是侵蚀模拟或全山系逆分解。统一海岸 taper 仍由 `physicalHeight` 执行。

与 `/root/curved_relief` 对齐的预期接口：

```ts
createNaturalRelief({ ..., scaleMode: 'local' }, batch, control)
physicalHeight(xQ, yQ, true, distanceQ, oldHeight, oldBackgroundMeters)
```

第六参替代新生成 lowland/rolling 米值，只叠新真实曲脊起伏，再执行海岸 taper 与合法物理高度约束。该接口不在本候选中声明/修改，须与曲脊候选共同接入后检查。

# 原生版 0.26.3（build 75）

基于 0.26.2。只改 `ios-native/`。不合并，不改网页版。

## 新增
- 无。

## 修改
- 开场印章、标题地图升起、生成世界和读档进世界，恢复 0.26.1 的时长和「注水成海」分段字幕。地图仍按海岸到内陆抬升，不再用整图淡入替换。
- 显示设置里去掉「开场与进世界动画」开关。航线、暗边、羊皮纸、国名缩放、完整国名、海色仍用原来的纸面开关、选签和滑杆，没有另做一套控件。

## 修复
- 国家失去最后一块实控领土的同一刻，该国兵力大于 0 的军队被清除：状态改为失去作战能力，兵力、士气、军粮写 0，行军停下。不再停在地图上发呆，也不改派去进攻或投奔盟国。只在本机启用的应用规则下这样做；与网页逐位对照的运行仍保留残余军队。

## 验证与已知问题
- 清除军队时的字段沿用本客户端已有的「失去作战能力」写法（SIMPLIFIED_：兵力 0、士气 0、军粮 0、路线清空、行军标为停止）。原作 DestroyArmy 的组件清单没有逐项搬进这里。
- 舰队不在这次清除里。
- 0.26.2 的省会、海色、省界、显示设置、州郡地形标题、国家页只展开基本信息都还在。
- 没有真机。开场恢复后，截图行程仍按 0.26.1 的标题和生成世界停点拍摄，并保留省会近景。

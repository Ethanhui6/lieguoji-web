# 0012 · 手绘轮廓塑造真实地形

2026-09-27。针对用户明确反馈：大世界仍像地理工具，缺少画出形状后自动形成自然大陆的流程、海洋层次及易用界面。

本批属于 PH06-T1/T2/T3：轮廓输入、连续高程与海岸显示。PH06 状态仍为进行中。轮廓是可复现生成配方的一部分，不代表 PH08 的完整地形笔刷、河流笔刷、多选及重做完成；水系、气候、国家与城市仍按依赖推进，不能补空面板冒充实现。

## 输入与结果

在地图上用鼠标、单指或触控笔画一个不交叉的闭合轮廓，松开后自动闭合并请求 Worker 生成预览。允许双指中断当前笔画并缩放移动，取消、失焦、图形恢复和忙态不得留下半笔提交。保留浏览/拾取模式、精确高程和共享顶点编辑。

新增 `shape-landmass` v1 配方，绑定真实运行闭包指纹、种子、3—256 个 Q8 世界点和海岸曲折、连续变化尺度、内陆起伏、近海宽度。Worker 独立验证非退化简单多边形与世界范围，不信任 UI 校验。真实 quad 重心的有符号距离与连续噪声形成海陆和高程；算法不能使用逐格随机染色代替地形。只新增陆地与其近海过渡，保留已有陆地高度、锁定内容、几何和所有其他层，影响区外海床不变。过小、无可新增陆地或无效形状明确失败，原草稿保持原样。

轮廓生成共用既有持久候选协议：原图 CAS → 私有候选 → 完整地图/hash 校验 → 预览 → 确认并原子保存。取消不写库；确认后的地形可撤销；刷新恢复的是实际地形与原配方。会话撤销栈仍有原有容量及生命周期边界，不冒称跨刷新无限历史。

## 兼容与显示

添加新配方会改变现有生成器闭包指纹，因此存储来源验证与执行配方验证必须分离。仅接受有真实公开构建证据的 90cdabc 四个历史指纹作为已保存来源；保留历史原始编码、hash 和 recipe，不重新标记为当前实现。新执行只接受当前实现指纹，未知实现继续拒绝。

海洋颜色连续依赖真实海床深度，陆地颜色与真实邻域坡度有关。岸线仅沿真实海陆共享边绘制。近景显示纹理可细分，但不改变地理数据、行政层级或模拟粒度；保留 PH05 总纹理像素预算、几何预算、真实 halo、缓存失效和图形恢复要求。历史 PH05 证据不重写，新显示需要新检查。

界面以地图为主，常驻浏览与画大陆两种工具；画图时收起面板，完成后显示预览与确认。浅色/深色均采用清晰的系统字体、圆角分组与克制的半透明工具条，继续支持较大文字、减少透明、键盘取消和 44px 操作目标。不同屏幕的仿真结果与真机及用户视觉验收分开记录。

# PH02 地图工作台验收记录

本记录对应本地 PH02，状态以 `plan/tasks.json` 为准。本阶段实际实现和规定范围的本地验收已完成；更大的后续范围和真机/用户视觉验收不在本阶段结果内。未推送、未触发云端构建或发布，线上仍是既有 0.4.0。

## 实施范围

- 工坊和推演分别保留一个稳定挂载的 Canvas；单一上下文检查器覆盖地图，不通过开关侧栏改变 Canvas 尺寸。
- 工坊五项导航为地图、画笔、国家、城市、世界；推演为舆图、军情、国家、纪事、世界。真实军令、存档、国家账册及历史入口完成映射，不提供行政、人物、家族、信仰的占位按钮。
- 宽屏使用侧检查器；手机与较窄竖向平板使用半高/阅读状态。检查器非模态，主要内容独立滚动，异常长反馈使用有界独立反馈区；确认继续使用原生模态对话框。Escape 避让对话框和输入法，并恢复触发入口焦点。
- 语义令牌、原创 SVG、系统字体、浅/深/系统主题、减少透明和较大文字统一使用。偏好只写本设备外观键，不写世界、运行或历史。
- 工坊初始为平移，画笔必须明确选择。既有画布手势与绘图事务代码未更换；陆地数量、所选国家及国家页表单选择继续由真实状态提供。
- 受保护存储在界面禁用写操作，保留查看、原始备份及返回；底层兼容保护仍由 PH01 的存储和 Worker 校验执行。

设计依据与边界见 `docs/adr/0007-map-workbench-and-appearance.md`。

| 既有操作 | 本批实际入口 |
| --- | --- |
| 手画海陆、地形、疆域 | 工坊 → 画笔，明确选择工具；当前工具持续显示 |
| 创建国家、自动分国 | 工坊 → 国家 |
| 城市、首都 | 工坊 → 城市 |
| 保存、导入、导出草稿、恢复已存运行 | 工坊 → 世界 |
| 选择军队、预览及确认命令 | 推演 → 军情 → 当前编队，也可点击地图对象 |
| 账册与外交 | 推演 → 国家；所选国家、标签页和未提交表单选择在普通面板往返保留 |
| 原因、记录、回放、独立分支 | 推演 → 纪事 → 事件/历史 |
| 保存、原始保护导出、返回工坊、外观 | 推演 → 世界；无法载入的错误页直接提供恢复入口 |

## 检查计划与结果

整批代码稳定后执行 lint、类型检查、计划/发布锁检查、单元测试与生产构建。对宽范围导航变化运行受影响浏览器用例及新的外观工作流；实际次数、失败、修复和原始路径在执行后追加，不提前记 PASS。

当前浏览器定义：原有 72 项，加 9 项外观/导航验证，桌面 Chromium、Pixel 7 配置 Chromium、iPad 第七代配置 Chromium。后两者均是浏览器仿真；360px 边界、系统深浅切换、减少动态、无透明和较大文字另有覆盖。不是实际 Android、iOS Safari 或真机 PWA。

已取得的本地证据：

- `npm run build:cf` 首次通过：计划校验、ESLint、TypeScript、14 项发布策略、12 文件 472 项单测、生产构建及 23 个产物白名单。日志 `.autopilot/ph02-build.log`，单测 39.56 秒。
- 新增 `tests/appearance.spec.ts` 的 9 项首次全过，57.2 秒，0 重试/失败/flaky/跳过。日志 `.autopilot/ph02-appearance.log`，机器报告 `.autopilot/ph02-appearance-results.json`，截图 `.autopilot/ph02-appearance/`。实际固定种子是默认创作草稿 `山河-2026`，后续自动分国与城市，然后创建真实推演和记录副本。
- 内部逐张查看桌面浅色工坊、手机浅色国家、360px 深色大字国家、桌面深色只读历史、竖屏平板浅色账册截图。指定可见状态未见核心按钮遮挡或文字不可读；不将这个内部检查记作用户最终视觉验收。
- 原有 72 项首轮回归 **66 通过、6 失败**，636.2 秒，0 重试/flaky/跳过。日志 `.autopilot/ph02-regression.log`、报告 `.autopilot/ph02-regression-results.json`、失败 trace/截图 `.autopilot/ph02-regression/`。
- 三端历史配额失败场景均卡在旧脚本对已禁用“单日”的点击。之前的故障注入、原日期及主备/usage/revision 一致检查已通过。修为显式检查继续/单日/速度禁用，保留全部原档及刷新后推进证据。

- 手机手画场景发现实际UI缺陷：成功提示覆盖“自动城池与首都”。修复为检查器自身正常布局的反馈footer；错误/状态仍完整可读和可聚焦，地图几何不变，不使用force或点击穿透。工坊提示定位改用稳定的 `studio-notice` test id。无权清除的根级错误不再显示无效关闭按钮。
- 修复后 ESLint、类型检查、生产构建及23产物审核通过（`.autopilot/ph02-rebuild.log`）。规则、存储、Worker、Canvas和单测文件未修改，复用本批472单测结果。
- 最终受影响集 **57/57 首次通过，约5.0分钟，0重试/失败/flaky/跳过**：外观、游戏闭环、历史故障恢复、经营外交、工坊与工坊保护共6份spec。日志 `.autopilot/ph02-fix-check.log`、报告 `.autopilot/ph02-fix-check-results.json`、截图 `.autopilot/ph02-fix-check/`。其余24个兼容、正常历史/分支及旧规则升级场景复用首轮通过结果；这些源规则/组件未改。

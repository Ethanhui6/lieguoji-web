**为何不是改了诊断名的同一串土包。**

旧三条独立平行山带改为一主两支；支脊根点是实际选中的主脊锚点，不是邻近目标坐标。helper 再要求该点确实存在于通过陆地探针的主曲线上，且位于实际 surviving run 已完全渐入的内部、其真实端部 gate 至少 0.5。主脊被海岸阻断时，只保留各自通过真实曲线检查的段；截断后成为真端点/渐退段的锚点不能承接支脊。支脊任何一段失败则整个支脊不采用，防止跨海峡剩下断开的远端。

旧 `run.length / 3.7` 周期包络已从新高度路径移除。主脊沿完整物理弧长预建三个不重叠、长度不同的峰事件；事件区间、峰位和幅度由固定种子决定。短于 384 world 的实际 run 使用一个事件退化。插入等价的共线锚点不会另生峰。基底脊高保留 0.34 比例，避免鞍部整条掉成细线。

横断面从正椭圆半径核改为“沿向 compact 支持 × 横向断面”的可分离条带。横向为 0.76 的窄脊与 0.24 的宽山麓；脊宽至少按真实采样尺度限制，不往粗内陆 Hbase 里塞无法承载的微纹理。其支持仍沿共享切线曲线做积分，但沿向支持不会把横向山麓挤成椭圆。

支脊根部峰高改为连接处父主脊**已经建立的实际高度支持与同一 gate 查询值**的 0.82 倍（父值最高取 FIELD_Q），并沿真实支脊弧长递减，末端归零。每个连接只在准备期穷举已有节点一次，最多两次共 8192 个支持检查，不在 fine 查询重复扫描。

不同实际 run 改为正规化 L64 合成：`(ε⁶⁴ + Σ h⁶⁴)^(1/64) − ε`，ε 为 1e-6 Q12 高度单位。它随任何非负山体单调不减，添加较弱支脊不会挖低父山脊；归一化最大值仅用于避免数值幂溢出，不是硬 max 裁剪。最多 10 个实际 run，合成不超过 `10^(1/64)` 倍最高单 run，抬升小于 3.67%；两条同高山体交汇的上界小于 1.09%。保留原最终 relief、高程整数化与海岸 taper 合同。这个明确小抬升替代了原候选错误的“绝不高于最高山体”设计，不能据此直接认定实际交汇已自然。

支脊一侧的有限中段降低宽山麓：沿弧长权重 `16 t²(1−t)²`，横向槽形 compact 权重，最大降低该山麓部分的 0.98。谷底不低于原背景，不产生新海面；窄脊保持独立。它是实际高度关系，不是河线，未表示已形成汇流网。主脊之间、支脊之间的真实低处也仍由高度数据决定。侧谷的尺度与可读性仍需最终实际 Hbase/细高程图确认，不能以 helper 测试代替。

原低地与 rolling 背景保留；取消原来乘在高山上的 64-world weather 噪声调幅。没有新增显示噪声、高频海拔层或渲染纹理。第六参背景仍只替代新低地背景，与统一新山体相加后应用原海岸 taper 和整数米返回；因此局部旧山体可被新的较低构型替换，未恢复 `max(old,new)`。

**连续性与工作上限。**

- 使用共享端导数的 Hermite 曲线，按 Bezier 导数上界采样，曲线陆地探针的相邻空间步长不超过 1 world 加 Q8 取整误差；实际探针数最多 131072。
- 有限源：最多 3 条链、17 个实际锚点（9 + 4 + 4）、14 段、10 个有效 run；复制前即检查每链及总锚点长度。规划器最多 15 个目标在私有 eligible 列表中查找。列表最长 `size²`，不扫描其他世界、文件或全局缓存。
- 高度节点最多 4096、索引 references 最多 262144、每 bucket 最多 192 个候选。仍是 64×64 个、每边 64 world 的固定空间 buckets。超出直接拒绝，不降低检测密度或扩大预算。
- 可分离 compact 三次核在边缘具有零导数；侧宽用端导数为零的有界奇函数，保留 `1.15 × width` 索引外包络；真实链端 gate 是 C1。山麓削减因子保持正值；非零 ε 的 L64 合成在零值也光滑。因此此处只主张构造的浮点山体场为 C1，不把 Q8 几何取整、整数米存储或最终屏幕像素称为处处可微。
- 所有数组与参数在首个 await/回调前私有捕获；曲线/节点/events/spans/ends 返回副本。正常扫描、陆地探针、支持节点、实际父高度连接核验及索引阶段按既有 batch 范围让出执行并前后检查取消；最后一次回调后再检查。查询只读私有结构，使用有界 scratch，未加入隐式全局缓存。
- local 原尺度默认逻辑继续：默认 world；local 使用实际选区长短跨度，2-world 采样，宽度继续受锚间距离约束。704×448 测试片只保留一条；极窄片及无 eligible 陆地只保留背景，不扩成世界山系。

**原检查不变，新增检查的目的。** 原真实曲线峰鞍测量仍在原 test 中，至少两个峰、两侧各大于 200 米显著度、内部总峰谷差大于 800 米；400 米截面宽差至少 32 world，段数不超过 16。原真实陆地曲线检查、最大宽至少 128 world、海床/陆棚差异、私有输入、取消和局部缩宽约束不变。原 `detail-curved-ridge.test.ts` 的全部旧 1-Q8 有限斜率、全 support oracle 与 192 候选上限也不改。

新测试增加的是独立 helper 的实际高度关系：非周期峰间距和峰鞍显著度、插入共线节点不变、窄脊宽麓、交汇实际截面不低于独立 parent-only 地形且符合小抬升上界、实际侧谷低于外肩、C1 斜率收敛、真曲线越海拒绝、跨海峡支脊整体拒绝、截断父脊零端点反例、384 点穷举支持与索引一致、原预算常量、私有副本、五阶段取消、真实 world/local 规划以及小选区背景退化。另直接检验原 `[1,.7]` 凹陷反例、L64 零/极小/极大值稳定性及超限源不复制。辅助 oracle 穷举所有节点，不复用生产空间索引；它验证索引完整性，不能单独证明自然观感。

没有修改任何现存峰鞍/截面的坐标约定。新增条带测试使用真实曲线弧长、切线法向及真实 float 高度；支脊谷底按物理横断面量测，其阈值不替代旧自然地貌测试的米数阈值。

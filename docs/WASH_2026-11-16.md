# 占领晕染与省份闪动（1.18.0）

## 闪动根因

1. **易主渐变的“上一版”卡住（主因）**。`MapRenderer.recolor` 旧逻辑：`previousColors = fading ? previousColors : colors; fadeStart = now`。全图只有一个起点和一份上一版颜色；渐变（0.7 秒）未完又来新颜色时，上一版不更新、起点却重置。打仗时归属每 0.5 秒刷新一次（`GameModel.apply` 的节流），渐变永远“未完”，上一版停在这一串变化开始之前——每次有州易主，之前已变色的州都被打回更早的旧色再渐变一次，持续闪。回归测试 `ConquestWashTests.testOwnershipFadesNeverSnapBack` 用旧算法复现（亮度跳变 > 0.5）并验证新算法（< 0.1）。
2. **战场地面预算边缘进出**。`setBattleGrounds` 按兵力排名截前 10，第 10 名上下的州每步进出名单：进入“胜方铺满后淡出”，下一步又回来淡入。改为已在显示（未结束）的优先。
3. **细节硬切**。战场地面在相机比例 1.0 处硬切墨晕与笔触，缩放停在附近时边缘反复跳。改为 0.7…1.3 连续过渡。
4. **后台结果只认最新**。高倍速下归属每半秒变一次，后台重算若更慢，结果全被作废，颜色迟迟不更新后一次大跳。`MapWorkRevision` 增加按代次安装：不比屏幕上旧的结果先装上，更旧的丢弃，切视图前的颜色作废。

## 连通区域晕染（`Core/Sources/LieguojiCore/ConquestWash.swift`，渲染 `Render/Wash.swift`）

- 拓扑：陆地格只认共享一段真实边的为邻（角点接触不算）；同一位置的顶点拷贝归为一个角点。
- 区域：同一进攻方、共享陆地边的被占州。每次输入或归属变化时重新分组；分组与源（进入边界格 + 起点偏移）的哈希不变就复用距离场。
- 距离场：多源 Dijkstra 沿格心在区域内传播；源 = 区域里挨着进攻方领土（区域外）的格子，本州有进攻方军队时离军队近的边界先起（起点 = 0.5 × 到军队距离，军队位置有 0.6 尺度的滞回）。没有陆上入口时从军队所在格起；断开的部分各自从离提示点最近的格起。顶点值 = 共享该角点的区域格中最小的“格心值 + 到格心距离”，跨格、跨州连续。
- 前沿：每州一个以世界单位表示的阈值（显示值），按该州面积分布由进度换算（`threshold`/`fraction` 互逆、区间外线性外推）。临界阻尼弹簧追目标，速度连续、有上限；同一区域里的攻占共用最远的铺满处作目标，同时起步的几州走同一条等距线。新州从进入边界起，若同区域邻州的前沿尚未推到，就与它同步。
- 换场（合并、拆分、源变化）：保留覆盖占比换算到新场，旧形状存为每顶点的有符号距离快照，0.45 秒形变过渡。
- 易主：底色换成进攻方时（安装新颜色那一刻发现），该州改为“未到达处盖旧色、已到达处旧色余韵 0.45→0”，与换底前“进攻色 0.5 压旧色”在画面上相等，不跳。
- 着色器：静止的世界坐标纸纹起伏（尺度 = 各州等效半径中位数），柔边与一道淡墨湿边；细节随缩放连续。交战中的州按战场地面透明度互补让位。
- 时钟：易主渐变、战场地面、晕染共用本帧时刻（`frameTime`），每帧 dt 上限 0.1 秒。读档、换世界（没有上一步状态）换代清空。

# 下一批：沿岸分区形态（最小实现方案）

记录时间：2026-09-28。状态：只读源码审计后的实现建议，未实现、未运行测试或 GPU，不是视觉验收。仅本文件可写；并行中的细山脊修改不属于本任务，也不应被还原。

## 预期结果

同一片手绘大陆中出现不等长的宽海湾、窄岬、局部裂岸和低变化长岸。生成结果仍是保存的真实覆盖场；玩家大致画出的半岛、海峡、内湾和总体笔形得到保留。只做沿岸局部形态，不增加国家、行政、河流或侵蚀的假数据。

当前不是等间距正弦轮廓：`createNaturalCoastArcPlan` 已经使用不等长、偏心峰、打乱符号的两级事件。因此本批不要再重复“随机宽度/相位”修复。具体缺口是全岸相同的事件语言与 48/12 world 细节组合，且主要湾岬顶端的次级形态被统一削弱。

## 改动一：现有弧长规划器形成有限的沿岸区段

文件与函数：`src/world/generation/detail-natural-outline.ts` 的 `createNaturalCoastArcPlan`，当前约 220—299 行；`NaturalCoastFeature` 只作内部规划诊断，不是存档格式。

### 区段与分配

1. 保留现有一次性私有规划、固定种子、弧长循环、空间 bins、有界预算和 source ownership。
2. 对周长不少于 2048 world 的普通大陆，建立 6—10 个连续、不等长区段。区段数沿用当前约 `round(perimeter / 360)` 的规模；不按输入点数、画笔速度、屏幕缩放或粗模拟格数分区。
3. 四种区段是内部形态标记：`bay`、`cape`、`fractured`、`quiet`。前 6 个区段提供 2 个宽湾、2 个窄岬、1 个裂岸、1 个低变化岸；额外区段用独立 seed tag 分配。用 Fisher–Yates 打乱区段顺序，不能固定循环“湾→岬→裂岸→平岸”，也不强制正负交替。
4. 每个区段先得到带扰动的物理长度权重，再归一化分割周长：宽湾约 1.7—2.6，窄岬约 0.7—1.2，裂岸约 1.2—1.8，低变化约 1.2—2.0。这些是初始设计区间，不是必须对每种子完全相同的固定长度；最终强主特征仍至少覆盖 48 world。
5. 周长较小的轮廓继续使用现有 0/2/少量事件策略，逐步缩小 reach；不能为了塞满四类地貌破坏小岛。初版可在 1024—2048 world 间平滑减弱区段差异；少于 1024 world 保留原有计划路径。`structureWorld === 0` 时结构层严格为 0，现有小尺度 roughness 行为保持可用。

### 各区段具体产生什么

| 区段 | 主结构（乘现有 structureWorld） | 次级结构 | 避免的问题 |
| --- | --- | --- | --- |
| 宽湾 | 负向、较宽，深度约 0.75—0.95；偏心低谷，左右坡程不同 | 最多 1—2 个较弱湾肩变化，不固定放在中心 | 不再每个海湾都是同宽圆碗；宽湾是切入陆地 |
| 窄岬 | 正向、较窄，深度约 0.70—0.95；峰不固定居中 | 1 个非对称肩部或基部次级变化；不把峰变成尖针 | 用真实狭长陆地外伸，避免与宽湾互为镜像 |
| 裂岸 | 较弱区域基形，约 0.10—0.35，符号不固定 | 3—5 个不等长、分簇的次级凹入/突出；16—64 world 尺度，在本区段内取可容纳数量 | 不给全圈堆同频锯齿，也不把裂岸叫作真实侵蚀/峡湾 |
| 低变化岸 | 结构变化约 0—0.15 | 不强制添加次级事件，小幅细节即可 | 有长短不一的安静岸段，与复杂岸段形成明显对照 |

宽湾/窄岬深度是 FIELD_Q 的归一化系数；最终仍乘旧 caps，而不是直接向最终位置平移。保留连续、不同左右坡程的曲线，C1 连续不等于必须具有相同圆波形。可复用现有 ease，分别以不同峰位、非对称肩部节点形成主轮廓；不为追求尖锐制造导数断裂。

次级事件总数继续不超过 36；同一区段的次级事件槽互不重叠，每个事件可偏心，间距不等。裂岸簇之间留空段，不对每条源边或每个顶点各加一个波。总特征不超过既有 48、bins 128、references 1024、每桶候选 8；若不能在当前预算内排布则减少该区段次级事件数量，不提高预算或退化采样。

主、次层可继续采用现有有界合成 `r + l * (1 - r*r)`，保持 `abs(l) <= 0.321` 和同层不重叠。裂岸区降低 r，给次级结构留下空间；宽湾/岬顶不必强行塞更多波。无需本批重写整套距离场。

诊断返回新增拷贝的 `regions` 与 region kind，不向外暴露可改动内部状态的引用。新增 seed tags 独立，不复用其他系统随机流；不要修改共享 seed.ts。

## 改动二：生成器按区段采样细节，取消全岸统一频谱

文件与函数：`src/world/generation/detail-shape-natural.ts` 的 `generateDetailShapeNatural` 内 `design(x,y)`，当前约 187—197 行。

目前真实岸场为：

```text
design = signedDistance + cap * (structure * structuralQ + roughness * detailQ)
                               / ((structure + roughness) * FIELD_Q)
detailQ = (3*N48 + N12) / 4
```

只把 `detailQ` 换为规划器提供的区段采样，例如新增 `coastPlan.sampleDetail(arcQ, shoreUQ, shoreVQ)`。保留 `sample(arcQ)` 的结构标量接口，缩小调用改动范围。sampleDetail 在闭包中读取私有区段；不在每个细节点分配对象/数组。

建议只用三组固定世界波长的场 N96、N24、N8，按区段作凸组合，再乘 0—1 的粗糙度增益：

| 区段 | 初始频谱建议 | 增益 |
| --- | --- | --- |
| 宽湾 | 0.80*N96 + 0.20*N24 | 0.35—0.55 |
| 窄岬 | 0.35*N96 + 0.65*N24 | 0.45—0.65 |
| 裂岸 | 0.35*N24 + 0.65*N8 | 0.80—1.00 |
| 低变化岸 | 0.90*N96 + 0.10*N24 | 0.10—0.20 |

8 world 仍有 4 个真实 2-world 步长；不加 1/2 world 级噪声。每次最多 3 次 noise 查询，当前为 2 次，需要如实记录 CPU 差异，不能声称零成本。

区段交界不能直接切噪声。让区段风格在两侧 24—48 world 的有界过渡带内回到共同基线，使用 C1 权重混合；对短区段将过渡宽度限制在区段长的 15% 内。所有权重非负且总和为 1，增益不超过 1，因此 detailQ 保持在 [-FIELD_Q, FIELD_Q]。循环首尾使用同一 wrapped arc，不能出现起笔接缝。若 structure=0，sampleDetail 返回当前原版 N48/N12 组合，保证该控件语义清楚。

仍只取轮廓投影点 shoreX/shoreY 的场值，沿同一法向保持常量。**不要改为给每个内陆 x/y 点加覆盖噪声**，否则会重新产生孤立海孔和未请求的岛。

## 保留的精度、拓扑与身份边界

- `prepareOutline` 的原始自交验证、`simplifyNaturalSampling` 的 2 Q8 抖动容差、`naturalFacingSeparation` 的双岸预算、cap 插值和传播全部保留。
- `roundAndIndexNaturalOutline` 的圆角已消耗 caps；新事件沿用剩余 caps，不把原始预算再花一遍。细节与结构先归一化合成再乘 cap，不能各自获得完整 cap。
- 最大偏移仍由 `structureWorld + coastRoughnessWorld` 和局部 caps 控制；新轮廓范围不能超出当前 display band / 世界边缘保护。2-world 节点、Q8 零边、目标海岸重新求真实距离、面积审计与拾取使用同一数据链不变。
- `generateDetailShapeNatural` 只影响新生成候选。追加自然大陆通过当前调用继承新算法，但旧大陆字节、实际海岸/高程锁、追加拒绝规则保持原样。没有版本/存档迁移。
- 当前并行细山脊只读。本批预计生产修改限定 `detail-natural-outline.ts`、`detail-shape-natural.ts` 和相应测试；不修改 `detail-natural-relief.ts`、`detail-orography.ts` 或 renderer 来掩盖结果。
- 实现前由 root 冻结当时实际源码闭包和全部生成器身份；若细山脊已先合入，基线必须是合入后的实际版本，不能再写成旧 preview18。新构建重新计算指纹，旧身份只加入对应 storage history；不得复用旧执行指纹。保留 v1 / natural@2 / local-relief 隔离和旧 Hbase reader。

## 只增加三个有意义的验证组

1. **同轮廓确实产生不同区域形态，且没有周期模板。** 在固定的 3 个种子、2541/5200 world 周长上，以 2-world 弧长采样完整实际结构+细节偏移，而非只断言 `kind` 数量。应观察到：两个以上强湾和强岬；宽湾的有效宽度显著大于窄岬；低变化区段的偏移/弯折明显低于裂岸；裂岸的小尺度转折集中于局部；四分之一周长平移后的序列不重复。按预先定义的物理尺度统计，不选择单个最好看的种子。保留当前 bounded/index oracle、循环首尾 C1、ownership、不同 batch 确定性契约。现有 `>=6` 主事件测试不应随手改小；典型大陆仍至少 6 个区域事件，新增要求覆盖可观察差异。
2. **真实输出保留笔形和窄海峡。** 通过 `generateDetailShapeNatural`、islands=0 生成一张不对称大陆和现有 12-world U 形通道轮廓。检查实际 targetCoast/持久化细场全部在原包络内、世界海陆面积守恒，12-world 通道的中轴到开口保持连通海域，没有跨岸桥接；手绘细长半岛仍连通。用两侧几何/连通性验证，不能只检查天然保护函数返回 12。保留零变化时原轮廓、直线输入加密不改变真实 bytes 的现有契约。
3. **新地理进入保存流程且旧世界不变。** 新世界 preview→确认→刷新后逐块 coverage/height hash 一致；取消期间无 durable 写入；在已保存旧大陆旁追加新区域后旧大陆/锁区签名保持，当前历史配方只允许读取。同一轮廓、种子、参数在不同 batch 结果一致。已有事务回归能覆盖的部分直接复用，并报告范围，避免为同一保障新堆重复测试。

## 默认参数与范围

本批先不改 UI 参数：主要湾岬 96、海岸细节 32、陆架 128、起伏 2400 米、1 条×3 岛。主要效果来自同样上限下的空间分配：128 world 最大包络不增大，低变化岸更安静，裂岸局部变密，宽湾与窄岬不再近似互为镜像。不会靠放大地图格数、抬高所有粗糙度、增加统一蓝色岸线或改变海色来宣称自然感已解决。

不新增玩家必须理解的四类百分比滑杆。现有“主要湾岬”控制大形变，“海岸曲折”控制区段内细节；值为 0 的行为要保持明确。陆架/海色、自然群岛、河网、行政、城市、兵种和战争均不属于本批，也不随本批完成而宣称已经实现。

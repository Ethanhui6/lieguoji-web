# 0.5.46 界面对齐记录

目标：修正用户指出的存档按钮偏心、界面不统一和不可下载交付。基线 main cbceec9e（0.5.45）；保留现有游戏和 iOS 资源修复，未修改模拟规则。

## 对齐关系

| 元素 | 旧问题 | 本版约束与证据 |
|---|---|---|
| 顶栏存档图标 | 未保存小点作为 flex 子项挤偏图标 | 小点绝对定位；按钮与图标中心 X/Y 差不超过 1 CSS px，三尺寸测试通过 |
| 顶栏功能 | 多个独立方块，尺寸/背景混用 | 返回和日期组成左胶囊；图层/菜单/保存组成右胶囊；按钮统一 44px，图标 22px |
| 播放、缩放、工具 | 不同圆角与内边距 | 共用中性半透明材质；播放组合居中，工具入口为圆形 |
| 存档标题 | 左对齐与关闭按钮挤在同一行 | 52px 标题区居中；关闭按钮固定右侧，独立 44px 点击目标 |
| 新建存档 | 表单宽度不一致，过大空白 | 输入框与提交按钮左右边界一致；内容高度面板，上限 440px；蓝色主按钮、灰底次按钮 |
| 图层与内容 | 地图文字透进表单，工具叠在菜单上 | 内容面板不透明，玻璃仅用于小控制区；菜单位于遮罩之上，地图无法误触 |
| 横屏与输入 | 存档操作可能被键盘挤出 | 受安全区约束，模拟键盘占用 220px 后滚动访问保存按钮；WebKit 实际命名存档保存成功 |

## 视觉方向

参考 Apple Liquid Glass 的控制层与内容层分离、中性材料、清晰文字和分组工具栏。使用系统字体、系统蓝操作强调色和分组灰底表单。这里是 WebView 内的 CSS 实现，不宣称原生 UIKit 材料或逐像素复现系统折射效果。

## 检查范围

- 21 个主要界面状态：生成、开局、国家、人物、官职、陆军、海军、历史、排行、图层、AI、国家编辑、菜单、外观、自动保存、云存档、加载、保存列表、新存档表单、导出、确认框。
- Chromium 三尺寸操作与对齐断言；软件渲染截图用于布局，不用于推断真机性能。
- WebKit 手机 393×852 / 852×393：地图像素、工具与面板、命名保存、重载恢复、键盘空间模拟。新增 ios-portrait-save.jpg 与 ios-landscape-save.jpg。
- 物理 iPhone 键盘、原生玻璃材质和 120Hz 性能仍未真机验收。
- 发布包将作为 GitHub Release 资源提供 HTTPS 下载；本地路径不作为唯一交付方式。

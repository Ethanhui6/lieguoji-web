# 主创世入口直接生成可编辑世界

本批目标：在游戏内选择模板和种子，生成真实地理预览，取消或保存为独立新世界。版本 0.5.0-preview.33，仍为本地开发构建。全 PH 发布门保持，不触发 GitHub 或 Cloudflare。

## 实现范围

- 四个经过限定适配的模板：群岛、多大陆、高山大岛、联合大陆。原高度操作和 Alea 随机算法的来源与许可证见 [PROVENANCE.md](PROVENANCE.md)。完整 recovered main、安装包、解包工具和私密素材不进入产品。
- 固定正方形网页点网：1536×1536，192×192共36,864点，d3-delaunay重建邻接。其身份是网页点网；不能称作原 Unity 邻接。新的方形输入完整映射4096×4096世界，不需要在内部上下填补海带。
- 首段Worker只运行固定打包代码；输入仅模板、种子与square-v1，不能提供脚本、路径或URL。按最多512KiB消息、ACK、总12MiB、请求与内容摘要边界传输；结束后释放此Worker，再进入原有严格导入和保存流程。
- 第二段Worker复用此前核验的三角形校验、细场转换、独立候选、原子保存与持久回执。不修改旧导入协议、旧生成器指纹、旧schema或旧草稿。新地图仍使用origin:null和generation.lastApplied:null，新增生成来源记录单独下载。
- 预览显示真实Atlas地形；取消无持久写入。保存后自动打开，可以继续编辑或建立独立建国世界。来源和技术细节收进折叠区，主流程不要求用户下载、找文件或访问研究页。

## 数值兼容与有界执行

纯TypeScript适配只保留四模板所需操作和明确种子的Alea数值内核；每次调用拥有独立的随机与高度状态，不读写全局Math.random。三个来源不确定的d3命名helper改为项目有限数值函数，没有冒称精确历史版本。

保留实际安装包研究基线中的linePower=0.79、Uint8Array截断时机、邻接迭代顺序、边界点的随机消费与首次最近点规则。classic-v1仅为内部对照测试，不能从生产消息选取；该布局的archipelago/421730高度与拓扑摘要必须逐字匹配上一批。生成加入总工作预算和海峡路径上限；失败拒绝结果，不静默换种子或替代地图。

生成字节包含固定字段顺序和0测量时间；0表示未将运行耗时写入地形文件，不代表计算耗时为0。相同模板/种子/版本得到相同字节；来源记录再包含独立编译指纹。新指纹覆盖所有本地运行依赖、实际d3相关源码与锁文件，不改写任何既有历史身份。

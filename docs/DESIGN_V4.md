## 1. 产品体验与真实基线

玩家的主要视线和操作应落在世界上：画出巨大世界 → 建立不同制度的国家与行政区 → 城市、人物家族与信仰 → 自主推演 → 解释变化 → 干预 → 保存、回放与分支。界面帮助完成这条路径，不做宣传首页、数据后台或设置面板集合。
当前 0.4 是可保留的工程基线，不等于巨大精细地图、完整行政制度、家族或信仰已经实现。未实现的能力不放进主流程假装可点；有真实能力但没有数据时，空态提供可执行的下一步。

## 2. 原创视觉方向

“iOS 质感”取清晰层级、直接操控、立即反馈、空间连续和可恢复操作；保留原创山海与历史气质。不复制 Apple 品牌、系统应用界面、设备外框、专有图标或字体，不暗示官方关联。系统字体由设备提供，不打包未经授权的 Apple 字体或 SF Symbols。
默认浅色、提供完整深色。地图承担自然细节，UI 承担读取与操作。禁止全屏毛玻璃、多层透明叠加、巨大空卡片、卡片套卡片、所有按钮胶囊化、连续发光与无意义背景动效。

| 设计角色 | 初始参数/候选 | 使用约束 |
| --- | --- | --- |
| 浅色阅读面 | `#F3F2EA`，文字 `#202E35` | 默认稳定实底，轻微暖色，不铺脏纸纹理 |
| 深色阅读面 | `#192F3B`，文字 `#F0F3F1` | 完整语义配色，不简单反相 |
| 海洋与外围 | `#102B38` / `#0C1E29` | 深浅海层次属于地图，不将所有面板继续刷暗 |
| 主要操作 | `#2D726A` | 与国色、信仰色分离；明确可操作和提交状态 |
| 选择与路径 | 暖金 `#C6A768` 加对比轮廓 | 不只变色；同时显示边界、名称或选中符号 |
| 控件形状 | 小控件约 8–10px、面板约 14–18px、抽屉顶部约 20px | 同类一致，不圆角化地图实际边界 |
| 间距与目标 | 4/8px 基准；触控至少 44×44 CSS px，密集命令优先 48px 高 | 视觉图标小也保留命中区，不靠巨大空白拉长流程 |

以上颜色与尺寸是待验证的起点，不是已达标的对比度或成品证明。地图自然色、国家色、关系状态色分别管理；敌对不能仅依赖红色，信仰不能复用国色误导归属。
半透明只用于少量浮动工具/导航；大面积文字和表单使用近实底。任一像素最多一层实时模糊，低性能档与减少透明度模式改实色。分隔以分组、留白和清楚边界为主，不能让阴影成为唯一识别方式。
字体栈建议 `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；衬线仅用于世界名、地图大地名和少量章节标题。手机正文 16px、按钮 15–16px、辅助说明至少 13px；桌面正文 14–16px。数字使用等宽数字特性，显示单位，缩写能查看原值。
统一原创 SVG 图标的线宽、圆角与光学居中；常驻触控工具有中文标签和可访问名称。支持中文长名、同名实体与合法混合字符；列表可截断，但详情和辅助名称保留完整值。

## 3. 大世界的可读层次

规模统一由 PH03 测量和锁定：16,384 / 65,536 / 262,144 个地理采样或基础地块。65,536 为标准大世界目标，262,144 为扩展目标，均不是当前实测能力或所有设备承诺。行政区、城市、人物、军队数量作为另外的负载参数，地理格不等于县、人口也不逐人建实体。
同一合成世界贯穿编辑、推演、保存、回放和性能检查。较弱设备可降低显示细节、阴影、标签密度与缓存，不可悄悄改变地理、行政结构、人物或规则结果。超限输入明确处理，不加载一半后删实体。

| 观察尺度 | 地图表达 | 默认交互与标注 |
| --- | --- | --- |
| 世界 | 海陆、主山脊、大河、国界 | 国家/主要地理名；点国查看；不铺满基层名称 |
| 国家/大区 | 连续地形、上层行政区、主要城市、交通骨架 | 本国实际层级称谓与首都；缩放保持指下地标 |
| 中层区域 | 真实存在的下级区界、道路、河流、军队聚合 | 层级名与重要城，聚合显示数量并可展开 |
| 基层/城市 | 局部边界、聚落、地形、编辑控制点 | 具体对象、邻接与操作；不突然闪出密集标注 |

按实际制度和职能显示线宽、明暗与虚实；不强迫各国统一省州县。标签有稳定优先级和碰撞避让，小幅移镜不频闪，国家名不压首都名，选中名称不被聚合隐藏。太小的对象可从“此处对象”列表选择，不篡改它的真实面积。
地形图保留适量政治线索；政区图保留可读山河，不把世界刷成平板色块。提供图层、比例尺、方向/坐标、书签、搜索、迷你图与归位。地图全局位图尺寸不等于世界规模，不使用巨幅离屏图片冒充可编辑大世界。
搜索覆盖国家、各层行政区、城市、人物、家族与信仰，结果标明类型/所属/实际层级。定位后可返回之前视角。对象面包屑来自真实父子链，缺失层级不补造；跨国比较用治理职能并保留各自称谓。
战事和人物事件不得自动抢镜头；提示可以主动点选定位。打开详情、返回列表、切换图层均保留镜头、选择和时间状态。回放有明显只读标记，不能响应军令或覆盖源世界。

## 4. 各国制度与自动/手动规划

每国使用独立 `AdministrativeScheme`；“省—州—县”“道—府—县”“州—郡”“直辖市＋县”“城邦/领地”只是示例。允许自定义层级序列、名称、职能和制度规定的例外；系统依靠稳定 ID、顺序与父子关系识别，不从汉字名称推断上下级。
地理地块、行政单位、聚落、主权、政权、实控、家族领地和信仰分布相互独立。首都、各级治所与城市标签独立引用；短期占领不自动重画行政结构。
真实流程：选国家与父级 → 选择/编辑制度 → 选自动或手动 → 预览 → 应用或取消。自动常用项先显示目标数量/面积或人口范围、治所/城市、保留锁定区域；山河、通达等高级约束按需展开，所有参数来自真实规则。
预览显示新旧边界、数量、名称、治所、覆盖与异常，并可定位问题。验证父级覆盖、同层不重叠、无意外空洞、邻接和治所合法；飞地/岛屿/直辖必须依制度明确处理，不能静默删地或跨海造陆路。
手选支持点选、刷选、框选/套索、列表多选及减选；手机不要求修饰键。拆分、合并、改隶、命名、迁治和制度变更均预览影响对象、保留身份、任命/税收/补给/历史引用。锁定后只重算未锁部分；取消无写入，确认原子提交且可恢复。
编辑草稿允许不完整，进入推演前定位必需问题。运行中重划依核心成本/延迟或明确沙盒干预记录事件，不偷改过去。行政树按需展开与虚拟化，但键盘焦点和读屏定位不因回收行丢失。
海陆/地形编辑遵循一笔一个撤销单元；双指进入缩放时取消未完成画笔意图。区分“补新陆地”“保留轮廓重算”“整幅重做”，长计算显示真实阶段、可取消，不以半成品替换旧草稿。

## 5. 人物、家族与信仰要能解释和干预

家族入口来自统治者、城市与事件人物；同一检查器逐层深入，返回原对象与镜头。亲缘图默认展开相关两到三代并提供同步列表；更多代际按需加载，支持找本人、共同祖先、家族分支与历史人物，不把千人树缩成装饰小点。
人物、家族/宗族、王朝/皇室、职务、政权和国家身份分开；同族可跨国。详情只显示真实成员、关系、资产/影响来源、职务及事件。所有未知正式人物继续待核；玩家创作和沙盒生成明确标识，不补造正史。
继承页给出现任、规则、合法候选顺序、逐项入选/排除原因。婚姻、任命、继承、监护/摄政、争位、断嗣等按 PH18—20 实际规则提供可预览动作与结果；取消不修改。图谱和人物头像不能替代身份更替、财产/职位作用与解释。
信仰层显示实际地区群体比例和变化来源，不一键整国改色；人物信仰、人口分布、国家制度立场、文化语言与国籍分别呈现。切图层同时换图例和标题。
信仰页围绕分布、组织/圣地、相关人物、政策与近期变化。创建/编辑原创教义和符号 → 初始群体 → 传播/改宗/制度作用 → 可解释变化 → 保存回放构成闭环；涉及人口必须守恒。共同信仰不自动结盟，不同信仰不自动开战。
代价、受影响人群、作用时间和约束来自权威规则；UI 不另算继承、信仰比例、税收或战损，也不使用随机新闻和假进度维持热闹。无规则支持的动作不显示空入口。

## 6. 三端布局与导航

断点是设计起点，实施按可用宽度、文字大小、输入方式和安全区共同验证，不只识别设备名。普通面板并行查看不加遮罩；专注编辑/阅读可暂时占用更多空间，但应有明确返回。

| 布局 | 默认结构 | 验收约束 |
| --- | --- | --- |
| 宽桌面，初始约 ≥1280 CSS px | 56–64px 可收工具轨、地图、一个 320–380px 上下文检查器；不默认左右全开 | 1440×900 默认观察态地图无遮挡面积目标 ≥70%，普通检查器开启仍 ≥55%；键鼠快捷键均有按钮替代 |
| 中宽/平板横向，初始约 900–1279px | 单侧约 300–340px 或不超过 35% 的检查器，地图与详情并排 | 触控/键鼠/笔可混用；长行不横跨整屏，不能套用手机高抽屉 |
| 手机/平板竖向，初始约 <900px | 一行紧凑顶部控制，最多五个目的地，对象抽屉有收起/半高/阅读态 | 默认观察态地图面积目标 ≥65%；44px 触控目标，安全区与软键盘不遮关键操作 |

面积目标适用于默认字号观察态，不用它压缩大字体用户的信息。短横屏/大字体可切专门阅读视图，保留世界上下文与返回点。
导航初稿：创世为“地图、地形、区划、实体、世界”；推演为“地图、观察、干预、纪事、世界”。“实体/观察”以当前对象提供内容，不变成所有模块总表；“世界”管理存档、分支、设置与返回工坊。PH02 用真实功能样板检验，PH30 统一收尾。旧入口需有迁移映射，不能删原能力。
顶部聚合当前世界/模式、时间运行控制与搜索，避免重复品牌和多行技术说明；存档状态就近、错误可查。选地图国家即查看该国，不再要求下拉框重选。暂停、关闭、返回、撤销位置稳定。

## 7. 触控、反馈与辅助功能

一个抽屉一个主要滚动容器，标题和主要操作固定；长列表提供搜索/筛选/分组或虚拟化。抽屉只在把手区识别拖动，内容区保留原生滚动；列表未到顶不得突然拖关抽屉。地图、笔刷、列表和抽屉手势各自命中，禁止全局阻止原生触控。
按下立即反馈，释放到有效范围才提交；拖离可取消。画笔直接跟手且不加惯性；地图惯性可被新手势立即接管。动画从当前显示位置开始，可中断、可反向；普通显隐不默认弹跳，不为转场锁住输入。异步事务锁与动效互相独立。
核心流程无需 hover、长按、双击、右键或多指；保留显式平移/选择/缩放按钮。危险修改先预览确认，普通导航不反复弹窗。模态确认采用真实 modal/inert、焦点约束与恢复，普通状态提示不拦截地图和底栏。
游戏字体提供 100%/115%/130%/150%；浏览器文字缩放 200% 时仍可操作核心流程。换行/折叠/滚动解决布局，不能重新缩字；地图标签字号可独立调，字号增大不强制铺更多地名。
减少动态：停用镜头飞行、弹性反弹、视差、闪烁与自动抢镜，保留静态选中和即时反馈。减少透明度独立设置，全实色不丢信息。高对比提供明确轮廓；三项读取平台偏好并支持手动覆盖、保存，在不支持媒体查询的环境仍可用。
最终色内部验收目标：普通文字至少 4.5:1，大字与关键非文本边界至少 3:1；用实际成品测量。颜色、音效和振动不能独立承载含义；静音/能力缺失不阻止玩法，不承诺网页在所有平台具备系统触觉。
键盘核心路径完整，Tab 顺序稳定，Esc 返回临时界面，输入框不被快捷键抢字。地图同步提供附近对象列表、选中摘要、命令预览与变化文本；读屏用户不必识别像素地图。输入法、软键盘、旋转、浏览器工具栏伸缩不能丢草稿或遮住确认。
每个关键界面覆盖加载、空态、错误、只读、冲突、取消、恢复和禁用原因。操作成功必须以权威命令与持久化提交为依据；提示变绿不是成功证明。回放/归档不允许透出可写命令。

## 8. 性能、PWA 与真机边界

以下为交互预算起点，由 PH03 具名设备基准锁定，PH33 长局验证；不是现有实测成绩。预算失败先优化，不能删规则、换小夹具、放宽测试制造 PASS。

| 项目 | 初始目标 | 必须留存的证据 |
| --- | --- | --- |
| 连续平移/缩放 | 桌面目标 60 FPS、p95 帧间隔 ≤20ms；移动目标 60、最低持续可操作 30 FPS、p95 ≤33.3ms | 同路径 ≥60秒，分布、长帧、最差场景、设备/浏览器/质量档；不只平均值 |
| 按下与对象反馈 | 本地反馈 p95 ≤100ms；热态对象/面板打开 p95 ≤300ms | 反馈和实际命令完成分测，不能以按钮变亮代替提交 |
| 规则命令 | 基础夹具 p95 ≤500ms；标准大世界目标 ≤2s且界面响应 | Worker 重验、持久化与显示各阶段；长任务有取消/真实阶段 |
| 世界生成 | 初始预算桌面 ≤30s、支持的移动档 ≤60s，可取消 | 实际阶段/已处理量，不跑假百分比；失败保留旧草稿 |
| 长局稳定性 | ≥30分钟观察干预，编辑撤销循环、回放往返 | 无崩溃/持续泄漏/状态失真；内存只用实际可用工具测量，未测不编数 |

分块数据、裁剪、空间索引、LOD、标签避让、静态缓存、增量脏区与消息分别预算。React 不为每块地创建 DOM，不逐帧重建世界；模拟日结不重建全部地形，Worker 不每帧复制完整快照。质量降级保留全部可玩实体与同一规则结果。
PH32 验证安装态网页/PWA：首次联网缓存边界明确；已缓存地图、字体、模拟与回放 Worker 断网可用。Service Worker 更新不混用旧 UI/新核心，不强换运行会话；可先保存、失败恢复。后台挂起/关闭不承诺持续运行；存储配额、浏览器清理和多标签冲突可解释并有导出恢复。
验证分层：桌面 Chromium/Firefox/WebKit；手机和平板移动仿真；真实 iPhone Safari及安装态 PWA、Android Chrome及安装态 PWA、桌面和至少一台平板。WebKit 自动化不是 iPhone 真机，CDP 手势不是真人体验。
PH35 记录型号、系统/浏览器、方向、质量档、温度条件和实际操作；覆盖连续滑动后点选、双指、软键盘、安全区、旋转、切后台、离线重开与温升后持续性能。真实设备或用户视觉未验，保持 pending_acceptance，不能提前上传预览作为例外。

## 10. 最终连续玩法与验收证据

用同一个标准大世界合成夹具及非私人真实存档的手绘样本连续验证，不能每到一个模块就换 demo：

1. 画海岸/山脊，保留轮廓生成地形，从全图到局部确认山河连贯；局部重算与撤销真实有效。
2. 两国采用不同层级及称谓，自动规划后锁定一块上级区，手动拆并/改隶/迁治；再覆盖直辖/城邦例外，原锁定边界和城市不被覆盖。
3. 建立沙盒家族与人物、继承规则及不同原创信仰；观察人口/粮食、身份、信仰、国家关系的真实变化，点事件查原因。
4. 实际经历继承/统治更替及战争/停战等冻结范围中的行为，预览并确认干预；UI 结果与核心事件一致，取消无修改。
5. 保存、关闭、断网重开；只读回放同日多条及后部记录，分支先取消再真实创建并改变决策，证明原史未写。
6. 三端完成地图选择、长列表连续拖动后的点击、弹窗取消、软键盘输入与方向切换；大字体/减少动态/减少透明度/对比模式下核心路径仍可用。

每项记录实际构建/源指纹、固定种子、设备浏览器、输入、权威状态、画面、事件、持久化和检查结果；失败证据保留，修复用独立结果。截图证明画面、仿真证明仿真，不能替代真机和用户视觉验收。
UI 成品不能以页面数量、代码行数或勾选数定义完成。所有新增能力在证据落地前保持未实现/待验收，PH00—35 全部合格后才按 V4 解锁最终打包、推送与唯一 Pages 发布链。

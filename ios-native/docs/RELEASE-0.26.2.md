# 原生版 0.26.2（build 74）

基于 `codex/native-war-editor` 的 `8121fa92`（0.26.1，build 73）。只改 `ios-native/`。不合并，不改网页版。

## 新增
- 省会标记（网页适配）：每省离省心最近的城市画成比普通城更清楚的圆标，国家首都仍是原来的三环。放大后能和普通城、首都分开。尺寸不是原作实测值。
- 显示设置补上原作里已有默认值的几项：航线（开）、暗边（开）、羊皮纸（开）、国名缩放（1.0，滑杆范围 0.5–2，与网页显示滑杆相同）、完整国名（开）。拨动后地图马上变，并写进本机。
- 海色可以在「原作海蓝」和原先的「暖纸海色」之间换。暖纸海色标为网页适配。
- 开场和进入世界改成地图淡入浮现，设置里可以关掉。屏幕上写着「网页适配」。
- 截图行程增加开场、进世界和省会近景。这个 PR 的头分支名字对不上工作流里的自动条件，推送和打开 PR 通常不会跑 `ios-native-unsigned.yml`，需要在 Actions 里对手动运行该工作流（workflow_dispatch）。

## 修改
- 默认海水改为原作显示预设 0：浅海 `#3c9cff`、深海 `#1487ff`、海岸 `#5f5f5f`。导出的海图仍按暖纸色存放，画的时候再换成当前预设，海岸渐变位置不动。
- 行省边界默认关闭。打开后颜色为 `#B2B2B2`，不再用网页的 `#303e37`、透明度 0.2。线宽仍是原先屏幕上约 0.55 点，没有写成原作线宽。
- 国家页打开时只有「基本信息」展开，其余分节收起。展开动画仍是 0.25 秒。纸面、分节和页签都没换一套新样子。
- 开场印章缩短，标题地图大约 1.5 秒浮现，新世界的地图大约 1.8 秒浮现。启动底色改为宣纸色，避免进应用时闪一下白屏。
- 版本号 0.26.2，构建号 74。主页的 iOS 说明改为原生版，不再停在 Capacitor 0.5.x。

## 修复
- 州郡页小标题与地形标签对齐。以前小标题用粗分的平原/森林/山地，标签用实际生物群系，会出现「哥廷根 · 平原」旁边标着「热带雨林」。现在小标题用同一套地形名；山地标记优先写成山地。

## 验证与已知问题
- 在 Linux 上用 Swift 6.0.3 跑过 `ios-native/Core` 全部 84 项单测，0 失败。没有编过 iOS 应用，也没有 iPhone 真机，不能把单测当成手机上已经看过。
- 港口、要塞、圣地：城市数据里没有类型字段，所以没有画这三类图标，也没有编造类型。
- 航线只连接引擎给出的港口，沿海格走，不穿陆地。颜色是 `#868686`。原作序列化里的线宽和虚线没有进这个客户端，所以画成实线，宽度是界面选择。
- 羊皮纸默认打开，是按显示预设 0。原作里序列化开关和预设谁在运行时覆盖，这里没有另作结论，开关旁写了网页适配。
- 开场、进世界、省会圆标的半径、卷轴暗边的具体色，都是网页适配，不是原作开场或原作图标。
- 显示设置换了新的保存键，旧的显示设置不会沿用，这一版用上面的默认值。
- 国名缩放的 0.5–2 是网页显示滑杆的范围，不是新测出来的原作滑杆极限。
- 省界线宽、海岸线宽、海洋由浅到深的距离、标签字号和缩放显隐，这一版没有改成新的原作数值。
- 包 B（国家页改成点进去再看、生成选项、玩家国界加倍、战争卡片文案）和包 C（开局省界笔刷、启动画面还原、完整羊皮纸着色器）没有做。
- 人物面板五节默认全展开没有单独重做；国家页里的「人物」分节本来就是收起的，这一版也没有把它展开。

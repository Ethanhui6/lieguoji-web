# 0.3.0：原作 / 网页版画面

用户反馈 0.2.0「还是没有原作和网页版的感觉」：0.2.0 是通用 iOS 地图应用的样子。本版把网页版已还原的原作纸地图外观整套搬到原生（仍是 Metal + SwiftUI，无网页运行时）。

## 地图（与网页 original-play-renderer + map.ts 同层序、同参数）
- 海：导出与网页 originalSeaTexture 相同的海岸距离纹理（参考纸外观 ORIGINAL_PRESETS[7]，浅 0x8eafb1 → 深 0x527c86，800×450）。
- 陆地：高度灰底 + 国家色 0.78 线性混合；地形视图为原作逐格生态色。
- 原作羊皮纸（sharedassets0 parchmentfinal2，与网页同一审核文件）按 originalParchmentRect 正片叠底覆盖整图。
- 河流：网页 originalRiverGeometry 的河带三角形，参考纸河色 (.38, .69, .74)。
- 山与林：逐形移植 original-relief.ts（山 h≥55、林 22≤h<55 且生态 5–9、不贴海、23 单位一格最多一个），同样的多边形、描边宽度与透明度，地图单位描边随缩放。
- 国界：StateLineRenderer 每国沿共享格边描自己的轮廓，颜色为网页 fmsStateLineColor（AdjustColor），宽 0.25/(240/1600) 地图单位；海岸为平滑海岸线 0x5f5f5f 同宽；省界 0.55 屏幕点 #303e37 透明度 0.2。
- 城市图标：Shapes CityMain（黑圆 + 0.56 白心）与首都 CityCapitalFinal（1.3 / 0.885 / 0.43 三圈），尺寸取 ORIGINAL_CITY_UNIT。

## 文字
- 字体：网页使用的台湾楷体子集（TW-Kai），由 woff2 转为 TrueType 打包（2729 字形，覆盖本世界全部地名）。
- 国名：每国一个 LabelUtility 名框（网页 stateLabelBoxes47 导出），TextMeshPro 自动字号 15–40，黑字 + 国家色描边 0.8，随地图缩放。
- 城市名：64 × 0.13（首都 ×1.5），城上方 0.7 倍处，屏幕小于 9 点不显示；缩放变化超过 25% 时按屏幕字号重新排版，保持清晰。

## 界面（网页游戏布局 + 暖纸色）
- 左上日期胶囊；右上图层 / 菜单 / 存档；左侧竖排工具栏 国家 · 军事 · 历史 · 排行 · 编辑 · AI · 生成；底部播放控制与 1 倍速；左下最新大事卡片；右下放大 / 缩小 / 全图。
- 颜色取网页 culture47.css（--paper #f7f2e4、--ink #2a2b24、--accent #2f5d50 等）；面板为系统底部 sheet，纸色背景、楷体标题、分组行卡片。
- 可用：国家列表（飞到首都）、行省面板、大事记（世界开篇的真实记录）、排行（行省与城市数）、图层切换、菜单（帧时间叠层）。
- 军事、编辑、AI、生成、存档与播放：网页版已有，原生规则重写完成后开放；目前点按会说明。

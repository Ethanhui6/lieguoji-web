# 0.9.17 基线渲染优化

基线 Claude 22912063，最新原生构建 41282831845 成功。旧 PORTING.md 的阶段一描述已过时，以 SWIFT-PORT-STATUS.md 为移植进度依据。已存在 Swift 整日模拟、舰队和港口；未迁移新世界创建后续段，手动舰令尚无 App 按钮。

本批只修改动画显示，不修改模拟、存档和网页。原 rebuildArmies 在每个动画帧按军种重建顶点数组并 makeBuffer；现在仅 setArmies 数据变化时构造 11-float 顶点（原 9-float + 目标坐标），逐帧只上传一个 Float 插值参数。起点仍使用当前显示位置，超过 20 地图单位的重组跳跃保持不插值。

取舍：军队顶点缓冲增大约 22%；换取动画帧不再创建这些数组及缓冲。不同快照使用不同不可变缓冲，不覆盖 GPU 正在使用的内存。已有平滑函数、图标大小、选中颜色与纹理均保持。

新增 CI 对内嵌 Metal 源执行 iphoneos metal 编译，弥补 xcodebuild 不检查运行时字符串着色器的问题。Core 黄金对照仍需通过。没有真机帧率测量；不能据此宣称 120fps 或固定百分比提升。下一步用同一存档测推演中拖动/缩放的帧时间及 GPU 调用，再优化行军接触热点。

## 实际问题与修改

1. 默认生成大陆有 36,864 个采样点、72,962 个三角形。过去的 676 点浏览器样例没有暴露重复几何序列化、深复制、海域映射重建的开销。对已验证私有几何建立精确见证，仅共享递归认证的不可变普通树；typed array 始终逐值比较、私有复制，不能通过对象身份、额外字段或自定义 slice 绕过。几何变更仍触发完整验证，动态军事检查保留。
2. 自动推演在途时，手动一天、保存、返回会等待回执并执行。页面显示实际日内刻度和处理状态。每批最多 12 个真实刻度，暂停/隐藏不积欠；没有跳过模拟来制造日期变化。
3. Worker 终止后，“继续时间”从最后已确认日志重建真实 Worker；不追加失败命令、不冒充已保存。重放期间再次暂停或隐藏会取消自动继续。创建/读取世界的 Worker 终止后也可以重新点按钮。
4. 真实 Codex 侧栏启动曾出现画布 0×0，触发“相机世界和视口尺寸必须是有限正数”，按钮全禁用。编辑器及新旧游戏画面以与渲染器一致的 1×1 最小尺寸启动；ResizeObserver 忽略暂时的零尺寸，实际显示后重新适配。最终侧栏已能打开地图并创建世界。

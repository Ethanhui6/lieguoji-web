## 已实现

- 真实鼠标、单指或笔直接画闭环，自动转入 `shape-landmass` Worker 候选；Q8 点、种子、参数和实现指纹进入实际保存配方。
- 有界连续海岸扰动、依据真实 quad 重心生成的山地起伏与贴岸海床过渡。旧陆地、锁定区域、影响带外海床、几何和归属层保持原样；无效或无可新增陆地的轮廓明确失败。
- 复用实际候选校验、确认保存、取消、会话撤销和刷新恢复。双指加入、失焦、Escape、模式切换、缩放/全图/定位、尺寸变化、GPU 丢失均取消半笔；同尺寸观察通知不打断输入。
- 根据真实高程的连续海陆颜色和四邻坡向光照；实际海陆共享边岸线。近景纹理采用 8×8 显示子核心，地理格式仍为原 32×32 逻辑块；保留 32 Mi 像素及原几何预算。
- 地图常驻浏览/画大陆工具，绘制时收起面板，候选确认位于参数前，局部生成及区域锁折叠。浅深主题、阅读和减少透明设置继续保留。
- 存储来源校验可接受有已核发布证据的历史生成指纹，但不更写历史字节或执行旧配方。新增执行仍必须匹配当前实现；未来未知来源拒绝。

## 实际试玩与限制

内置本地浏览器通过实际输入创建了“山海新卷 · 手绘试玩”：25 点轮廓，9,462 个新增陆地地块、3,311 个近海地块，确认保存至修订 1。实际刷新后地图恢复且控制台 error 为空。它保存在该浏览器的 localhost IndexedDB，不是跟随 Git 的玩家存档，不上传。

新空白海洋仍为原合同的 -100 米；手绘只生成贴岸过渡，远海保持原样。因此本批没有完整海盆/深海地形生成，浅青远海不能描述成完整海洋。当前轮廓边界仍有地理格网感，最终用户视觉验收未通过。测试用 F 型凹湾/长半岛是输入忠实性诊断，不是自然地图美术验收。

水系、气候、国家管理、城市、行政制度、家族和信仰等后继内容未由此批完成；完整 PH08 笔刷也没有提前宣布完成。PH06 仍为 `in_progress`。手机/平板测试是模拟器，真机、用户视觉及完整游戏长局性能继续待验。

旧 9/24 试玩站仍为 90cdabc；旧云端 CI 的 153/156 浏览器失败保留，过时地址断言仅在本地修正。此轮没有推送、触发预览、改 main 或新建部署链。

## 可审查的实际运行时改动

只有三份可提升运行时，均在 `ready/source/src/world/generation/`：

- `detail-natural-relief.ts`：仅显式 `heightPlanning: 'fine-world'` 进入脊树。未设开关的 world 和 local 保留旧分支。海侧高程、海岸门控和 Hbase 读法不变。
- `detail-orography.ts`：独立 `fine-tree` 截面，节点自带左右山脚范围与低肩份额；节点峰/鞍高程沿真曲线插值，支臂从实际父支持高程接出。旧模式仍有原来的 3 链/17 记录限制与数值路径。
- **新增** `fine-range-tree.ts`：固定 32-world 陆地规划格，内陆余量与种子隆起场决定主路径/分支候选；正代价八邻域寻路、禁止斜穿海角，受占用路径限制的侧臂。简化后最多 7 主控制点、4 个最多 3 控制点的支臂，允许较早支臂成为父脊。真实曲线仍通过现有 `isLand` 探针，不把规划格当成岸线。

fine-world 不再进入旧 `bendKnots` 的固定先正后负模板。384-world 的种子隆起场共同影响实际路径代价、侧臂目的地与实际峰高，不是 shader 装饰。左右肩来自真实陆地规划余量；较窄峰脊和低肩都参与实际 `physicalHeight`。这仍是有限地貌模型，不是水蚀或完整构造地貌。

直接运行时闭包共五文件：三份候选，加 `src/world/generation/seed.ts`、`src/world/generation/detail-curved-ridge.ts`。`DetailShapeControl` 是 type-only，不进入运行时闭包。manifest 另列 natural/add-natural/local 三入口的静态传递名单，分别 28/28/27 文件。

## 显式预算与内存

- 保留支持 **4096**、单点候选 **192**、索引引用 **262144**、曲线真陆地探针 **131072**。fine 继续 32-world 桶，最多 16384 个桶槽；legacy/local 仍 64-world 桶，4096 槽。桶数组对象/临时 JS 数组并非零开销。
- 新结构独立限制 **5 链 / 19 anchor records / 15 唯一点 / 14 曲段**。旧常量 3/17 不变；树的父支持扫描为最多 4 次 × 4096，旧最多 2 次 × 4096，这项额外工作明确区分，不称所有预算完全不变。
- 新规划最多 16384 次 isLand 格点查询、7 次寻路、458752 次边检查、16777216 次堆比较、589824 次侧臂候选检查。八邻域仍保持原边检查上限；极端搜索可能显式拒绝，不暗中提高预算。
- 新 typed working arrays 为 **376832 bytes**；另有有界路径/候选/节点 JS 数组。该数不是整个 JS 堆峰值承诺。主例实际 6 次寻路、81392 边检查、138062 堆比较、84544 候选检查、最大堆 290。

## 尚未覆盖和提升注意

- 未验证 GPU 中远近景、视觉自然感、三端性能、真机。现有 sample 表明真实谷/鞍/弯支臂成立，不证明用户要的整体山块外观已达成。
- 本轮 writer/codec 是真实内核与二进制 tile 往返，不是 Worker/IndexedDB/浏览器刷新存档闭环。追加旧陆块、锁区、多标签、新旧存档保护需生产受影响范围回归。
- 当前占用规划路径避免明显支臂重复，但没有单独的全曲线几何相交审计；简化/Hermite 后任意输入不存在非父子交叉尚未证明。复杂多块不相连陆地未做按连通分量规划；极端样本可空规划/受预算拒绝。一个 seed 的 3 条弯臂不承诺所有支臂必弯。
- 这是生成器行为变化，fine-world 已设开关的新生成会改变。保存过的细高程不应重解释。旧实际生成闭包、recipe/history 保留；主线提升时须冻结旧实际来源、让新 module 加入 natural/add/local 的真实传递闭包，再绑定新的 generator 身份。`branching-orography-v4` 仍是现有结构摘要字符串，不把它当成新完整生成身份。
- 提升候选测试时应移除写 `.autopilot` 的测量副作用，并调整 import 到生产；不可把 `ready/postcheck-dependencies` 或整个 staging 搬进 bundle。独立旧 oracle 继续留测试 fixture。统一生产检查可使用这份候选作为差异来源，不能把本轮 27 项替代生产集成验收。

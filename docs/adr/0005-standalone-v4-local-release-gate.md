# ADR 0005：完整独立 PWA 与全 PH 后统一发布

日期：2026-09-23。状态：用户最新指令已采纳；产品扩展尚未实现。

用户指出现有地图太小、不够精细，行政层级、家族与信仰深度不足，UI 不满意；明确希望大世界、可自动和手动规划、不同国家采用不同制度，以及具有 iOS 质感的完整独立游戏。交付形态已确认网页/PWA，并要求全部阶段完成验收后才打包上传 GitHub／Cloudflare。

沿用现有 0.4 基线与 TypeScript/React/PixiJS/Worker/IndexedDB；不从头搭新项目，也不把 PWA 换成未经选择的 Windows 壳。V4 将地理、模拟单元、行政树、城市、国家政权、人物家族与信仰分离，以可测规模档替代盲目提高640常量。旧引擎冻结与真实指纹分派是新规则硬前置。

新增 PH00—PH35、144 个子项，唯一状态源仍为 plan/tasks.json；旧25任务及证据原样保留。旧 M4 皇室范围映射 PH18—20；新沙盒 PWA 有独立路线，不能把正式地图/长征未知项偷偷标完成。新版首发只包含原创自建沙盒及原创挑战，正式内容仍等待核定。

冻结全部新云端写入，尤其非 main 分支也会触发 Pages 预览。本地开发、测试构建和本地提交继续允许。添加项目范围的检查与 pre-push 防误操作，不宣称这是云端强制保护。现站保留，唯一原生 Git 部署链不变。

本地 PH35 与真实设备/视觉验收通过后才允许首次候选上传；上传后的 CI/HTTPS/生产核验独立记入 releaseVerification。这样既不提前发布，也不会形成“必须先上线才准上线”的循环条件。

V4 覆盖 V3 与早期部署 ADR 中冲突的发布节奏。历史 ADR 作为当时决策与证据保留，不按现状重写。实施和门禁细节见 CODEX_AUTOPILOT_V4.md、docs/PH_ROADMAP_V4.md、docs/RELEASE_POLICY_V4.md。

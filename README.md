# 列国纪

原创二维架空世界模拟网页游戏。手画海陆、生成地形、创建国家与城市，再观察人口、粮食和列国关系如何影响世界推演。0.4.0 开发版增加历史记录、只读回放与独立分支，发布验收状态以 [交接记录](docs/AUTO_HANDOFF.md) 为准。正式五国地图仍未提供、未核定；玩家自由创作不依赖正式核图。

实际游玩地址：[列国纪 · 世界工坊](https://lieguoji-web.pages.dev/)。源码位于本人私有仓库 [Ethanhui6/lieguoji-web](https://github.com/Ethanhui6/lieguoji-web)。Pages 原生 Git 为唯一发布链：通过检查后合并 main 自动生产，其他分支自动预览。发布、CI 与线上验收见 [M3 经营与外交证据](docs/evidence/2026-09-23-statecraft.md)，早期工程发布见 [云端证据](docs/evidence/2026-09-23-cloud.md)。

Node 24.18.1，npm 锁文件安装：`npm ci`。启动：`npm run dev`。完整本地检查：`npm run check`（首次需 `npx playwright install chromium`）。Pages 构建：`npm run build:cf`，仅发布 `dist`。

工坊操作：在现有大陆上编辑，或从「世界草稿 → 空白海洋」开始；使用海陆/地形笔刷，或按种子生成；手动建国并涂抹归属，或自动分国；点选城市与首都，或自动安排；保存草稿，然后开始推演。每完整一笔可撤销/重做。手机和平板通过底部画笔、国家、城市、世界面板操作；双指用于缩放，平移工具用于移动视图。

自建世界使用真实相邻地区、地形、补给和战斗规则。新世界从和平开始；国家簿可查看人口、粮库、下一日预计需求和最近实际日账，调整民生/均衡/军事政策，预览并确认宣战或停战。军队补给实际扣除驻地粮食，其他省区的库存不会凭空运来。缺粮影响人口与部队；交战、追击和占领受双边关系约束，停战后部队沿真实路线撤离。自主宣战需要满足观察日数、粮食、实力和接壤条件，并保留原因。

也可暂停并干预任一军队：选择 → 预览 → 确认 → 推进日期 → 查看原因 → 保存。国家行动预览会暂停推演，局势改变后过期预览不能确认。桌面从右侧切换军令/国家，手机和平板从底栏打开国家簿。尚无跨省运输、贸易、海军、外交谈判或皇室模拟；相隔海洋的地区不会凭空通路。

在自建推演中打开「纪事 → 历史」，确认创建记录副本。它从当前日期开始，原局不改，过去未记录的日子不会补造。每次成功推进或命令单独编号，并自动保存世界与完整记录。进入回放后可按序号/日期定位、播放暂停、查看当时地图和国家账册；回放不能下令或保存覆盖原局。选择某条记录并确认「从此处创建分支」，即可在独立世界中尝试不同决策。

完整历史导出为 `.history.json`。在纪事中导入后以只读归档打开，继续推演须创建分支；导入不会重写原包身份或 hash。单条历史最多 2048 次输入 / 20 MiB，整个历史库主档与备份合计最多 200 MiB，浏览器实际空间可能更少。写入失败会暂停并保留最近完整记录。不同规则实现指纹禁止直接回放，仍可保留并导出原记录；详细约束见 [ADR 0004](docs/adr/0004-history-replay.md)。

草稿、每一次推演、旧五国测试大陆分别存于 IndexedDB。新推演分配独立身份，回到工坊后可继续最近推演或选择已保存历史。草稿导出为 `.world.json`；推演导出为 `.save.json`；在工坊导入推演会建立独立历史，不覆盖原局。不同网址互不共享存储，跨网址需要导入导出。旧固定战役入口为 `/?demo=1` 或 `/campaign/test`，继续作为规则回归样例。

新世界采用规则 0.2.0；旧 0.1.0 存档继续原规则，不自动升级。旧自建局的国家面板提供「创建经营推演副本」：确认后保留当前日期、地图、军队与事件，初始化新经营账册并沿用旧局敌对关系，在新数据库中继续；原历史保留。人口与粮食初始值是沙盒规则参数，不是正式历史统计。

当前编辑精度为 640 个确定性 Voronoi 地理单元；画笔改变真实海陆与归属。采用连续噪声生成连贯地形及严格下坡河流，国家按陆地连通关系扩张。它是可玩的创世基础版，尚非最终地图精度或完整产品。

# 世界工坊 0.2.0 本地验收

日期：2026-09-23（Asia/Hong_Kong）。范围：M2-001/002/003 自由创世基础版；不代表正式五国地图、完整产品或云端发布通过。原 v2 规划包仍未取得。

## 功能与实际检查

- 640 个确定性 Voronoi 单元，空白海洋或按种子生成大陆；连续笔刷绘制/擦除海陆与地形；每完整一笔一次撤销/重做。自动地形保留既有陆地掩码，河流沿严格下降的高程连线。
- 手工建国、命名、颜色与疆域；自动陆地分国；补全未归属地区保留既有手工领土，并为无领土新国家从空地分配起点。国家可有不相连岛屿，岛屿间不生成跨海邻接。
- 手动城市和首都、自动城池首都、有效本国陆地与唯一首都校验。编译前不足项列明，不能用缺失首都的地图直接开局。
- 自建草稿编译成真实 World 进入现有 Worker。各国军队依据补给、兵力、地形和边境选择基础调动、进攻、休整、防御；玩家可暂停干预，既有行军路线不会被AI覆盖。完整外交、国家经济、皇室仍未实现。
- 草稿/每次推演/旧测试战役使用独立数据库；SHA256、有效备份、三层草稿版本锁写、revision和主槽CAS、操作期间编辑锁。跨世界运行档导入须通过工坊创建独立run；缺失run链接显示错误，不生成测试战役替代。

## 已修缺陷与限制

首次真实链路发现：空白手画后仅创建国家，补全领土未为新国家分配起点，导致自动城市为0。现已修复并补单测与三端E2E，未通过修改验收来掩盖。

自建缺档URL曾可能生成默认战役，跨run导入曾可混入其他世界，异步保存期间编辑曾有丢失窗口；均已加入明确拒绝或原子操作保护。工坊未来Workspace/Draft版本也在外层版本之外锁写。

这是640单元精度的编辑器，尚无自由曲线高精海岸、完整外交/经济、海运、皇室、回放、PWA；不把本地单次性能测量当作低端真机长局验收。正式核图和真机仍待验。

GitHub CLI设备授权、真实远端CI与Cloudflare Pages持续部署未接通；只打开本机生产预览，不存在已验证公网HTTPS URL。Cloudflare控制台登录成功，尚未创建本项目Pages。发布时只使用经过检查的dist。

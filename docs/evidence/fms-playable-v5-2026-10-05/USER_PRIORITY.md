# 用户调整本地开发优先级 · 2026-10-05

用户本轮原话：“现在进度太慢了 我想体验游戏了 但是还是个半成品 能不能先做出来关键的功能内容 然后后续再慢慢优化”。

据此先交付同一张 FMS 地图上的可玩核心：真实陆地区划、自动国家／首都／城市、时间与自主推演、可预览确认的外交和军令、交战／撤退／占领与原因、独立保存恢复。继续复用现有模拟规则，不重新编造原作等价声明。

这是本地开发顺序例外。允许 WEB-PH03 的国家基础和 WEB-PH04 的核心推演先行；WEB-PH02 与 PH03 完整体验保持未完成，真机与用户视觉验收记录不改，后续复杂行政、家族、信仰不在本批。PH04 子项仍显式依赖国家基础子项。

云端发布规则、旧阶段历史、pre-push、Pages 唯一链完全不变。本次不 push、不上传、不创建远程任务、不触发 Pages。移动浏览器仿真仅记录实际检查，不能替代 iPhone 真机或用户视觉验收。

# 原生版 0.26.6（build 78）

基于 0.26.5。只改 `ios-native/`。开场仍是「注水成海」。亡国仍在失去最后一块实控领土时清除残军。不合并。

## 新增
- 无。

## 修改
- 府城圆标从城镇的 1.28 倍改为 1.7 倍。国家首都外环仍是城镇的 1.95 倍，三环不变。普通城仍是原来的双环。府城名字略放大，仍小于首都名字。这是显示尺寸（网页适配），不是新的城市类型。
- 文化、宗教、迁都、驻地、割让州郡这些长列表，点开后是宣纸名单，点一行选定。不再弹出系统菜单。
- 州郡页的围城进度改成与战争分数同一条墨条，数值仍是原来的进度。

## 修复
- 无。

## 验证与已知问题
- 自绘地图在划分州郡之后不能改都城。网页开局编辑器里有「设为首都」，规则是只在本国境内把都城挪到另一州。手机开辟天下只把高度图交给生成接口，选定的都城传不进去。这次没有在预览上先挪都城，避免开辟之后又回到自动都城。
- 船舶大师、改革家、雪原、沙漠、高度图三档，仍与 0.26.5 相同：没有造船队列，也不放生成接口不接收的空开关。
- 宣战理由和战争目标没有再加句子。目录里的六条国际理由和已恢复的目标原文，0.26.5 已经写上。
- 导出存档仍走系统分享，导入仍走系统文件选择。加载中的转圈仍是系统指示。纸面滑杆里面仍是原来的滑块。
- 开场、亡国清军、海色、显示设置、国家页下钻，仍是 0.26.2 至 0.26.5 的行为。

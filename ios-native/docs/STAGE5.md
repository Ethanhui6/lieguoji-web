# 0.5.0：月度结算（月税与国运）

## 本版移植（Swift，逐位对照网页）
- `Monthly.swift`：
  - 浮点/整数仿真：每个 Math.fround 用 float32 舍入、`|0` 按 Int32 回绕、Unity RoundToInt 银行家舍入，表达式顺序与 TypeScript 相同。
  - 月税：Province.GetEcnomicPerMonth（人口千分之一 + 资源（人口利用率、民族加成 1.2、人口密度 0.5–2）× 国运系数 × 大国规模折减 × 地方官倍率）与 State.UpdateEcnomic（领袖税率 × 中央官员倍率、高库存衰减 5/15/25 倍档、赤字下限、财政战力倍率、军费）。
  - 国运：月度下降（下降率 × 人口比、赤字加速、领袖行政减缓）、低于阈值重抽（天命眷顾 70–89 / 普通 10–89 与新下降率），使用网页同一条线性同余随机流。
- 金样：`monthly-golden.test.ts` 让网页引擎真实推进 12 个月，每个月结记录 8 国全部输入与结果；`MonthlyTests` 逐国逐月比对国库、月入、财政战力倍率、国运、下降率、重抽余量与随机种子。
- 接入每日流程：粮食 → 原作军队重置 → 每 30 日月税 → 国运（与 settleCivilizationDay47 顺序一致）。

## 界面
- 国家列表显示国库与国运；大事记在每月结算后显示各国月税（入账、国库、财政战力倍率、国运）。

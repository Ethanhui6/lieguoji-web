# 原生版 0.26.9（build 81）

基于 0.26.8。只改 `ios-native/`。开场、宣纸界面、亡国清军没有改。不合并。

## 新增
- 无。

## 修改
- 应用规则下的自主军令：常规目标只含已被敌军进入的本省，以及边境上的敌省。两者交给原来的距离打分一起比，不再规定必须先回援，也不再把盟国境内的敌人、所有沿海敌省塞进名单。这份边境名单仍是现有的国界读取（网页适配），不是原作 `borderRegularEnemyProvinces` 的完整分类。
- 没有这类目标时就地待命，并停掉还在走的行军。不再抽驻防点，也不强制撤回故乡。

## 修复
- 行军目标还在、但脚下这一省已经有敌军时，改为以本省为目标并停止行军。原先只有本省归属敌国才停。脚下有敌军用的是「省里站着敌方军队」（简化），这套数据里没有单独的战斗编号。玩家手动军令不改。

## 验证与已知问题
- 原作里野战军走常规目标、驻军优先找叛省。现在的军队只有常备和应急两种，没有驻军类型，所以没有接上叛军优先。应急军不假装成驻军。
- 原作目标打分用的地块特征和突出、港口，仍是现有的近似输入，没有把整个打分改写成原作公式。
- 网页对照样本仍走原来的候选名单，所以和网页军令记录保持一致。手机上开启应用规则的世界用上面的名单。
- 亡国清军、开场、宣纸界面仍是之前各版的行为。

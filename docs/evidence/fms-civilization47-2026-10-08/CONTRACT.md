# WEB-03-06：实际文化创建与名称事务切片

本批三个范围：独立真实文化/宗教目录与双模式；文化/政体国号和人物职位；直接建立真实辖区世界、开局任次和人物，并支持候选事务内的名称/制度修改。

## 已实现的数据流

`FmsDocument → settlementRegions → 首都及真实连通辖区分配 → civilization47名称账 → World国家/城市/地区 → Chronicle开局任次 → initialPeopleAndLife22人物与生日`。

不先走旧六文化建局再全世界改名。源地形不修改；坏参数、无陆地、历史名称容量用尽会抛错。这里返回私有创建候选，军队由后续真实征募统一建立，当前允许空军队。原 `validateWorld` 最少一支军队的冻结合同保持；新 `validateCivilizationWorld47` 保留原字段白名单、几何、引用、上限及治理验证，明确将军队数量下限设为零。它不是完整新规则存档验证器。

`Civilization47` 独立保存文化、宗教、政体、模式、来源键、基础名和自定义覆盖。名称账可以JSON往返；这还不是IndexedDB保存、Worker刷新或多标签存档CAS验收。

编辑入口先验证真实世界、文化账和必传史书，核对 `expectedRevision`，再克隆整个候选。改政体/宗教同步当前国号；改城市名同步对应地区。自动全称不被识别成手动改名。玩家覆盖名一直保留，明确置null才恢复自动名称。历史事件、登基称号、人物能力、生日原样保留。未知/继承对象键、未来字段、负版本、溢出、过期确认均拒绝。

人物来源严格回查目录，继承家族使用最终家族索引，避免源键和实际名字不一致。当前称号由当前制度派生，登基称号依保存的当时制度验证。城市被占领不会静默重抽原文化与名称。

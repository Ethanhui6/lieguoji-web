# ADR 0016：独立于行政与模拟采样的细海岸场

日期：2026-09-27。

状态：合同已确定，独立内核已实现并完成定向核验。尚未接入创世入口、生成 Worker、持久化或实际地图渲染；不能据此声称第四版世界可玩或 PH06 完成。

## 要解决的实际问题

第三版 `land-mask-fan-v1` 修正了显示、海陆拾取和面积不一致，但每个原地理单元仍只有一个海陆符号。绘制的轮廓和连续距离被压缩成中心的正负值，单元之间的小海湾和半岛会丢失。增加纹理分辨率只能提高已有直段的清晰度，不能恢复这些地理细节。

下一步固定采用真正的细采样地理数据，不再增加仅供显示的平滑曲线。细地理场、原粗地理单元、行政归属、模拟区及显示缓存继续分离。国家和行政区未来绑定真实地理位置，不能依赖贴图像素。

## 固定合同

- 新世界格式为 Atlas v4，地表合同为 `sparse-coast-field-v1`。旧 v1/v2/v3 的身份、数据库和地表含义不变。第一阶段只提供明确的新建 v4；旧版重采样副本另行实现并说明形状/面积差异，不静默迁移。
- 世界仍为 4096×4096 世界单位，坐标 Q8。细网格间隔 2 世界单位，共 2048×2048 个细格；它不把行政区、城市或军队数增加到这个数量。
- 32×32 细格构成一个数据 tile，逻辑目录为 64×64；键为 `coast:bx:by`。与旧四层 `blockRefs` 分开登记、分别编码和哈希。
- 节点采用左上 tile 唯一所有权：tile 持有其右/下 32×32 节点；第零列/行另外持有世界边界。节点数量只能为 1024、1056 或 1089。共享边不能保存两份可能分歧的权威值。
- 稀疏目录中缺失的 tile 明确定义为全海覆盖值 -32767；全陆 tile 明确记录 +32767；沿岸/需要细地形的 tile 保存 `Int16Array coverageQ` 和 `Int16Array elevationMeters`。
- `coverageQ` 保存夹到 ±32767 的真实有符号 Q8 距离，不只是正负标记。uniform/缺失节点的高度从粗连续高程采样，并按类别限制为陆地 ≥0、海洋 ≤-1；sampled 节点保存实际整米高程。
- 生成影响带必须延伸至距离夹限且高度回接粗场的位置，不能在 tile 边缘将小幅负距离突然替换为缺省值而挪动岸线。后续山地/海床修改必须同步更新或保留细场的真实高度与锁，不能遗失整层。

## 同一套几何解释

每个细格固定沿西北—东南对角拆成两个三角片，按真实覆盖零线裁切。异号交点按 Q8 在原轴向/45°边上量化，保持在边内部；同一个量化交点供两侧使用。渲染、点拾取、海陆面积和岸线都使用这些实际裁切片。不能用未量化的零线做另一套拾取。零线归陆，零面积线不加入面积。

世界面积累计细格三角片，保留整数面积守恒。uniform tile 只有在其共享节点依赖也满足同类条件时才能整体计面积；不能跳过来自相邻 tile 的混合边。

细海岸按自己的 tile/视口绘制，不能先裁到旧任意四边形再分别舍入。点选先用旧四边形确定行政/编辑归属，再用细格确定该坐标的真实海陆与高度。需要对旧四边形锁区进行保护时，保守保护全部与其相交的细格；界面要说明它包含一层细格保护边带（细格轴向尺寸 2 世界单位，任意斜边外侧的最远距离不超过 2√2 世界单位），不能泛称几何距离最多 2。锁检查与持久化校验均比较实际数据，不能只检查粗中心正负号。

## 必须接通的完整路径

1. 独立 core：严格 tile 编解码/哈希、唯一 owner 读写、真实裁切与拾取、面积累计、四边形相交细格、合作式验证和取消。孤立 core 的单元通过只代表该范围。
2. 新版持久化与传输：独立 v4 域；manifest refs、实际内容、原子主备、容量和 CAS 全部计入细场；Worker 分片 ≤512 KiB；对象接管、取消、未知字段/未来版本保护均不得退化。
3. 新手绘生成：保留旧 `shape-landmass@1` 的执行输出和历史；新生成器明确注册自己的版本/源码指纹，保存轮廓、种子与参数，输出真实细场。宏观、山地、海床等操作逐项接入，并对尚不支持的真实操作给明确说明，不能让按钮悄悄丢掉细场。
4. 新地图渲染与交互：真实细片、拾取、锁、撤销、确认保存、刷新恢复一致。远中近缓存继续遵守原像素/几何资源预算，不为细场移除性能门。显示简化要有误差界，不能改变权威岸线或世界数据。
5. 完成新格式的真实浏览器手绘→预览→确认→刷新闭环与性能/取消验收，保留旧格式回归；然后按 PH 依赖继续地理与国家/行政/城市/军队工作。

这份合同不能替代上述实现与用户视觉验收。`plan/tasks.json` 的 PH06-T3/T4 状态继续为进行中，全 PH 发布门保持。

## 首次内核实测暴露的接入约束

独立内核检查期间，本机密集 4096 个 sampled tile（4,198,401 节点、16,793,604 数组字节）的拥有权接管在首个 `await` 前耗时 483.73 ms，全程 494.88 ms；16 个稀疏 tile 为 1.96 ms。这里记录真实观察值，没有把它设为会随机器速度变化的单元通过阈值。

因此完整密集场不能用当前公开克隆入口一次搬到 UI 主线程。仅放进 Worker 也不能自动宣称满足 250 ms 进度和 500 ms 取消门：Worker 长时间不让出事件循环同样可能延迟取消。后续接入必须利用分片解码时已经获得的私有数据拥有权，逐片核验、报告进度和检查取消；已拥有内容的内部路径不得暴露为调用者可选的“跳过验证”开关。公开不可信文档入口继续保持独立缓冲区和完整验证。旧预算不因本轮测量而放宽。

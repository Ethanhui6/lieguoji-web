## 1 崩溃：家族页（族谱）

复现方式
- 本机探针 `famBase.exe w/m3.json 30`、`w/m4.json 30`（两个 1800 天后的固定世界）：逐家族读族谱共 5924 次、随机婚配/添丁/处死 2468 次，并逐国、逐州、逐军调用国家/外交/贸易/财政/史/政体/官职/州郡/军队/大事记/统计接口。旧代码**未崩溃、解码失败 0**。即正常推演数据下引擎侧不触发闪退；真机闪退堆栈仍缺（见待办）。

已证实可闪退的路径与根因
1. App：`NumberEditSheet` 接受任意 `Double(text)`，`1e20`、`nan`、`inf` 交给调用方 `Int(v)` 直接陷入（族谱「设定年龄」、国家数值、舰船数都走这里）；`format` 对超大数也会 `Int(v)` 陷入。
2. 引擎：`familyTree` / `personView` 对人物记录强制取值（`isAlive.asBool`、`memberIds.asArray`、成员 `asInt`、特质 `asString`），旧档、手改存档或半途中断留下的异常记录会 `fatalError`。
3. App：详情查询不校验世界归属，请求返回前读档/换世界会把旧世界的人物 ID 交给新世界的操作；失败时页面永远停在「载入……」。
4. 功能缺陷：「设定年龄」只改 age 不改生年，次月被按生年改回。

修改入口
- `Core/Sources/LieguojiCore/FamilyTreeView.swift`（新）：族谱解码（逐项宽容、去重）、按血缘分代（迭代、防环、自为父母视同无父母），App 与测试共用。
- `Trade.swift` `familyTree`、`NationInfo.swift` `personView`：全部改为容错读取。
- `Custom.swift` `renamePerson`：设定年龄同时移动生年。
- `App/NationLedgers.swift` `FamilyTreeSheet`：载入中/失败（原因+重试）/空谱三态；请求序号只采用最后一次结果；操作执行中不接受连点。
- `App/GameModel.swift` `query`：详情查询按 `worldEpoch` 丢弃换世界前的结果。
- `App/PaperUI.swift` `PanelPending`：国家、外交、财政、贸易页的失败+重试占位。
- `App/NationEditors.swift` `NumberEditSheet`：只接受有限、在显式范围内、绝对值 ≤ 1e12 的数，并写明原因。
- `App/ShotTour.swift`：巡游从国家页世家进入族谱，换四国连续开合，留图 `11g-family-tree`。

回归测试（`FamilyTreeTests`）
- 异常记录（缺 isAlive、特质混数字、roles 非数组、年龄 NaN、父亲 ID 类型错、自为配偶、成员表混入字符串/不存在/重复/空 ID、家主 ID 非数、成员表不是数组、家族不存在）。
- 每个家族都能出谱、成员 ID 唯一；连续读 100 次世界不变；婚配、添丁、处死后族谱随之变化；已故者再处死给出原因。
- 解码宽容（坏项略去、重复只留一位、技能长度不符取默认、空对象）。
- 分代：亲缘成环、自为父亲、父缺按母、一万代单传、三千人十代大家族。
- 设定年龄经 70 天按月重算后不变。

## 2 性能与缩放（第一批结构修正，1.17.0）

- 根因（割裂）：地图由 Metal 以 `setNeedsDisplay` 异步呈现，国名/兵力字/特效是 UIKit 图层、在当前事务立即提交，两者差约一帧。修改：`MTKView.presentsWithTransaction = true`，`draw` 中提交后 `waitUntilScheduled` 再 `drawable.present()`，同一次相机变更的各层同帧上屏（`Render/MapView.swift` build、`Render/MapRenderer.swift` draw 末尾）。
- 已核对：双指缩放锚点在钳制缩放比之后计算（`MapCamera.zoomed`），到达缩放边界不漂移；手势→`set(camera)`→各叠加层同步更新→`setNeedsDisplay`，相机状态单一来源 `renderer.camera`。
- 待测（需真机）：同一固定存档、同一操作流程三次以上的帧间隔 p95/p99、最长停顿、>50ms 次数、CPU/GPU、内存与 10–15 分钟发热。现有 HitchMeter 计的是主线程 CADisplayLink 回调间隔，不是 GPU 呈现间隔，报告时需标明。引擎每日耗时见 1.16.0 本机基准（200 州 90 ms/日，140 州 52 ms/日）。

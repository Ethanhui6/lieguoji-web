# 原生版 0.26.5（build 77）

基于 0.26.4。只改 `ios-native/`。开场仍是「注水成海」。亡国仍在失去最后一块实控领土时清除残军。宣纸控件没有换成系统开关。不合并。

## 新增
- 国家页增加「人物」「战争」「外交」三行。点进去是下一页，返回回到国家页。国家页默认高度约为屏幕的 38%，地图留在六成以上。基本信息仍然打开就展开，其余分节不改成全部收起。
- 人物页标题为「人物」。五节默认展开：君主、继承人、行政首脑、财政主管、常备军统帅。有总督或战时统帅时，用同样的分节再展开。这五节用的是现有身份，没有另起一套栏名。

## 修改
- 正在查看的国家，以及选中州郡所属的国家，国界线宽为普通国界的两倍。两国是同一个时只加粗一次。这套应用没有玩家国家字段，所以加粗的是当前打开的国家，不是另存的一个玩家国（网页适配）。
- 战争页上的目标文句补齐已恢复的原文：独立、推翻统治、改革政体、夺取王位、迫使目标改信本国宗教。原先只有索取、占领、吞并全境、附庸、索取赔款。
- 新世界里原来的文化勾选标明为「文化集」。宗教仍由所选文化决定，没有单独的宗教集开关。

## 修复
- 无。

## 验证与已知问题
- 国际宣战理由以目录实际登记的六条为准：领土征服、吞并、霸权臣服、文化统一、强制改宗、空白开拓（编号 1、2、3、6、7、8）。编号 4 和 5 没有登记。「宿怨报复」「劫掠」是本地化里没用进宣战列表的遗留词，没有当成第七条或第八条加进去。
- 结束原文是四句：达成目标、战局已定、对方崩溃、久战厌兵，另有首都沦陷。进行中的战争卡不写还没发生的结束原因。没有新写和平公式常数。
- 船舶大师的原文是军舰建造时间减半。手机这场推演没有造船队列，Swift 海军也没有按月造船，所以没有假装乘上 0.5。改革家两边都没有可执行的改革结算，只保留原来的说明文字。
- 雪原、沙漠、战争规则的新游戏偏好、高度图二万／三万／四万格，生成接口都不接收。高度图固定二万格（简化）。没有放空开关。高度图三档的本地化原文不在这版仓库里，所以没有自拟三档名称。
- 开场、亡国清军、海色、府城、显示设置、州郡地形标题、宣纸控件，仍是 0.26.2 至 0.26.4 的行为。

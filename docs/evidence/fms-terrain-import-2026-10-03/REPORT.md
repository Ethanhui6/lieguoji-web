# 原算法研究地形接入独立地图草稿

2026-10-03，`0.5.0-preview.32`，仅本地开发和验证。全 PH 发布门保持锁定。

## 实际交付范围

世界草稿中新增“导入研究地形 JSON”。读取本地研究页导出的 `fms-terrain-research v2`，在独立 Worker 中核验文件、节点、高程摘要与完整 Delaunay 三角网，再显示可缩放的地图预览。取消不写 IndexedDB；确认后以全新 Atlas v4 身份保存，原草稿和原历史不变。新地图沿用现有编辑与独立建国入口。

输入上限 12 MiB、50,000 点、100,000 三角形；计算有工作量上限和取消处理。输入/输出按 512 KiB 分包并确认接收；主线程独立复核文档摘要。持久化使用现有原子事务与 `expectedRoot:null`，确认回执丢失时查询原命令结果，不另起一次写入。

来源记录可以单独下载，包含源文件 SHA256、点网/高程摘要、转换约定、目标身份和真实保存回执。来源记录未扩展旧存档格式；刷新后该会话的下载入口消失，已保存地图仍可恢复。

## 地理转换的真实含义

- 本次实包样本来自恢复的原高度生成器 `archipelago` 模板、种子 `421730`，配合明确的网页测试 Delaunay 点网：24,576 点、48,514 三角形。并未恢复原 Unity 邻接。
- 输入矩形 1536×1024 等比居中映射到 4096×4096 世界，矩形外填海。高程采用真实三角形重心插值；`100×(相对高程−20)` 米是网页转换约定，不是原作测绘数据。
- 基础编辑规模 16,384 地块；4,096 个细地形块、4,198,401 个采样节点全部来自采样结果。细海岸覆盖值采用到量化海岸线的真实有符号距离，避免把高度值误当距离。海岸精度与模拟地块分离。
- 导入地图 `origin:null`、`generation.lastApplied:null`。不套用旧生成器指纹，不伪装成已有历史命令，不自动带入国家、城市、军队、家族或信仰。

独立数值验证检查全部采样节点的海陆/高程符号，并对 80 个位置另行遍历源三角形计算高程，误差不超过整米量化。最终样本范围 −2000 至 6478 米。详细结果见 `actual-source-verification.json`。这不等于用户对自然地貌的视觉验收。

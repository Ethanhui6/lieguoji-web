# ADR 0021：连续曲脊、局部地形背景与同地理显示复用

2026-09-28，PH06 的局部实现决定；不是 PH 完成、自然视觉或性能验收。

原来的山系沿直线片段生成，片段交界和局部重生成容易留下折线、鼓包。区域锁只改编辑元数据，却会触发整个细地形的 CPU/GPU 重建，令完整保护、撤销、恢复流程在移动仿真中超时。这两类问题分别修复，不改变海陆权威、存档格式或原锁保护合同。

## 地形数据

山系采用共享切向的三次曲线，用真实陆地采样检验曲线经过的范围；不合适的跨海片段拒绝并分断。沿实际弧长积累有限宽度的高度贡献，真实端点才渐隐，曲线接点不再次变成山脉端点。峰谷和左右坡宽沿曲线变化；横向坡宽使用连续一阶导数的过渡，避免此前线性限幅接点的折痕。所有生成结果仍写入实际细节点，不以显示噪声代替地理。

准备与查询分别限制支持节点、索引引用、单查询候选和陆地探针数量；预算不足拒绝，不截断后冒充成功。离散陆地探针不是任意连续位置都在陆地上的数学证明，最终地形和锁的逐片审计继续保留。

局部重生成从旧陆地细高程提取低频背景：在固定世界网格上，使用有限窗口的陆地高度分位值，再连续插值。新山系覆盖旧山系，而不是逐点取新旧最大值，因此原高峰可以降低。全局网格及边缘读取范围避免把选区边界当成地理断面；海洋、覆盖、高程锁、海岸锁、选区外和过渡带仍由原写入限制与末审保护。跨度超过窗口的旧高原仍可能成为背景，这不是侵蚀、水文或地质模拟。

## 显示复用

只有两个已经验证的提交视图拥有相同地图身份、规格、粗地理引用及完整细海岸合同和引用，且现有 CPU 地形、空间索引、纹理与几何缓存完整时，才允许复用地形显示。更新当前修订、锁和界面状态，同时保留等价地理缓存。生成候选、地理变化、缓存缺失、GPU 丢失仍走原重建流程。未知增量显式拒绝，不能推断为无变化。

这项复用不减少 Worker、存储、接收协议或存档完整性验证，也不以当前字段名称或仅修订号相同推断地理相同。

## 历史与验收

实际 preview.13 的原始生成闭包、构建身份和文件字节保存在 `docs/evidence/ph06-preview13-generator-history-2026-09-28/`，旧配方继续识别旧实现。新增历史注册表本身属于实际生成依赖，所以本批全部 11 个闭包身份变化；其中 8 项仅历史注册表变化，3 项还包含新地形算法。引擎身份未变。不得将旧指纹写成新算法的身份。

本批窄检查覆盖连续性、独立查询参考、保护范围、旧高峰降低、历史身份和显示复用；浏览器继续使用实际非零三种锁、局部生成、单项解锁、混合撤销和刷新流程。具体结果见同批证据。功能断言或记录完整不能替代自然地图效果、用户视觉、真实设备与整体游戏性能验收。新版 Atlas 的国家、行政区、城市和军事实体依然需要后续计划真实接入。

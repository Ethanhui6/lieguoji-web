## 本批完成的工程范围

1. **独立 v2 分块国土存储**：新建默认 v2，旧档只经显式升级副本获得新 World ID，已有国家/政权/城市 ID 与独立地理保留。每页最多 1,024 个单元、32 KiB；SHA 不可变页、清单、根及回执同事务 CAS。消息每包不超过 512 KiB，完整重组校验后才交付状态。旧 v1 格式与 256 KiB 限制保持原样。
2. **手绘与逐点圈地**：3—256 顶点，支持撤销顶点、重画、移动视野、预览取消。Worker 从真实几何逐页选择单元中心并排除海域，确认重算；自交、退化、越界、他国冲突及超限拒绝。取消/错误不写部分国土，失败可继续编辑原轮廓。运行中有真实进度与取消，保存阶段不声称可撤回。
3. **分块政治显示**：每 8×8 单元按国家合并路径，视口裁剪；全世界归属索引消除同国共边，避免视野外邻国被画成假边界。改名/城市/迁都复用几何。去掉旧 8,192 显示单元上限但保留有界缓存与明确预算。细片计算共用让出时片，取消仍持续响应。窄屏圈地工具停靠底部，可滚动，不截获普通提示下的绘图输入。

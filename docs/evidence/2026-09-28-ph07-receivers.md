# PH07 真实双页流路内核

已把双页 receiver、私有 Owned 来源提取与路径投影接入 `src/world`。它能从当前实际细高程取得两块相邻地形，逐个相邻节点追踪下坡，穿过两块之间的接缝。原单域流向、Worker消息、bridge和界面没有改动；本批尚未新增可点击的跨页玩法。

核心范围最多两个 128×128 core，带真实一圈 halo；来源绑定当前私有地图会话及完整 head，并在让出执行权和返回前核对取消与来源失效。海岸识别遵循现有细三角面规则，陆地流路保持四邻接，不跨海峡。私有地形页面不会因为调用者修改诊断数组而改变。

路径最多4096个真实节点，保留节点高程和所计入的上游样本数，区分真实岸口、天然洼地、区域外尚未解析的陆地、世界边缘、海节点和显示截断。岸口不自动等于与全球海洋相通；洼地不自动等于已蓄水的湖。样本数不是水量或流量。上游贡献不完整与下游未解析分别记录，不能相互代替。

统一实际检查记录：[`integrated/first/verification.json`](ph07-receivers-2026-09-28/integrated/first/verification.json)。计划检查、全项目 lint、类型、9个测试文件共94/94通过，前后源码指纹一致。范围包括原边界14项、新 receiver及真实Owned16项、新路径5项、已有kernel/snapshot/trace/Worker和preview22历史兼容。先前独立候选检查16项与5项有各自原始记录；不将它们额外累加为新的测试数量。

实际故障拒绝包括循环、跳点、逆坡、非法累计、损坏终点、过期来源、会话替换、取消、错误预算及未知字段。长走廊测试证明第4096节点仍有下游时明确截断；若该节点本身是实际岸口则如实结束。

本批没有重新构建浏览器产物。当前 `dist` 和本地试玩仍为已经检查过的 preview.22。新内核尚未用于整世界分块调度、全域流域和累计、完整河网、湖面/蓄水/溢流、河湖编辑或持久化；两个128² core也不能冒称比原512²单域覆盖更大。内核typed-array预算不代表整个Owned快照或浏览器总内存峰值。后续须先补可复用的私有地理读视图和跨块协调，再接实际河网操作，不增加边界诊断面板冒充游戏功能。

# 0013 · 真实海床、陆架与深海

2026-09-27，PH06-T2。用户要求海洋有真实层次。手绘大陆已生成沿岸高程，但其影响带外保留空白草稿原有 −100 米，导致远海仍普遍浅青。本批新增独立海床生成，保存实际水深。

## 操作与边界

`ocean-floor` v1 使用明确的种子、平均海深 1000—6000 米、海底起伏 0—2000 米、陆架宽度 64—1024 世界单位。默认 3600 / 1000 / 320。只作用于通过真实四邻共享边连到世界边界的负高程海域。封闭内陆负高程按内湖保留，未将此定义冒称完整水文学。

完整保留陆地高程、海陆分类、第一圈近岸水深、所有锁定格、共享几何、模拟区和行政归属。海水连通分析与距岸传播使用实际 quad 重心，连续种子场形成海盆和海底山脊，陆架向带外高程平缓混合。颜色继续根据真实高程显示，不单独随机填色。

该操作共用现有 Worker 私有候选、完整校验、根 CAS、原子主备、确认/取消/会话撤销和刷新恢复。没有可编辑外海或参数不合法时明确拒绝，不静默写库。摘要中的陆架格/带外格以距岸宽度分类，不冒称严格深度阈值。生成前取得私有输入，长循环可取消并报告进度。

## 兼容

不改 `createGenerationDraft` 的空白 −100 米合同，不迁移旧 v1 草稿或直接改写历史。新增配方导致共享验证闭包指纹变化，因此将真实已测本地 `0.5.0-preview.2` 的五个生成指纹登记为仅存储来源可接受；新操作必须使用当前实际指纹。静态 codec 样本绑定原 build/source 检查证据，不冒充玩家存档、旧地形结果或已公开发布。

## 验证与发布

用单元检查实际连通、退化/变形 quad、锁/内湖保护、确定性、私有输入、取消和 512² 地理；用 Worker 检查预览不写、确认恢复及撤销；用三端浏览器真实 UI 生成大陆并挖出封闭洼地，独立解码落库数据核对全海陆分类、旧陆地、内湖、其他层与近远海深度差。最终结果写入本批证据，不提前宣称通过。

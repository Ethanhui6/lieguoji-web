# ADR 0017：在细海岸世界继续画大陆

日期：2026-09-27。范围：PH06-T3/T4 的本地实现；状态与实际检查结果以 plan/tasks.json、AUTO_HANDOFF 和本批证据为准。本文件不是完成或发布证明。

## 玩家行为

第四版草稿画好第一片陆地后，可以在海面继续画下一片。每笔仍经过预览、确认保存，也可以撤销最近一次生成。预览不写主档；刷新只恢复已确认的数据。新增面积单独显示，已有陆地、基础几何、非高程层与区域锁保留。

目前追加的是相互分离的陆地。新大陆接触、重叠旧陆地，或在一个细格中无法同时保留两者真实边界时，拒绝候选并说明原因。它不是任意并集、连接大陆、擦除或局部重塑工具；这些编辑能力仍依后续计划实现。

## 生成、身份与历史

首片 `shape-detail-landmass@1` 的生成内核不变。追加使用独立 `add-detail-landmass@1`，沿实际运行依赖计算指纹，不把旧首片历史改名为追加。preview.7 的七种实际构建指纹及 27 份依赖源码字节归档在 `docs/evidence/ph06-preview7-generator-history-2026-09-27/`。旧身份只用于识别和读取历史，不批准以新代码执行旧配方。

adapter 先核验完整输入并取得私有副本，从真实粗格四边形及锁层提取完整保护区。生成器保留旧陆地及相关节点，必要时显式保存受新基础高程影响的旧隐含高度；最后按实际裁片审计面积、边界和高度。结果是保留既有分量的受约束拼接，不声称是全世界精确并集距离场。

预览、版本和根摘要绑定、Worker 分包、取消、确认、CAS、提交回执、撤销与备份沿用现有协议。完整候选在存储最终提交处再次核验实际保护区，不能凭前端按钮或生成器声称已保护而省略。

## 锁与渲染

完整 v4 替换使用细格保护：真实粗格四边形决定覆盖区域；海岸锁比较实际海陆裁片、岸线和零面积归属；高程锁还比较实际片高度和隐含基础高程。分批重建有界细格，不持有整张世界的三角网格。旧格式锁行为保持，尚不支持的 v4 局部编辑继续使用原保守保护。

地形明暗由实际量化裁片的高程梯度计算，沿既有西北光方向及有界对比度采样材质。没有修改海陆判定、拾取、持久高度或增加装饰性假地形；缩放不改变坡向。该光照改进并不代表大陆自然形态、地貌层次或用户视觉验收通过。

## 独立验收边界

- 正确性需覆盖连续两笔、旧区域保留、撤销、恢复、重叠拒绝与库内容不变。
- 全局静态检查、受影响的生成/锁/事务/存储测试、实际构建和原生浏览器输入单独记录。
- 已有软件 GPU 的数值及颜色检查不是硬件性能验收；移动仿真不是真机。
- 国家、行政区、城市、军队和自主战争仍未接入 Atlas；本批不替代这些后续 PH。
- 只在本地开发；全 PH 发布锁、唯一 Pages 原生 Git 链与旧存档隔离保持。

## 真实工程格式

安装版是 **Unity 2021.3.36f1、Windows x64 PE32+、IL2CPP metadata v29**。`GameAssembly.dll` 为 53,442,048 字节原生代码，CLR目录为空；`global-metadata.dat` 为12,223,432字节。检查范围未发现原始 C#/C++ 工程或 PDB 文件，只发现指向 PDB 的编译记录，没有 DWARF 调试节。

已建立 88 个程序集、13,681 个类型、101,296 个方法名、60,691 个字段名索引；Assembly-CSharp 有2,024个类型。**名称/签名索引和空方法声明不等于恢复了实现，不等于游戏已经能够编译或运行。** Unity 的 IL2CPP 会把托管程序集转为 C++ 并编译为原生程序，Windows DLL 不能直接作为网页脚本使用。[Unity IL2CPP 文档](https://docs.unity.com/en-us/engine/6000.7/manual/programming-environment/scripting-backends/il2cpp)

图片流程采用其分阶段思路，按实际格式调整：

| 图片阶段 | 本项目执行方式 | 完成标准 |
|---|---|---|
| DWARF/ELF 元数据 | PE/IL2CPP 索引、资源对象目录与摘要 | 地址/类型/文件可追溯，不编造源码 |
| hk4e-mcp反编译 | 本次无该工具；用 Il2CppDumper 和限定函数静态分析 | 明确函数实现证据和未恢复部分 |
| 分函数并行 | 原生地图载入、内容适配、网页消费分别分工 | 不重复改同一模块、不整包盲目改写 |
| 填服务/编译 | 先数据适配，再生成器，再独立地理草稿 | 真实 TypeScript/Worker 构建、受影响检查 |
| 原进程联调 | 本批只做静态分析与网页验证 | 未执行原游戏，不能声称原作行为一致 |

工具：[UnityPy](https://github.com/K0lb3/UnityPy) 1.25.2 用于资源读取；[Il2CppDumper](https://github.com/Perfare/Il2CppDumper) 6.7.46 net6 用于类型/函数映射。其 DummyDLL 本就不恢复方法实现。工具包均在本项目临时分析目录，不加入游戏依赖或网页产物。

### 已运行的地形内核

已经从恢复脚本中拆出 `HeightmapGenerator`、模板和必要纯函数；原脚本保持原字节。适配器将两个 Unity 布尔字段读改成明确输入参数，将原 Unity 地块查询替换成调用方点集上的最近点查询，并移除不可达的图片DOM载入路径。输入包含点坐标、邻接关系、尺寸、seed、template；输出为真实0—100整数高程，海平面20。它**不生成原作顶点/邻接拓扑**。

独立有界子进程验证：相同种子/模板两次输出一致，改变种子或模板输出改变，样本均有海有陆且高度合法。6,144节点夹具采用96×64扰动网格和8邻接，明确不是原Unity地图。原生浏览器研究页 [http://127.0.0.1:4175/](http://127.0.0.1:4175/) 已以Worker运行24,576节点（192×128规则点阵），能切模板、种子、缩放与输出研究用高程；仍未接Atlas保存，不能当完整游戏试玩。原生成器与网页图形/数据适配分别验收。

随后对照改进：规则八邻接会产生贯穿斜纹，当前研究页改为固定抖动点集 + 已有d3-delaunay 6.0.4的真实三角邻接，仍为24,576点、48,514三角形。渲染和拾取共同读取真实三角重心插值高程；未覆盖像素为0。旧规则点网证据保留在browser/lab-regular-baseline，不能混用两套输出摘要。高度适配器SHA256保持 `420dc9d9dd795406a7334848ec11ee58cb1865d2756ab3b07257a08a9f307c31`，没有靠修改原算法消除斜纹。

新拓扑种子 `0x51f15e3d`，拓扑SHA256 `ede5a394c6957c7eef5f7fd31061732ec3708491d2015e5061057f395e2072cf`。7个暴露模板在桌面与手机仿真均成功生成，固定种子同输出、模板间不同；所有模板存在海陆，完整三角形/点/高程研究JSON导出通过。原生IAB保留用户的群岛/421730选择后刷新，新图陆地节点17.2%，24,576点，零覆盖缺口，控制台无错误；后续原生完整截图调用未成功，最终画面证据使用同源同版本隔离浏览器截图，不宣称捕获成功。当前没有原Unity拓扑等价结论。

恢复脚本带有Alea MIT/BSD注释及Azgaar相关来源线索；[Azgaar上游许可证](https://github.com/Azgaar/Fantasy-Map-Generator/blob/master/LICENSE)为MIT。保留实际提取模块和所有识别到的第三方声明，不把用户作品所有权推断为所有第三方组件都无单独条款。原生插件和Shapes没有加入网页产物。

## 网页接入约束

第一批消费只导入国城命名候选：用户手选本地包、选择命名文化、显式替换输入框；导入/切文化不覆盖手填名，不修改世界制度。选定名称仍走现有 Worker 预览确认和原子存档；名称包是会话辅助资料，不持久写入世界。

地形后续采用“导入为新的独立 Atlas v4 草稿”：单独记录源摘要、转换器版本、坐标映射，保持 manifest `origin: null` / `generation.lastApplied: null`，不假装运行了已有生成配方。用 `createGenerationDraft(...,4)`、共享几何和细场codec，逐块写入真实高程/海陆，完整校验后以 `expectedRoot: null` 原子保存。不得通过当前明确禁止的v4 fork/generation-copy绕过，不覆盖原草稿/国家世界。

原作自动省份、完整城市、兵种战争、家族、信仰传播仍待后续PH的真实实体和规则接入；本次数据提取不将这些功能标为完成。自然大陆视觉和真机验收继续独立待验。

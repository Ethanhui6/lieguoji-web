# 《列国纪》两步到位全局深度进化计划表（v4.2.1 → v4.2.2）

## 长期协作与发布规范（铁律）
1. **集中厚实、分两次到位**：全部计划内容集中打磨为 **`v4.2.1`** 与 **`v4.2.2`** 两次扎实重磅更新，版本号平稳小步递增（`4.2.0 → 4.2.1 → 4.2.2`）。
2. **GitHub 统一中文发布**：GitHub Actions Summary 与 GitHub Release 统一展示同一份中文更新日志；IPA 文件与 Artifact 均携带版本号与构建号（`lieguoji-<version>-build<build>-unsigned.ipa`）。
3. **永不中途关掉运行中的构建**：旧任务仍在 GitHub Actions 编译或上传时严禁取消；新更新顺序提交推送下一次构建。
4. **全局统筹、实机验收**：过渡动画、UI/UX、高帧率动效/视频、海陆军系统、数据属性与因果事件链按全局清单系统交付并经 iOS 模拟器实机截图逐张核验。

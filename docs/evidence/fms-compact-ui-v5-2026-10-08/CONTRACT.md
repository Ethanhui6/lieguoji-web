# 图标与信息层级改版 · 2026-10-08

用户本轮明确要求不用 skills 自行设计，减少文字和臃肿感。本批没有读取或应用技能，也没有新增 UI 依赖或下载图标包。沿用 React / CSS，新增本地 SVG 符号集合。

这是一批实际界面改版，不是 iOS 真机、用户视觉或完整原作等价验收。地图几何、渲染配色、国家 AI、战争和存档规则未因此完成。源码检查点以 DELIVERY 与 tested-artifact 为准。

1. 沙盒常用工具改为可访问的图标按钮：返回、保存、图层、缩放、全图、播放、单日、时间选项。保留中文 accessible name，桌面 title，手机主导航短标签；命令仍预览后确认。
2. 国家详情改为概览、外交、宫廷、地方四页。默认页优先国家、首都、人口、粮储、军队及定位/编辑；财政、治理、军备按需展开。军队和海军先呈现选择、关键状态和移动命令，补给说明、调度、造船等位于分组。
3. 绘图工具使用同一套图标；五组地形参数折叠。保留真实海岸/保护范围说明、预览取消、撤销重做、版本保护提示。史书保留开篇君主、重要事件、搜索和筛选，收起默认的大段说明。

交互约束：隐藏的国家页继续挂载，不能丢失表单草稿；显式编辑的暂停状态和取消按钮必须始终可见；点击地图或首都进入所选地方；普通观察继续推进时间；Worker 命令仍重新校验；旧版本没有能力时不展示空分组。减少动态与键盘切换减少动画。

只写当前工作区，根唯一代码写入。只读审查者指出并修复：隐藏编辑器仍暂停且没有取消入口、地图选择未打开地方页、旧能力缺失时空分组。画面复核还发现新的 button display 样式盖过 hidden 属性，已显式修复；绘图入口不会遮住展开的参数面板。早期 JSX 文本替换语法错误在类型检查中发现并修复，未交付为可玩版。

浏览器证据采用独立 Chromium context 和之前经普通 UI 创建的测试存档；不读写用户正在玩的 5250/5248 站点存档。428×926 为桌面竖屏仿真，1440×1000 为桌面；同样存档与相机截图比较。文字长度为当前展开面板的 innerText 字符数，不是地图像素遮挡率或性能证明。

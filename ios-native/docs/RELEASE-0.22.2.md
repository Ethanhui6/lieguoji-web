# 0.22.2 · 山川与笔触

延续 0.22.1，并核对远端 Claude 分支仍为 66c3329a。保持原有 PR，不合并；不修改 src/ 与 Capacitor ios/。

- 地形：山地光照在相邻地块共享顶点取连续值，自然地图的群落颜色平滑过渡，减少硬块拼接感。政治颜色不混合，国界、拾取、地形高度不移动。缓存自然底色，仅地形变化时失效；每帧仍使用原有 Metal 顶点颜色与插值，不增加纹理采样、绘制调用或动态噪声。
- 自定义：自绘地图新增笔刷强度 0.2–2、柔和度 0.3–2、目标高度（海洋 0–19、陆地 20–100）、海岸保护。修改真实高度，继续走现有气候/河流/州郡生成与撤销重做。这些是编辑器参数，不宣称是原作新增规则。
- 图标：编辑器海洋、平原、山地、升高、降低、平滑加入同一 24 单位线条图标体系。游戏操作共用语义图标，工具操作保留易识别的系统符号；沿用上版应用图标。
- UI：主次按钮统一文字大小、图标框与最小高度；国家操作支持多行；信息行窄屏上下排列，数值等宽；按压改为 2% 缩放与 0.15 秒反馈，并支持减少动态效果。

## 验证
新增 Core 测试覆盖海岸保护、上下界、笔刷强弱/边缘，以及共享顶点明暗一致与平地中性光照。CI 运行全套 Core 测试、Metal 编译和 iOS archive，具体结果附 PR。

尚未完成真机地形截图、横竖屏视觉验收与帧率测量。新增预计算会增加地形首次构建/编辑提交成本与顶点光照缓存，不能承诺整体性能无变化；正常拖动缩放不重算这些数据。没有重写地貌生成算法，山脉连贯性和河谷形态仍受原有高度场限制。

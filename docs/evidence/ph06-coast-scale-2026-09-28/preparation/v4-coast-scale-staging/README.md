## 物理设计

- 主事件数量按约360world原岸周长提供一个主事件，夹在2..10；2541world标准周长为7个。旧900world尺度只给3个宽弧，数量不足。本候选没有强迫tiny周长满足大大陆数量。
- Regional 权重采用6百起、每档增加240、每档种子扰动0..80；fill为.760..800。相邻档宽度在共同周长归一化后仍不同，形成可区分的窄、中、宽物理弧，不依赖随机碰巧给出宽度差。
- 强湾和强岬有平衡配额，奇数的额外项是湾；它们随各自宽带一起打乱。若种子打乱后恰好整圈严格正负交替，只交换其中一对来打破该情形。空间顺序、宽度、phase、偏心峰及左右肩形仍由种子确定，沿岸不是等距交替波。
- 主事件最大幅度仍为原.85..1个 FIELD_Q，上限不变。过去每项都以 `width/(2*structure)` 收缩，窄口必被压浅；现在主事件按整岸 `min(1,perimeter/(8*structure))` 收缩。标准大陆的窄主湾能保留真实深度；全岸不足的tiny整体缩小。
- 满尺度主事件最小源弧宽48world，即24个2world细采样步长；短周长时该宽度随整岸reach缩小，但不低于16world。不会靠把亚分辨率事件放大成大幅度尖刺获得效果。Local小肩形仍使用原分布、原单事件宽度收缩及16world下限。
- 小于96world周长不创建结构事件；64world测试仍要求零事件。160world/structure96时整岸reach约.2083，保留原“幅度小于FIELD_Q/2”要求。structure0的精确零结构、最大160检查不变。

## 边界与静态依据

Regional的最大fill .800加最大槽内偏移.110为.910，Local为.820+.110=.930；均不越槽，round/floor不能累积越过槽末。同层仍不重叠。shape函数、regional+local*(1−regional²)组合和强度上限未改，所以此前[-FIELD_Q,FIELD_Q]幅度证明仍适用。原下游cap和总预算继续压住实际位移。

2..10主事件加最多36 local仍低于48事件上限；128 bins、1024 references、8 candidates拒绝门保持原值。新代码无全局缓存、无每细节点重建计划、无额外无界循环。复制输入与返回诊断副本、checkpoint/abort结构未改。

权重档位的静态间隔：相邻id在fill前后的最小差为 `(600+240*i)*.760 - (600+240*(i−1)+80)*.800 = 104−9.6*i`；在最大id9仍为17.6，故共同归一化后不会成为等宽槽。合法本批尺度的Q8取整误差远小于该间隔。实际八点大陆的湾口宽度仍必须由生成后的target测量，不能以这个plan级推导冒充视觉证据。

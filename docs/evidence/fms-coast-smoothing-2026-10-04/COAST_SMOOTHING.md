2026-10-04 香港时间。本批源码 `fd6f8a5bf174b0de519eaf9e532e32ae74377873`；起点 `cf6532c`。只本地开发与临时构建，无云端写入。**WEB-02-01 仍 in_progress，首份真机/用户视觉门未通过。**

## 可玩变化与保形合同

新增“预览轮廓平滑”，与上一批的“海岸细化”分开。默认最大偏移仍为 0；玩家主动设定 0—4 地图单位，预览/对照/取消/确认，确认后作为一个整网格历史步骤，保存真实点位。高程、三角连接、邻接和保护位不改。自然地形生成仍固定当前 h20 海岸；本操作是玩家主动选择的几何变更。

平滑针对**本次操作前的当前地图**，不是最初画图的永久锚点。连续确认会累积位移和面积变化，UI 已说明。每次候选在 Worker 计算后、主线程预览及确认时独立重验：

- 渲染器 float32 顶点位移不超过玩家上限；海岸交点是边端点的同权重组合，因此对应 h20 轮廓点也受该上限约束。
- 各正面积陆地/水域连通区域的总面积变化不超过 2%。按裁剪面之间的正长度共有边连接，不能用 h20 单点或零宽连线合并两个岛体的面积预算。
- 分片仿射位移梯度 Frobenius 范数不超过 0.2。合法完整矩形源域上，任意对应点间距倍率在 [0.8,1.2] 内，网格不折叠、连接与包含关系保留。**这不是每个固定 x 剖面的宽度完全不变，也不是每个三角面的面积变化≤2%。** 本次浏览器最大单面面积变化约 23.87%。
- 源域先检查一致面朝向、内边抵消、矩形边界一次覆盖、顶点 link、Euler 特征及连通；缺面、重叠/折叠、非矩形源拒绝。当前固定 1536×1536 源域适用；不能精确对应 float32 边界的自定义尺寸可能安全拒绝，未实现通用任意域支持。
- 任一保护点涉及的整面坐标固定。面积严格小于 4096 平方地图单位的岛屿/水域边界固定；不是冻结整个岛内所有点。两层采样支撑不足的细部跳过；其余窄颈使用上述间距/拓扑保障，没有声称全部细颈绝对不动。
- 独立的海岸折角平方和指标必须降低，才允许提交移动候选；这只是诊断指标，不是自然感或原作相似度验收。无改善时不应用。

旧微细化的合同保持原样：每个原父三角面内，陆地和海洋面积各变化≤2%，旧点/旧边交点固定。没有把旧的“分面 2%”静默放宽成新的“组件 2%”。

## 发现的失败与修复

1. 新增 h20 细化点若单独参与局部缩放，位置/面积虽合规，却制造额外锯齿。初版测试图从 revision22 的折角指标 623.223 变成 revision25 的 690.941；保留 `failed-independent-knot-*` 和 `failed-*-close.png`，它们是本批未提交中间实现的失败证据。修复为三邻点 h20 内插点随原父面仿射位移联动，并在生成/主线程增加折角改善检查。三个不规则采样回归覆盖此路径。
2. 冻结的小岛仍给第一轮扩散泄漏位移。现在先把冻结点的位移清零，再扩散；单点及 3×3 岛回归通过。
3. 很小的用户上限若逐轮廓点单独截断，会制造微小折角。现在保持统一目标场，再整体验证/缩小到用户上限；0.25/1/4 的最终 float32 回归通过。
4. CDP 以数值对象传出完整文档时，工具传输使少数 double 坐标末位舍入，独立“全点精确相等”检查实际失败。没有放宽容差：改为浏览器生成 JSON 文本后传出，精确点位与刷新前后原始文本比对通过。完整测试网格仅存 ignored `.autopilot`。
5. 原保护笔刷重算 Voronoi 找最近采样点，再扩面，会遗漏非 Delaunay stored mesh 下实际落点的面。改为基于 stored float32 三角面做圆相交、分桶查询；超预算整笔拒绝。A(0,0)/B(80,0)/C(80,80)/D(0,20)、ABC+ACD、笔刷(30,28,r8)的具体漏 B 回归通过。普通海陆笔刷仍使用既有 Voronoi 数值选择，不宣称 Unity collider 等价。
6. 原河段绘到海中 receiver，近景出现短棒。现在中心线在同一 h20 插值交点截止，h20→sea 零长段不画，终点恰好 h20 的上游段同样用平端帽。排水/receiver/汇水与保存数据不改。**粗线斜交岸边时边缘仍可能覆盖少量海面，未实现整条笔画像素裁剪。**

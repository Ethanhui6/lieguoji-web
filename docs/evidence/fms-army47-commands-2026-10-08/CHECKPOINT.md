# WEB-04-37：实际海陆位置下的军令与连续行军

2026-10-08。接续已冻结的 v46 和已有 Army47 位置、粮食、占领切片。根独占写入。这是尚未启用的新运行时模块，不是已接入浏览器的跨海试玩；最终代码提交、文件哈希和真实检查结果见同目录 checks.json。

## 本批实际实现

- `army-geography47.ts` 从当前 terrain、真实辖区重算地理绑定，再派生有界缓存的海陆图；军令只能提供目标，不能提供路径、图或自报地理。
- `army-commands47.ts` 预览和确认使用 run/day/event/tick/位置 revision/地理 binding。同一预览重复确认、过期、未知字段、计数上限全部拒绝。确认重新寻路，接受后只增加一次位置版本和事件编号。
- 改令、停止和同格指令保持实际坐标，不跳回旧城市中心。真实海域目标不要求存在舰队，不复制或消除 Army；旧 route/战斗计划与远征自动任务让权，原船航段与船员物资保留。
- 新的停止军令与“关闭预览草稿”分开。交锋中的部队必须通过后续独立撤离机制，不能用停止或改令清除交锋。撤退的结束条件在停止、同格改令、到达之间一致：真实可通行陆地且没有活动敌军；在海上停止仍保持撤退身份。
- 行军 phase 使用实际 cell 的速度回调，跨 gate 重验外交权限。候选包含所有可变世界/时钟/附加状态，后续一支军队计算失败不会提交前一支军队的移动或时钟修改。terrain 是经验证的不变输入；完整 session 不得把共享 terrain 当可变状态使用。
- 与上一切片连通：实际海上消耗随身口粮、不从旧城市补给；实际登陆空地后只夺取该地区。旧 provinceId 仅保留为历史兼容引用，绝不当真实海上位置。

停止、任意格改令、撤退安全判定、外交通行与候选事务属于明确的网页交互适配。原作连续位置、入格后取速、Army 可自行跨海的静态依据沿用 [此前内核检查点](../fms-army47-foundation-2026-10-08/CHECKPOINT.md)，不以这些适配声称原作所有军事规则相同。

## 审查与失败记录

- 第一轮 65 项相关测试中 64 通过、1 失败：小规模合成世界合法地没有初始舰队，测试却假设存在。修正为明确建立位于实际相邻海面的合成舰队，保留完整 node/route/progress/物资断言；没有修改生产舰队生成条件来迎合测试。
- 第一轮 lint 检出一个未用测试 import，已移除。首轮类型检查通过；修改后重新执行最终检查。
- 只读审查发现候选原先共享 clock 等可变字段，已改为复制全部可变附加数据，并覆盖成功返回后改 clock/finance 与回调改 clock 后失败的原对象保护。
- 只读审查发现 returning 任务删除后空船可能永远失去自动巡航资格；现在与 assembling 一样恢复合格空船的自动资格，保留实际航段，不干预手控/载军/损失舰队。
- 只读审查发现先停止再进攻可以绕过直接改令的撤退检查；现在海上停止、同格抵达、普通到达共用安全终止判定，并有序列回归。
- 失败日志与最终日志分别保留，不以最终结果抹去首轮失败；测试数、构建、保护和源码指纹见 checks.json。

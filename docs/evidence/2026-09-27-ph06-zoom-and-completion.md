# PH06：放大清晰度和第三版生成闭环

2026-09-27，本地版本 `0.5.0-preview.6`。全部 PH 发布门保持，没有云端写入。本批是现有 Atlas v3 的显示和操作修复，不是自然大陆视觉验收，也没有接通国家、行政区、城市或军队。

## 实际改变

- 地图缓存依据实际相机倍率和屏幕像素密度分级细分，单纹理不超过 1024，保留真实 2px 邻域和原 32 Mi 像素预算。默认隐藏采样中心标签，主动打开网格后才显示。
- 取消生成不再被浏览器 AbortError 英文覆盖；已提交草稿保留，真正的其他错误继续显示。
- 绘图缓存预热按实际已用 32ms 或原八块上限合作式让出；准备整图撤销时按真实编码数据分批核算字节。64 MiB 撤销门、源文档身份重验、失败和取消保护保持。
- 已从 preview.5 实际 Git 提交与归档构建逐一重算六个生成器闭包，登记为仅允许读取的历史。不会把旧配方伪装成当前实现。
- 独立细海岸内核已落盘：唯一共享节点所有权、真实量化裁切片、海陆拾取和面积、四边形锁保护。尚未接入第四版存档、Worker、生成和界面。详见 ADR 0016。

第三版完成度浏览器现为 **8 个唯一场景取得通过证据**，按实际执行记录组合，不是首轮全过：

1. `desktop-256-first`：运行配置误合并多项目；首个用例暴露取消英文错误后人工停止。没有完成报告，不纳入完整次数统计。
2. `desktop-256-recheck`：反馈修复后仍因真实绘制间隔 270.3ms 失败。
3. `desktop-256-cooperative`：合作式渲染后 1/1 通过。
4. `remaining-first`：7 项中 3 通过、4 失败。三端局部用例把海岸锁误当高程锁；实际锁为 1，合法高程变化 3→1274m，地块二进制和 SHA 已独立核验。另一个 512 用例暴露撤销核算间隔 282.8/314.7ms。失败报告全部保留。
5. `repair-four-first`：只改三处锁位掩码 oracle，并修真实撤销核算长任务后，受影响 4/4 通过。512 手绘完整预览最大进度间隔 173.3ms、海床 231.7ms；实际生成中取消响应 22.8/21.1ms。250ms 进度和 500ms 取消门没有调整。来源和全部产物前后稳定。

上述四次完整运行共 13 次实际用例执行（1+1+7+4），另保留一次被中断首轮失败；自动重试均为零。桌面、手机和平板只是 Chromium 尺寸与输入仿真，不能代替真机。

一次本地验证脚本误调用正式 `release:check`，因未完成 PH 正确拒绝；随后改回发布策略的单元检查。正式发行门仍不通过，原拒绝记录保留，没有推送或绕过检查。

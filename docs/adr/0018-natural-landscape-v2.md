# ADR 0018：自然大陆、低地山脉与首片海床

日期：2026-09-27。状态：实现接入中；不是自然视觉、性能或阶段完成证明。对应 PH06-T3/T4，任务状态仍以 `plan/tasks.json` 为准。

用户指出首片大陆仍过于规整，海岸像等宽厚环，远海缺少层次。实际 preview.8 截图与源码确认：原轮廓只加入较小的岸边变化；陆侧起坡和海侧陆架使用相近宽度；v4 空白世界高程为 −100 米，旧首片生成器沿用该浅海。增加显示精度不能单独解决这些地貌问题。

采用独立 `shape-detail-landmass@2` 与 `add-detail-landmass@2`。Atlas 配方封套仍为 version 1、草稿仍为 format 4；生成器语义版本和实现指纹另行绑定。旧 @1 内核与实际历史身份保留，不能把旧配方重标为 @2。新世界默认自然地貌；打开旧世界恢复其原有参数，玩家可明确选择下一片大陆的地形风格，已有大陆不会自动重生成。

自然轮廓先在非相邻特征间距限制内圆顺转角，再沿完整闭合海岸的弧长加入主要湾岬和较小岸边起伏。`coastStructureWorld` 控制较大尺度变化，原 `coastRoughnessWorld` 控制细节；两者不依输入每一小段重新播种。派生轮廓重新检查交叉、接触、方向和工作上限。窄海湾与陆地连接处使用限幅保护；具名数值样例通过也不等于任意形状的拓扑已获证明。

高程使用真实低地与有界的定向山脊支撑。陆侧起坡和海側陆架独立变化。数据经粗采样与 fine 节点写入，显示、拾取、面积和保存继续使用相同权威分片。存储 coverage 为到量化目标岸段的截断距离；最终再次裁切的岸线才是地图权威，不能把两者错误称为完全相同的精确距离场。

首片 @2 的适配器只有在确认世界为空、无陆地、无锁、无实体和无生成历史后，才用独立 `natural-ocean-base-v1` 生成区域海床作为内核私有底场。使用真实粗格重心与固定种子域，深度有界为 −6500 至 −1200 米，再由实际海岸距离形成大陆架。它是可复现海床高程模型，不是板块模拟。最终输出与用户原来的 −100 米空海比较并持久化，不能只改变渲染颜色。

追加 @2 不重新生成全图海床。仅把新分离组件交给相同的自然大陆内核，再沿用相离拼接、旧高程保留和真实区域锁检查。接触、重叠或不兼容拼接仍明确拒绝；本决定不宣称实现局部重塑、大陆合并或全图联合距离重建。

实现不得增加全世界 fine 高程数组，不改变既有缓存、GPU 恢复、保存隔离、回执与 CAS 边界。检查应覆盖真实空海入口、旧历史可读、新首片/追加身份、旧大陆及远海保持、撤销与刷新。水文、气候、国家、行政区、城市和兵种战争继续属于其原有后继任务，不能由本次地形完成记录替代。

2026-09-27 preview.10 调整：对输入直段只去除最多 2 Q8 的采样抖动，合并时检查整段全部原点以避免累计抹平真实浅湾；零变化配方保留原输入。对向岸段和狭窄连接继续限制位移，同岸相邻碎段不再将主要湾岬幅度压到近零。山系由有偏移的峰、鞍和渐低端部组成，宽度沿线变化；侧坡宽度随有符号垂距连续改变，修复端点延长线外的有限高度跳变。新回归先在旧硬切实现测得 534 Q12 差值，再在原 2 Q12 阈值下通过。

本次仍使用已持久化的 coarse Hbase 与细海岸，不伪装为侵蚀、水文或额外内陆高分辨率数据。实际 preview.9 的十个生成器与37份源原件已单独归档，旧实现指纹保留为存储读取身份。实际游戏图仍有近海片间明暗格与偏圆峰顶，preview.10 自然视觉未验收通过。

对这个矩形，原相对岸距不会把136world预算进一步压低。诊断使用原公开 `roundAndIndexNaturalOutline` 和 `createNaturalCoastArcPlan` 重建同 seed/参数的设计分量，与真实生成覆盖对照，没有替换权威覆盖。

小环周围整个导出网格最近边恒为51，structural恒为0；粗细两个结构 profile 没有在这里跳变，bin/弧接缝也不是该缺陷成因。所有导出2world节点的重建设计符号与实际地理分类一致，mismatch=0。

## 最小修复建议的静态评估

主执行者准备只把粗糙噪声的采样位置改为既有 rounded input outline 的最近投影点：`a + roundRatio((b-a)*nearest.t,Q20)`，随后保持原旋转、48/12world频率、3:1权重及其余结构/cap算法。

该修改针对本次成因成立：同一固定岸线投影的法向上，arc、cap与roughness变为常数，设计场为 `F=d+offset`，不会再因离岸噪声产生本次局部反复穿零。噪声幅度界、原单预算、海洋边带与真实距离/面积存储管线不变。它使用输入轮廓，不是对最终target做反馈滤波，更不是删环。

这不构成任意曲角或非相邻最近投影切换均无拓扑问题的通用证明；原 facing cap、真实2world覆盖及单组件/水道/陆桥等检查继续保留。建议保留同法线只有一个海陆过渡的局部回归，避免未来在不同位置出现新小环而误判本成因已修复。微孔位置可作观察点，但若新投影噪声使整条有效海岸合理移过该点，不能硬性以该点必须为陆约束自然生成，更不能为通过该点移动海岸。主执行者决定实际测试补充与执行；本诊断不改产品测试。

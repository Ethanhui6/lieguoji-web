# ADR 0020：在既有细大陆上局部重生成山地

日期：2026-09-27。状态：已实现，限定功能检查通过，见 [实际证据](../evidence/2026-09-27-ph06-local-relief.md)；不是PH06完成或自然视觉验收。

玩家需要修整已画好的世界，不能每次换种子都重掷海岸。format4增加独立 `local-detail-relief@1` 配方，只有种子与200—6000米起伏参数，只接受带至少一格过渡的 `cell-rectangle`。旧四个细大陆配方仍只接受整图范围，旧格式不能执行新配方。

操作沿用已有Worker私有候选、预览绑定、CAS持久提交、确认取消和完整撤销。没有新增数据库、旁路保存或不真实的显示高程。新配方以自己的完整运行时源码闭包标识；变更前preview.11的十个生成器按实际构建与完整源码原件保存，旧来源仅准读取，不被重标为当前可执行配方。

首版只修改真实细陆地节点高程。所有粗地理块、海陆覆盖整数、锁和其他目录内容保持原样。粗高程也冻结，因此以粗高程为基础的隐式海床和uniform-land不会从隐藏依赖通道改变。需要将uniform-land块物化为samples时，先逐节点读取原场，再仅修改被许可的节点；海节点、海岸零点和不允许的节点保持原高度。

选区由真实粗地块四边形的并集定义。细格只要接触非选中四边形或高程锁就受保护；一个节点只有所有实际存在的入射细格均允许修改才可改变。此保守边带和选区内过渡一起保护邻区，不能仅以节点中心或名义矩形判定。海岸锁保海陆几何，高程锁另保实际高度，操作不解除任何锁。

自然山脉锚点只来自当前真实可编辑陆地，海岸距离来自当前量化岸线。地形覆盖的饱和哨兵不能当作精确海岸距离。可编辑内陆太窄、保护将内陆割断或没有有效山脉时，解释拒绝且不产生可确认候选。这里只重生成山地，不声称实现侵蚀、水系或植被。

预览显示实际变化、抬升和降低的细节点及变化分块数量。粗采样改动数为零；旧通用摘要中的连通片仍标明粗采样四邻接口径，高程范围仍标明存储样本及粗基础口径，不冒充全细场遍历极值。新摘要另给本次变化节点的实际最小、最大高度。

验收需分别证明真实节点差分、coverage/海床/非选区/锁保持、输入所有权、确定性、取消、预览不写盘、确认持久化、完整撤销与刷新恢复，并在真实产品浏览器中查看地形。代码、单测或GPU绿灯均不能替代自然外观、真机和性能验收。PH06-T3/T4及全部PH发布锁保持。

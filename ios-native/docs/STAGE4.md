# 0.4.0：Swift 模拟起步（时间推进 + 每日粮食与人口）

路线：游戏规则全部用 Swift 重写。方法：从网页引擎导出某一步结算的「前状态 → 后状态」金样，Swift 对同一前状态计算，必须逐位相同；每移植一个模块就补一份金样。全部模块移植完后，整套推演与网页一致。

## 本版移植
- 开局世界与网页 UI 新建世界完全相同：`src/native-export/native-world.ts` 在创建后执行网页 UI 依次发送的规则操作（退役、恢复、帧循环、批量行军、叛乱建国、官职、原作军队）。
- `Simulation.swift`：
  - ISO 日历（native-economy/iso-calendar.ts），每日 120 tick，日期显示「公元1年1月1日」。
  - 每日粮食与人口（war47-economy.ts advanceEconomy）：军粮按状态扣除（日长 1/30）、产粮（平原 1.12 / 森林 1.04 / 其他 0.82，被占领减半）、按国家粮政先后补给本省停驻军队（按军队编号）、民用消耗、饥荒死亡 0.2%、人口增长 0.01% 至上限、日账。
  - 原作军队日重置（settleOriginalArmyDay47：补给、士气回到 100）。
  - `Simulation` actor 在后台推进，界面只读快照。
- 金样：`economy-golden.test.ts` 导出 60 天每日各省人口、存粮与各军补给；`SimulationTests` 逐日逐位比对。

## 界面
- 播放 / 暂停、1·2·4 倍速（约每秒 10 / 20 / 40 日，与网页相同）、推进一天。
- 日期胶囊随推演更新；左下事件卡显示各国「日粮结算」；大事记里有各国当日粮账（期初 + 生产 − 民用 − 军用 = 期末）。
- 行省面板：人口、人口上限、存粮、补给；国家列表与人口排名实时更新。
- 地图上画出 51 支军队：原作兵种图标（步兵 / 弓兵 / 盾兵 / 骑兵 / 精锐）着国家色，位置与网页闲置军队相同，最小 7 点。

## 尚未移植（推演时这些不发生）
军队行军与 AI、战争与和约、外交、联盟附庸、人物生老病死、家族、官职、月税、征兵、国运、叛乱。军队停在原地，因此长时间推演的结果会和网页不同，直到这些模块移植完成。

## 本批实际完成

这不是一套新的战争演出，也没有改变任何战争结算、移动路线、AI 决策、存档 schema 或旧世界。它把现有 Culture47 模拟已经提交的事实接到玩家可读的界面上：

1. 新增纯只读 `force-activity47` selector。陆军位置来自 `actualForces47(...).spatial.space`，所以陆军在海上时不会因为旧的 `army.provinceId` 而被误显示为已在陆地。舰队目标由真实港口站点解析；围城只有当前空间视图仍确认敌对部队存在时才显示。
2. 国家信息页只展示最多三条真实行动摘要；军事详情页展示所选部队的实际地点、目标、军粮、接触、有效围城和已持久化的行动原因。地图动画的中间插值不被当作占领事实。
3. 大事记默认仍只显示重要事件，避免边境单省易手淹没宣战、和约、继承和独立。玩家可切换到“全部记录（含领土易手）”；点进一条领土易手快讯时，史书会自动切换到该范围。
4. 一处真实单省控制转移现在会进入顶部快讯，但作为普通消息显示约一秒；它不会抢占宣战、和约、覆亡等重大事件的队列优先级。完整、不可变的 `occupation` 账仍保存在 Chronicle 中。

## 真实数据合同

| 玩家看到的内容 | 实际读取来源 | 明确不使用 |
| --- | --- | --- |
| 陆军海上或陆地位置 | `actualForces47` 的空间账本 | 旧 `army.provinceId` |
| 围城是否仍有效 | `activeSiegesFromSpace47` | 残留的旧 siege 记录 |
| 舰队目标港 | `assignedPortId` → `harbors.sites` | 将港口 ID 当作省 ID |
| 行动解释 | 已持久化的自治 `decision/reason` | UI 根据动画重新猜测 |
| 领土易手 | 实际 `controller` 改变时写入的 Chronicle | 按颜色、国名或地图文字推断 |

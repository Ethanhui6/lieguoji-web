# ADR 0015：第三版草稿的权威裁切海岸

日期：2026-09-27
状态：权威地表合同已实施，并取得组合单元与三端浏览器验证证据；自然大陆视觉、真机及整个 PH06 验收尚未完成。详见 `../evidence/2026-09-27-ph06-coastal-surface.md`。

## 问题与选择

第二版创世草稿以共享四边形和每格一个高程样本为权威。连续地形着色消除了每格平涂，但海陆边界仍沿整格边缘，近景存在阶梯。现有海岸平滑会移动真实共享顶点；它受顶点四分之一格偏移、严格凸四边形和锁定限制，无法普遍把阶梯变成自然岸线。因此，增加显示曲线或抗锯齿不能完成此次需求。

第三版采用原创且确定的 `land-mask-fan-v1` 地表解释。保留原共享四边形、真实高程样本及行政/模拟归属层；在每个四边形内部建立四个三角扇片并裁切海陆。渲染、点击命中的海陆和高度、地表面积共同使用 `src/world/coastal-surface.ts`，不再以一条只供显示的曲线覆盖原边界。

这提高海岸的几何表达能力，不新增高程采样点，不声称它是更高密度地形、曲线海岸或流体模拟。每格中心仍只有一个真实高程。地块仍是编辑、行政归属和存储单元；同一个地块可以含有陆地片和海水片。

## 明确的格式与兼容边界

第三版 manifest 显式记录：

```json
{"version":3,"surface":{"kind":"land-mask-fan-v1","coordinateScale":256}}
```

它使用独立的 v3 存储域。默认创建 v2 的底层 API 保持兼容；产品入口明确创建 v3，旧 v1/v2 只通过用户选择的独立副本进入 v3。原草稿身份、当前版本、备份、原操作历史和原库不重写；不能只修改旧 manifest 的版本号后在原库保存。未来格式/未知 surface 合同继续锁写。

高程、几何、归属仍使用原 LGAB 分层块，锁仍使用原 LGAL 编码。派生三角片不另存一套可失配的海岸数据。`surface` 参与 manifest 哈希和完整候选身份校验；生成配方继续绑定实际运行源码指纹，历史指纹仅允许恢复，不授权以旧名称执行新实现。

## 几何和高程合同

1. 由真实共享顶点求面积重心，并在已有 Q8 坐标格上量化重心；重心高程等于该格权威高程。高程大于等于零的中心覆盖值为 `+256`，负值为 `-256`。
2. 每个共享角点的覆盖值为其实际 incident cells 的中心覆盖值均值，按固定拓扑顺序计算。该值只依赖海陆符号，不受山高或海深的幅度改变影响。
3. 角点覆盖值非零时，其高程仅从同一海陆类别的 incident cells 按真实重心距离反比插值；覆盖值为零和零线交点的高程固定为零。禁止跨海陆平均产生另一条高程零线。
4. 重心与相邻角点组成四个真实三角片，按覆盖值零线作直线裁切。面积为零的片舍弃；反向、非凸或退化源几何拒绝。
5. 零边界归陆地，点接触不意味着两个开区域连通。共享边零线由两侧实际开区域类别判定，并通过稳定 owner 避免重复绘制；世界边界不凭空生成海岸。

源坐标是 Q8（256 单位/世界单位）。固定覆盖场会产生二分和三分交点，内核采用源 Q8 的六倍精确坐标，即 1536 单位/世界单位。代码字段 `xQ6/yQ6` 中的 `6` 表示这个六倍系数，并非六位定点数。线性交点必须位于源三角边上且能在此固定格精确表达；任何面积不守恒均拒绝。

每个 cell 导出 `land/sea` 三角片、真实 `shore` 段、精确 `landAreaTwiceQ6/seaAreaTwiceQ6/totalAreaTwiceQ6`。其普通面积字段 `landAreaQ2/seaAreaQ2/totalAreaQ2` 是前述两倍面积除以 72，单位为“实际面积乘以 256²”。

历史生成摘要的 `landAreaQ2/worldAreaQ2` 一直是“**两倍**实际面积乘以 256²”。第三版为了保持跨版本字段单位，先累计精确 `TwiceQ6` 整数，再除以 **36**。不可把内核 `/72` 的普通面积直接写入原摘要。第三版边界裁切使陆地面积可能不是整数，不能再要求该摘要为整数；世界总面积仍等于 `2 × (4096 × 256)²`。v2 摘要继续使用完整地块面积，不改变原语义。

`majorComponentCount` 继续沿原中心海陆 mask 的四邻接 BFS 计算。第三版界面明确称为“陆地采样连通区”，不将其当作裁切片大陆拓扑数量。本批没有新增全世界分片连通分析。

## 生成、局部范围和锁

原大陆、手绘、山系盆地、岛链、海岸平滑和海床生成算法继续产生真实源块。第三版 `generation-session.ts` 在生成算法完成后、候选哈希和替换准备前，调用 `coastal-generation.ts` 分批核验实际分片面积、锁与范围。

- 海岸锁保护带锁格的实际海陆分片和岸线坐标；只保留该格自身 sign 或四角坐标不足以证明锁被遵守。
- 高程锁还保护实际分片上的高度。邻格同号高度改变，或邻格非 incident 顶点改变了重心插值权重，都可能影响带锁格的高度。
- 高程变化需要包含其 3×3 依赖邻域；几何变化从顶点 incident cells 扩展邻域。比较只使用真实片坐标/高度，忽略对物理结果无影响的临时 anchor 身份。
- 局部范围必须保持范围外的派生海岸几何不变。源格值未越界并不足够；边缘改变如会通过共享角点影响选区外片，整份候选被拒绝并说明原因。
- 不在校验阶段偷偷恢复若干单元、移动锁或改小实际操作范围。拒绝/取消留下原会话和源块原样；候选须重新预览。
- 海床和山系在海陆 sign 不变且几何不变时不移动任何裁切岸线。它们仍可能影响共享高度，故不能跳过高程锁检查。

生成核验按真实地块分批累计面积，比较只覆盖实际变化依赖中的锁定格和范围外格；每批都报告进度并检查取消。最终编辑、完整替换和存储 CAS 仍从真实数据重新检查同一保护规则，不将预览已通过当作绕过持久化校验的理由。

## 验证范围与剩余事项

内核测试负责精确裁切、共享边、拾取和面积守恒。`coastal-generation.test.ts` 使用解析可算的单格岛屿（原格面积的 4/9）、邻格和间接重心依赖验证保护与单位。`coastal-generation-session.test.ts` 使用真实生成器、会话与 IndexedDB 路径验证摘要绑定、取消/拒绝原像保留、显式保存恢复和 v2 兼容；此处的测试名称不是通过证据。

渲染缓存和 CPU/GPU 资源预算、三端浏览器截图与交互、真手机和用户视觉验收继续各自记录。完成单元测试或一次本地构建不自动完成这些门，也不解除发布边界。

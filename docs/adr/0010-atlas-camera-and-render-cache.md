# ADR 0010 — 生产地图相机与按需显示缓存

状态：ACCEPTED DESIGN CONTRACT，2026-09-24。PH04基线为本地提交c131c9664d30da8aafa83114a9169359e6e57635。本文件固定PH05实现与测量合同；任务实际完成状态和每次检查结果以plan/tasks.json、docs/evidence/2026-09-24-ph05-rendering.md为准。合同采纳不等于功能或性能验收。既有发布锁与ADR0008的原定阈值不变。

## 坐标与输入

生产数据继续使用已核验AtlasDraftData/共享拓扑，视图不得修改权威缓冲区。相机纯函数统一worldToScreen/screenToWorld/fit/pan/zoomAt/resize，CSS像素与DPR分开；DPR仅影响实际纹理/输出分辨率。缩放使用实际clamp后比例保住指针/双指中心的世界坐标；resize保留世界中心，不偷偷全图复位。默认缩放范围为fit的0.5—80倍。

拾取始终使用原共享几何空间索引与稳定ID，不从缩略贴图或LOD形状反推另一个地块。pointercancel、失焦、capture丢失和双指结束均清理手势状态，不能在操作结束后产生意外编辑/点击。桌面1440×960的实际地图边界必须达到1280×800；检查器覆盖地图，不通过缩小画布满足性能目标。

## 缓存与失效

从当前全块Graphics预绘改为视口与有界预取的按需缓存；真正不可见的dirty块只记失效，返回视口时重建。可见dirty必须在正确画面完成回执前接收。原跨块shared vertex全部incident显示块失效继续有效，不能仅核owner块而漏掉相邻显示。

缓存身份包含atlas/块/显示图层、真实依赖的几何owner和高程块摘要、样式及分辨率档；不能用全局revision无条件失效全图。行政及社会图层尚未实现，不用空组件冒充。

优先显式RenderTexture/Sprite所有权，使分配、替换、淘汰、context恢复和destroy均有确定释放。缓存纹理实际source.pixelWidth×pixelHeight总和硬限32 Mi pixels，包含DPR、gutter与新旧资源共存。分配前做预算；禁用未计入的mipmap/MSAA。正常绘图不得依赖Pixi内部纹理池的不可见资源来声称受控。

淘汰优先离屏；可见集合超预算时使用有记录的低分辨率或精确几何后备，不能删地理样本、缩小世界或改规则。显示质量变化不得影响拾取结果、完整地理hash或存档根。真实CPU提交耗时包含缓存排队/构建和完整绘制过程，不只测末尾renderer.render调用。

首次实际截图发现透明gutter会在相邻块的线性采样合成中露出背景，形成均匀海面的深色块缝。因此显示核心改为固定名义32×32地块矩形，全球采样栅格对齐；每张RT绘制四周2个实际纹理像素halo所覆盖的全部真实邻居quad和高程，使用共享同一source的裁片Texture显示唯一、不重叠core。禁止用海色填充或复制边色伪装真实邻地。预算包含整个RT的core与halo，裁片不另占source；Sprite、裁片和RT分别明确销毁。

裁剪依据显示core矩形；拾取继续使用原始共享几何索引。依赖覆盖实际采样halo可能引用的几何owner/高程块，几何允许偏移step/4也计入保守范围。高程变化只使terrain失效，geometry变化影响terrain/grid。一个数据块会影响邻接显示core，四个权威高程块并不承诺只重画四个core；回执提供真实去重repaintBlockKeys及一致的repaintBlocks，浏览器核其与可见受影响集合相符。均匀海陆跨core连续性及异色边缘需真实像素回归。

离屏失效使用独立的内容脏核心集合，不能仅依附于当前缓存条目。按最宽合法采样halo记录全部受影响核心，预取跳过，真实可见且所需当前图层齐全后才清除；跨分辨率、淘汰和GPU丢失保持这一限制，完整草稿恢复才重置。由此避免UI选择刷新在接收结束后提前重建离屏脏核心；干净邻块仍可有界预取。

外框、选择和预览Graphics按实际数据、选择/提议顶点、描边缩放和GPU代次缓存；纯平移与相同输入不重复构造预览多边形。数据接收、合法输入变化、缩放及GPU恢复使对应缓存失效，卸载释放引用。缓存维护和必要重建仍包含在完整draw计时，不改帧序列或将廉价检查混入真实绘制样本。

地形Graphics独立保留最多128个实际core、131072个quad，包括在途预留；这仅是逻辑几何预算，不声称浏览器或GPU总内存。首次实际绘制建立世界坐标几何，后续更高采样密度只在旧采样范围包含新范围、旧范围全部几何/高程摘要仍匹配时复用路径与三角化；仍绘制新的真实密度纹理，不能放大旧位图替代细节。范围扩大、任一旧依赖变化、GPU丢失或全量换图均释放对应资源；LRU淘汰受两项硬限约束。网格保留当前分辨率准确描边。创建/销毁/命中/释放失败及live+reserved累计账本真实记录，不因clear归零；释放失败不得退账或继续假装资源受控。不得提前按验收轨迹预热未来图层。

## T3 显示策略

三档保留相同真实高程调色，以CSS地块尺寸决定细节，不由DPR改变地理含义。首次阈值为6/24 CSS像素，后续使用进入7/26、退出5/22的迟滞，快速缩放允许直接跨档。远景只保留合法选中高程；中景显示稀疏陆地高程；近景增加真实编辑网格及陆地稳定ID。普通海洋不重复铺满相同深度，选中海洋仍显示准确负高程，0米按真实陆地处理。

所有标签源自当前已核验数据，使用真实quad的面积质心。世界锚定二次幂lattice的每帧检查量最多256地块，包含被过滤项；宽屏标签总上限1/8/32，宽度不足600CSS像素为1/4/12，均包含选中。选中优先，其余确定排序；按实际字体测量矩形避让彼此、视口边缘与已有工具/检查器，不把屏外锚点夹到屏内制造错误定位。

渲染器复用有界DOM标签：展示节点最多32，隐藏测量探针最多256，字体/文本尺寸缓存最多256项。读取布局与写入分批，全部候选、测量和布局纳入完整draw CPU耗时。标签不另建未入账的Pixi文字纹理池；DOM及浏览器合成开销仍由实际帧测量约束。大字、主题变化、面板开闭与缩放重新布局；销毁、GPU不可用或接收期间不遗留过时标签。

遮挡面板绝对定位且外盒不变时，内部进度文本变化不要求地图重画。面板外尺寸变化由border-box ResizeObserver捕获；增删、位置/展开属性、祖先样式、字体主题、滚动及窗口尺寸保留更新。实际矩形和文字测量在真实draw内进行，不丢真实避让，也不为通过预算隐藏进度。

## 生命周期与存储保护

GPU丢失时停止不可能正确显示的操作，保留最新已核验数据/已提交根、相机与合法选择。恢复时重建同一数据的可见缓存；若在持久提交后的accept中丢失，不能把旧画面重新开放为可编辑状态或称为回滚。明确恢复失败才进入既有fatal/刷新恢复路径。销毁取消RAF/异步队列/监听器/observer，显式释放缓存资源，迟到回调按代际失效。

真实浏览器用WEBGL_lose_context扩展验证；只派发DOM事件不是GPU恢复通过。若环境不支持须记录，不伪造。可证明受管理对象回到基线；缺少真实GPU总内存指标时不宣称全局无泄漏。

PH04的preview取消、Atomic commit/backup/CAS、未知版本、关页和迟到取消边界不能退化。旧0.4引擎、数据库、正式CANON与版本指纹保持独立。

## 批次与验收

- 本批T1/T2：纯相机与实际输入接线，按需缓存/裁剪/预算/失效及GPU生命周期。先定向检查，再统一受影响浏览器验证；实现不是验收。
- 下一批T3：远/中/近LOD、细网格和标签密度，全部对应同一数据；当前缺少的城市/国家实体不得伪装成已实现玩法。
- T4：按ADR0008做标准三景、各至少三次60秒轨迹，cold/warm分列，保留全部长帧，DPR2独立。有窗口实际呈现与移动输入仿真分别核验；真机仍PH35独立。

性能使用生产入口、真实草稿和合法编辑序列构造测试地理；测试场景明确非正式设定、非PH06生成器，不将ScaleFixture注册成游戏。测试前后核完整渲染数据/存档摘要和关键拾取，缓存像素与资源计数只是各自范围的证据。未来完整社会和实体规模需其相应阶段再次验收，不能把现空白地理绘图当未来完整游戏性能。

实际结果、首次失败、复测范围与未通过项目持续写入PH05阶段证据和plan/tasks.json，不通过修改本合同抹除失败或降低阈值。

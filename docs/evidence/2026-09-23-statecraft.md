# M3 国家经营与外交验收

日期：2026-09-23。版本 0.3.0，新规则 0.2.0；旧规则 0.1.0 保留。对应 M3-001、M3-002、M3-003 / Issue #11、#12、#13。本文件先记录本地证据，云端栏在实际验证后补充。

## 实际实现

- 人口与粮食保存在地方辖区，国家按实际控制汇总。地形生产、居民消耗、有限驻军补给与饥荒逐日结算；民生/均衡/军事政策影响实际分配。实际日账满足期初 + 生产 − 民用 − 军用 + 领土转移 = 期末。
- 新世界和平起步。宣战/停战影响实际寻路、交战、追击和占领；停战保护十日，已开始的路段保留进度，抵达后沿合法路线撤离。无安全路时等待，不瞬移、不借道第三中立国。
- 桌面右栏、手机/平板抽屉提供国家簿、真实账本、政策与外交预览确认/取消。预览暂停并读取 Worker 权威快照，确认重验 day/nextEventId；过期预览拒绝执行。
- AI 根据观察日数、粮食、有效军力和陆邻关系作可复现选择，记录理由；没有强制胜者。基础系统尚不包含贸易、跨省运粮、海军和外交谈判。
- 旧世界不静默迁移。旧自建局可确认创建规则 0.2 的独立副本，保留日期、地形、实体、军队、路段和原事件；旧数据库逐槽字节不变。新副本沿用旧局敌对关系，新增人口粮食为明确初始化的规则参数。

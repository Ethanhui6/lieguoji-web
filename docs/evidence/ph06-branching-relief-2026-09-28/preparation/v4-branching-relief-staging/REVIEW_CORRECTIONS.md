# 静态审查修正记录

本记录仅描述源码修正与新编写的回归；没有执行生成器、测试、类型检查、lint、构建或浏览器。生产未改。原 candidate 的 ready 清单 `93231e7afc402e293ef37fe9007aa1443f508eac72745c4c49697d3e5c70b985` 已失效并另存为 `ready-manifest.before-review.json`，不能继续按该清单提升。

**问题一：加弱支脊反而降低父山脊。** 原候选的 `Σh⁴/Σh³` 是加权平均；`[1,.7]` 会得到约 `.9234`，比独立父脊低约 7.66%。原新增测试只检查不超过 max，漏掉了这个实际凹陷。

改为具有正 ε 的 L64 合成。对非负值它单调不减，增加支脊不可能从既有父场中减去高度。最多 10 run 时上界为 `10^(1/64) × max`，小于 3.67% 抬升；两 run 上界小于 1.09%。稳定实现先除以最大量级再乘回，避免 64 次幂溢出；最大值在代数中消去，不是形状 max 接缝。ε=1e-6 Q12 单位保证零值光滑；最终整数米/relief cap/海岸 taper 保留。

原新增“绝不高于 max”的设计与断言被明确替换为这个单调性和小上界合同，不是删除旧产品验收。新增独立 `[1,.7]` 反例、0 与极小/极大质量、相等高度交叉的有限斜率检验；真正的单 run 与双 run 场采用相同父几何，沿二维截面逐点检查双 run 不低于 parent-only，且上界满足 `2^(1/64)`，并要求样本里确实出现弱支脊/父脊比例 0.5–0.85 的原缺陷区间。

**问题二：截断主脊的零高真端点还能长出支脊。** 原代码只检查支根是父曲线中的点；当主脊遇海被分成 run，原内部锚点可能成为真实末端。父 endpoint gate 为 0，但原 rootPeak 来自未渐退 profile，因此可从零高处另起高支脊。

支根现在必须位于通过真实海陆探针后留下的父 run 内部，距离两端均不小于实际 endFade，并且同一 endpoint gate 至少 0.5。真端点及渐退段直接拒绝。构建支脊支持前，再以父 run 已构建的真实支持和同一 gate 查询连接高度；根部峰值为该真实值（最高 FIELD_Q）的 0.82 倍。最多两次、总共 8192 支持检查；有独立进度、取消和内部有限值检查。

新增审查原反例：主脊 `x=400→1200→2000,y=1000`；陆地为 `x<=1250 || y>=1020`；支脊从 `(1200,1000)` 向上。先独立查询父场证明此处实高为 0，再检查支脊被拒绝、无支脊支持、整片对照区域与 parent-only 完全一致，不能只靠 rootPeak 元数据通过。正常 fork 回归同时检查支根实际父场高程、根部限定幅度与真实支脊贡献。

**附带输入预算修正。** 每链长度和总 17 锚点上限移到私有复制前，避免 helper 在检查预算前遍历超限源。新增带元素读取陷阱的超限数组测试，要求预算拒绝发生在元素复制前。此项不更改正常 planner 的上限。

原有真实峰鞍、宽差、海陆检查和其他产品测试阈值全部保留。修正后的 15 项新测试仍均为 authored-not-run；需新 ready 精确 SHA、独立静态复核和 root 的统一执行结果后再判断可提升。

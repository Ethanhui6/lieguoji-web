## 实际操作

在国家面板选择「手绘移除领土」，可手绘或逐点圈出本国区域，经过预览、确认保存后恢复为未分配陆地。支持取消预览、持久撤销和刷新恢复。海陆本身不变，仍按当前版本的完整政治单元移除，不是沿任意笔迹切割单元。v1 拒绝此命令，v2/v3 保留各自原几何规则。

Worker 按已有预览/重验/摘要比较/CAS管线执行 release-territory-shape。所选单元若含本国城市或首都、他国法理或实控归属，整笔拒绝；没有变化或移除本国全部法理领土同样拒绝。即使城市坐标在笔迹外，其完整政治单元被圈中仍受保护。城市、国家、政权与首都 ID 不改。

选择已有城市/国家会清理过期错误与点选提示。跨国选择还会清除上一国的未提交轮廓、候选地块及扩大/移除模式，同步新的名称与颜色，避免把甲国草稿挂到乙国。

## 几何与性能

coverage 裁剪不再预先建立用不到的基础高程和旧空间索引；真正点选海陆/高程时仍惰性读取真实高度。此首轮改动没有改善整图打开：同一三国世界 preview.27 为 83.31 秒，初版 preview.28 为 85.76 秒，原始数据均保留，不能声称首轮提速。

进一步发现内陆单元先生成大量细陆三角裁片，最后又用完整政治多边形替换。最终先按原 Surface 和正面积 SAT 证明完整单元没有海水、有实际陆地，才直接返回同一多边形。一旦发现海水，使用保留的完整慢裁剪函数，输出顺序/坐标不变；预算、取消和私有来源保持。测试直接用保留的慢算法比较真实海湾洞、零边、孤岛、全陆和全海，不重写一份镜像裁剪来冒充参考。

最终同世界刷新到可操作为 **50.45 秒**；这是单台 Windows / Chrome、同一 664×690 视口的各一次本地观察，未清空 HTTP 缓存，不是严格统计基准、p95或真机性能通过。最终测量期间没有同时跑工程/浏览器测试。旧轮次的机器负载未严格控制，不推导普遍收益。

原世界 11,087 条领土、59,611 个裁陆片、8,303 条边段保持；最终 SVG 陆地路径摘要、边界路径摘要与国名锚点同 preview.27 完全一致。v3 当前根及旧 v1/v2 根、历史、独立地理摘要均未变。原模拟引擎和 11 个地理生成身份不变，未改生成闭包、渲染规则或旧存档格式。

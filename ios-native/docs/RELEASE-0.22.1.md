# 0.22.1 · 邦交与界面细节

基于 Claude 最新已推送提交 66c3329a（0.22.0），而非旧版 0.9.18。已阅读 PORTING.md、SWIFT-PORT-STATUS.md 和交接记录；阶段文档是历史记录，功能现状以最新代码为准。不修改网页版与 Capacitor 壳。

## 新增与调整
- 外交总页增加互不侵犯（5/10/20 年）、十年联姻、同盟、赠金。复用国家页现有引擎命令与资格校验，不新增未经核实的数值规则。等待期间禁止重复提交，失败原因直接显示。
- 国家搜索、现存国家筛选；军事页按全部、交战/围城、玩家军令筛选。保留原有军团、舰队详情与军令。
- 国家分节按钮至少 44pt，箭头连续旋转；统一卡片短淡入，适配减少动态效果。
- 保留原作交锋图集、围城、占领、宣战、和约效果。持续特效上限：48 处交锋、64 处围城、32 条战术箭头；瞬时层上限：占领/爆发/宣称各 24，宣战/和平各 8。超额仅省略装饰，不影响战斗结算。视野外交锋和围城层隐藏并冻结，回到视野后续播，避免重新从第一帧开始。历史去重缓存最多 2048 项。
- 新应用图标：imagegen 内置生成，海青底、玉白城阙、朱红与领土拼片；打包为 1024px，不预裁圆角。提示词方向：centered ivory jade ancient city gate above interlocking territories, deep ocean teal, cinnabar accent, tactile ceramic relief, no lettering。

## 验证与限制
本地 git diff --check；Swift/Core 回归、Metal 编译与 iOS archive 交由该提交的 GitHub Actions 验证，结果见 PR。没有 Mac 或真机，未测 120fps，未做原生截图验收；不能承诺动画零成本。

真机验证：同一存档在暂停/推演、拖动/捏合、交战密集区分别记录平均帧时间和 1% low；打开外交确认重复点击不会重复扣金，检查赠金前后双方国库；国家搜索与军队筛选后进入详情；打开系统减少动态效果后核对卡片与分节；相机移出战场再移回核对动画接续。

后续仍需：外交关系全局总览、战损趋势/战役详情的原作对照、全面 Dynamic Type 与小屏截图验收、真实设备 CPU/GPU 测量。新世界生成等遗留移植边界继续遵循 SWIFT-PORT-STATUS.md，未在此版声称完成。

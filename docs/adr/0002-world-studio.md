# ADR 0002：自由创世成为主线，正式核图保持独立

> 后继范围见 [ADR0005](0005-standalone-v4-local-release-gate.md)。本文件的授权/创建状态是当时历史，不作为当前登录或Pages项目判断；当前状态读 AUTO_HANDOFF 与实际证据。

日期：2026-09-23。状态：已采纳；0.2.0三项基础功能本地验收通过，云端/真机/正式核图未通过。实现及证据见 ../evidence/2026-09-23-world-studio.md。

## 问题与依据

已有工程实现固定五国测试大陆的可玩命令闭环，但这不能覆盖用户最新明确的自由创世目标。旧路线把地图编辑挂在原规划恢复和 ACCEPT-MAP 后，导致不依赖正式资料的创世开发也被阻塞。

用户最新指令优先：自由创世 → 海陆与连续地形 → 国家、城市与首都 → 自主推演。官方参考游戏的分层编辑流程提供产品研究依据，具体来源和无法播放视频的限制见 ../REFERENCE_GAME_RESEARCH.md。采用玩法关系，不复制源码、素材、文字或原作界面。

## 决定

- M2-001 → M2-002 → M2-003 为当前三项批次，起点依赖已完成的 M1-003；各项以真实测试证据完成，不等待 ACCEPT-MAP 或原 100 项任务恢复。
- 保留现有 React / PixiJS 展示、独立 sim-core、Web Worker 和 IndexedDB 基础。地图草稿经校验与编译进入同一模拟链，不新建一套与真实规则脱节的动画演示。
- 地理、行政区、国家、城市、首都引用、标签位置分层保存。编辑改变真实地图和规则输入，行政颜色由归属推导。编辑模式暂停，初始草稿和运行历史分离。
- 先实现基础自主决策和可解释行动，不将外交、经济、皇室等后续系统做成空面板或提前标为通过。
- 自建世界存档与测试战役隔离，保留备份、版本锁写和多标签 CAS。启动新世界或导入不能悄悄覆盖已有局。
- M2-PLAN 继续负责恢复原规划后的差异核对，仍因资料缺失 blocked；它不再是上述三项或 M3 的硬依赖。M3 以 M2-003 为前置，未知原规划内容继续待核。
- ACCEPT-MAP 只约束正式五国地图和依赖正式地图的剧情验收。CANON 确认设定不变，测试地图和玩家沙盒不能自动转正。

## 后果与验收

固定测试大陆继续用于规则回归，主入口增加自由创世。新功能须完成海陆绘制/生成、撤销、草稿恢复、国家城市首都编辑、自建地图运行与存档恢复全链；模拟必须受到玩家编辑的地形和归属影响。手机以显式工具和确认操作完成核心编辑，仿真与真机证据分开。

需要为地图编辑后的拓扑、实体引用和派生规则数据建立检查。失败时保留草稿并提供可定位的问题，不能用重置地图或忽略错误取得通过。新旧存档隔离和原模拟回归属于本批次测试范围。

部署决策仍沿用 ADR 0001，优先 Pages 原生 Git，当前未创建 Pages 项目。现场 Cloudflare 登录已成功不代表仓库 App 授权或 CI 已连通；GitHub CLI 最终交换曾遭遇网络 EOF，新设备授权流程待完成。只有真实远端运行和实际 URL 验证后才能更改云端任务状态。

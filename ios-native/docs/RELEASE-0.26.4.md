# 原生版 0.26.4（build 76）

基于 0.26.3。只改 `ios-native/` 的界面。开场动画和亡国清军没有再改。不合并。

## 新增
- 无。

## 修改
- 设置里的音量、显示设置里的国名缩放和颜色浓度，改用已有的纸面滑杆。
- 新世界的省份数量改用已有的纸面加减，种子输入改用已有的纸面输入框。远程计算的地址框同样改成纸面输入框。
- 出错提示、放弃自绘地图、换底图，改成已有的宣纸面板和朱红按钮，不再用系统弹窗和系统菜单。
- 自绘地图的笔刷、州郡数、国家数改用纸面滑杆；笔触与地貌改用已有的折叠分节。
- 军团页的士气、国家页的国运和四项能力，改用同一条纸面滑杆。

## 修复
- 无。

## 验证与已知问题
- 没有真机。导出存档仍调用系统分享，导入仍调用系统文件选择，因为那是把文件交给系统，不是游戏里的设置控件。
- 国家页里选择文化、宗教、州郡仍用原来的纸面菜单行。那一行点开后仍是系统菜单，这次没有另做一套下拉。
- 开场仍是 0.26.1 的「注水成海」。亡国清军仍是 0.26.3 的行为。
